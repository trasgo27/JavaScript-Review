## Set con objetos — Clave para entender

**No necesitas transformar objetos completos a string.** Solo extraes el campo que te interesa como string primitivo y `Set` funciona directo:

```js
const logsServidorLimpio = logsServidor.map(item => ({
    userId: item.userId.trim().toLowerCase(),
    action: item.action.trim().toLowerCase(),
    status: item.status.trim().toLowerCase()
}));

// ✅ Set de usuarios únicos (strings → funciona directo)
const usuarios = new Set(logsServidorLimpio.map(item => item.userId));
// ["usr_10", "usr_25", "usr_42", "usr_88"]

// ✅ Set de acciones únicas (strings → funciona directo)
const acciones = new Set(logsServidorLimpio.map(item => item.action));
// ["purchase", "view_item"]
```

**¿Por qué funciona?** Extraes **strings** (`item.userId`, `item.action`), no objetos. `Set` compara strings por valor → elimina duplicados automáticamente.

**Solo necesitas el "viaje ida y vuelta" (`JSON.stringify` + `JSON.parse`) cuando quieras deduplicar objetos completos** (varias propiedades como clave compuesta). Para una sola propiedad, un simple `.map()` basta.

## Cómo crear un Set de objetos completos

**Problema:** `Set` compara objetos por referencia, no por valor. Dos objetos con el mismo contenido son distintos en memoria.

**Solución — viaje de ida y vuelta (string → Set → parse):**

```js
const unicos = [...new Set(logsServidor.map(JSON.stringify))].map(JSON.parse);
```

### Desglose paso a paso

```js
const normalizados = logsServidor.map(item => ({
    userId: item.userId.trim().toLowerCase(),
    action: item.action.trim().toLowerCase(),
    status: item.status.trim().toLowerCase()
}));

// 1. Serializar cada objeto a string
const strings = normalizados.map(JSON.stringify);
// ['{"userId":"usr_10","action":"purchase","status":"completed"}', ...]

// 2. Set elimina strings duplicados (comparación por valor)
const setStrings = new Set(strings);

// 3. Reconstruir objetos desde strings únicos
const objetosUnicos = [...setStrings].map(JSON.parse);
```

### Atajo en una línea

```js
const unicos = [...new Set(normalizados.map(JSON.stringify))].map(JSON.parse);
```

### Si quieres deduplicar solo por una combinación específica

Ej: mismo `userId` + `action`, ignorando `status`:

```js
const visto = new Set();
const filtrados = normalizados.filter(item => {
    const clave = `${item.userId}|${item.action}`;
    if (visto.has(clave)) return false;
    visto.add(clave);
    return true;
});
```
