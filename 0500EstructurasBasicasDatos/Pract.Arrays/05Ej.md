# Bug Report for `05Ej.js`

## Bugs Found

### Bug 1 — Line 28: Case mismatch after uppercasing
```js
if(p.accion === 'login'){
```
All actions were uppercased to `'LOGIN'` on line 12 (`p.accion.trim().toUpperCase()`), but the condition checks for lowercase `'login'`. The condition never matches, so the frequency map stays empty.

**Fix:** Change to `p.accion === 'LOGIN'`

### Bug 2 — Line 31: Wrong indexing on object
```js
let frec = p[1];
```
`p` is an object `{usuario, accion}` (from `actTrim`), not an array. `p[1]` evaluates to `undefined`, so every subsequent login count becomes `NaN`.

**Fix:** Replace with `let frec = frecUsu.get(usu);`

### Minor — Lines 17–18: Unnecessary JSON.stringify
```js
const usu_Unicos = new Set(actTrim.map(p => JSON.stringify(p.usuario)));
```
`p.usuario` is already a string. `JSON.stringify` wraps it in extra quotes. Not a bug, but adds unnecessary noise. Works fine as-is.
