splice() Method, is used to replace the original values

catalogo.splice(n1,n2?,n3 ...)
n1 Starting Index,
n2 how many items to remove from that point onward. Warning, if you omit it ALL from n1 onward are removed
n3 forward new items
splice() a) Modifies the original array and b) returns an array with the removed items.

removed = days.splice(1,2,"M A R T E S","M I E R C O L E S");

slice(n1,n2) takes two parameter that are the indexes.
a) it DOESN'T modify the original array
b) it returns a new SUBARRAY from n1 to n2 (not included)



removed = days.slice(1,4)
