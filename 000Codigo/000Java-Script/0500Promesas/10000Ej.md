# Guía Completa de Promesas y Async/Await para Principiantes

---

## 1. ¿Qué es una Promesa?

Una **Promise** (promesa) es un objeto que representa la **terminación o el fracaso** de una operación asíncrona. Básicamente es un "vale" que te dice: *"ahora no tengo el resultado, pero te lo daré en el futuro"*.

```js
const promesa = new Promise((resolve, reject) => {
  // código asíncrono aquí
});
```

---

## 2. Estados de una Promise

| Estado | Significado |
|--------|-------------|
| **pending** | Estado inicial, aún no se ha resuelto ni rechazado |
| **fulfilled** | La operación terminó con éxito → se llamó a `resolve()` |
| **rejected** | La operación falló → se llamó a `reject()` |
| **settled** | Ya sea fulfilled o rejected (ya terminó) |

---

## 3. Sintaxis básica de una Promise

```js
const miPromise = new Promise((resolve, reject) => {
  const exito = true;

  if (exito) {
    resolve('¡Todo bien!');  // → fulfilled
  } else {
    reject('Algo salió mal');  // → rejected
  }
});
```

### Parámetros del constructor:
- **`resolve`** — función que se llama cuando la operación tiene éxito
- **`reject`** — función que se llama cuando la operación falla

> ⚠️ `resolve` y `reject` son funciones que el motor de JavaScript te proporciona. No son variables para asignar (`resolve = 'ok'` ❌). Se llaman con paréntesis (`resolve('ok')` ✅).

---

## 4. Métodos para consumir una Promise

### `.then()` — manejar el éxito

```js
miPromise.then((mensaje) => {
  console.log(mensaje); // "¡Todo bien!"
});
```

### `.catch()` — manejar el error

```js
miPromise.catch((error) => {
  console.error(error); // "Algo salió mal"
});
```

### `.finally()` — se ejecuta siempre (éxito o error)

```js
miPromise.finally(() => {
  console.log('Esto se ejecuta siempre');
});
```

### Encadenamiento completo:

```js
miPromise
  .then((mensaje) => {
    console.log('Éxito:', mensaje);
  })
  .catch((error) => {
    console.error('Error:', error);
  })
  .finally(() => {
    console.log('Fin del proceso');
  });
```

---

## 5. Ejemplo clásico: Simulador de descarga

```js
function descargarArchivo(nombre) {
  return new Promise((resolve, reject) => {
    if (!nombre || nombre.trim() === '') {
      reject('Error: Nombre inválido');
      return;
    }

    console.log(`Descargando ${nombre}...`);

    setTimeout(() => {
      resolve(`Archivo "${nombre}" descargado`);
    }, 3000);
  });
}

descargarArchivo('foto.jpg')
  .then((mensaje) => console.log(mensaje))
  .catch((error) => console.error(error));
```

### Línea por línea:
1. `return new Promise(...)` — la función devuelve una promesa
2. `if (!nombre)` — validación: si no hay nombre, rechazamos
3. `reject('Error...')` — llamamos al rechazo con un mensaje
4. `return` — salimos para no seguir ejecutando
5. `setTimeout(() => { resolve(...) }, 3000)` — simulamos una descarga de 3 segundos
6. `.then()` / `.catch()` — el consumidor maneja éxito o error

## 6. Async / Await (ES2017)

`async/await` es **azúcar sintáctico** sobre las Promesas. Hace que el código asíncrono se lea como si fuera síncrono.

### `async` — declara una función asíncrona

```js
async function miFuncion() {
  // esta función siempre devuelve una Promise
}
```

- Una función `async` **siempre devuelve una Promise**
- Si retornas un valor, se envuelve automáticamente en `Promise.resolve()`
- Si lanzas un error, se envuelve en `Promise.reject()`

```js
async function hola() {
  return 'Hola mundo';
}

hola().then(console.log); // "Hola mundo"

async function error() {
  throw new Error('Algo malo');
}

error().catch(console.error); // Error: Algo malo
```

### `await` — espera una Promise

```js
async function ejemplo() {
  const resultado = await descargarArchivo('foto.jpg');
  console.log(resultado);
}
```

- `await` **pausa** la ejecución de la función `async` hasta que la Promise se resuelva
- El valor resuelto por `resolve()` se asigna directamente a la variable
- Si la Promise se rechaza, `await` lanza una excepción

### try...catch con async/await (en lugar de .then().catch())

```js
async function procesar() {
  try {
    const resultado = await descargarArchivo('foto.jpg');
    console.log(resultado);
  } catch (error) {
    console.error('Error:', error);
  } finally {
    console.log('Proceso terminado');
  }
}

procesar();
```

## 7. Comparativa: then/catch vs async/await

### Con .then() y .catch()
```js
function main() {
  descargarArchivo('foto.jpg')
    .then((msg) => {
      console.log(msg);
      return descargarArchivo('video.mp4');
    })
    .then((msg) => {
      console.log(msg);
    })
    .catch((err) => {
      console.error(err);
    });
}
```

### Con async/await (equivalente exacto)
```js
async function main() {
  try {
    const msg1 = await descargarArchivo('foto.jpg');
    console.log(msg1);
    const msg2 = await descargarArchivo('video.mp4');
    console.log(msg2);
  } catch (err) {
    console.error(err);
  }
}
```

> El código async/await es más lineal y fácil de leer, especialmente con múltiples operaciones secuenciales.

## 8. Errores comunes de principiantes

### ❌ Error 1: Olvidar el `return` en la función que crea la Promise

```js
function descargar() {
  new Promise((resolve) => {  // ❌ falta return
    resolve('ok');
  });
}

descargar().then(console.log); // TypeError: Cannot read properties of undefined
```

✅ **Correcto:**
```js
function descargar() {
  return new Promise((resolve) => {
    resolve('ok');
  });
}
```

### ❌ Error 2: Usar `resolve` y `reject` como variables

```js
new Promise((resolve, reject) => {
  resolve = 'BIEN';  // ❌ esto reemplaza la función
  // ahora resolve no es una función, es un string
});
```

✅ **Correcto:**
```js
new Promise((resolve, reject) => {
  resolve('BIEN');  // ✅ se llama como función
});
```

### ❌ Error 3: `await setTimeout()` sin envolver en Promise

```js
async function esperar() {
  await setTimeout(() => console.log('hola'), 1000); // ❌
  // setTimeout retorna un número (timer ID), no una Promise
}
```

✅ **Correcto:**
```js
async function esperar() {
  await new Promise(resolve => setTimeout(resolve, 1000)); // ✅
  console.log('hola');
}
```

### ❌ Error 4: Poner `return` dentro de .then() cuando no es necesario

```js
miPromise.then((msg) => {
  return console.log(msg); // ❌ return innecesario
});
```

✅ **Correcto:**
```js
miPromise.then((msg) => {
  console.log(msg); // ✅ sin return
});
```

### ❌ Error 5: Confundir `.try()` con `.then()`

Las promesas tienen: `.then()`, `.catch()`, `.finally()`. No existe `.try()`.

## 9. Promise.all() — Ejecutar en paralelo

```js
async function descargarTodo() {
  const promesas = [
    descargarArchivo('foto.jpg'),
    descargarArchivo('video.mp4'),
    descargarArchivo('doc.pdf')
  ];

  const resultados = await Promise.all(promesas);
  console.log(resultados); // Array con los 3 resultados
}
```

- `Promise.all()` lanza todas las promesas **en paralelo**
- Espera a que **todas** se resuelvan
- Si **una** falla, toda la operación falla

---

## 10. Promise.allSettled() — No importa si fallan

```js
const resultados = await Promise.allSettled([
  descargarArchivo('foto.jpg'),
  descargarArchivo('')  // esta fallará
]);

resultados.forEach(r => {
  if (r.status === 'fulfilled') console.log('OK:', r.value);
  if (r.status === 'rejected') console.log('FAIL:', r.reason);
});
```

```

│                       │                              │
│            ┌──────────┴──────────┐                   │

│      ┌─────────┐          ┌──────────┐               │
│      │fulfilled│          │ rejected │               │

│      └────┬────┘          └─────┬────┘               │

└─────────────────────────────────────────────────────┘

async/await es solo una forma más legible de escribir lo mismo:

  async → declara que la función devuelve una Promise
  await → pausa hasta que la Promise se resuelve
  try/catch → captura errores como si fueran síncronos
```
