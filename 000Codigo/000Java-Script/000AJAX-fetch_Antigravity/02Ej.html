AJAX & Fetch Mastery

Exercise 02: POST, PUT & DELETE Methods

Practice modifying data on a server using Fetch API's other HTTP methods.

fetch('https://jsonplaceholder.typicode.com/posts', {
  method: 'POST',
  headers: { 'Content-type': 'application/json' },
  body: JSON.stringify({ title: 'foo', body: 'bar', userId: 1 })
})

Tasks

Task 1: Create a new resource (POST)

Use `fetch` to send a POST request to `https://jsonplaceholder.typicode.com/posts` with a new post object. Log the response to the console.

Task 2: Update an existing resource (PUT)

Use `fetch` to send a PUT request to `https://jsonplaceholder.typicode.com/posts/1` to update its title. Log the updated object to the console.

Task 3: Delete a resource (DELETE)

Use `fetch` to send a DELETE request to `https://jsonplaceholder.typicode.com/posts/1`. Note the response status and log it.
