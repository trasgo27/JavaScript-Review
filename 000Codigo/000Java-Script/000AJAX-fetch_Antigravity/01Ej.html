AJAX & Fetch Mastery

Exercise 01: Fetch API Basics

Practice making asynchronous requests using the fetch() API.

fetch('https://jsonplaceholder.typicode.com/posts/1')
  .then(response => response.json())
  .then(data => console.log(data));

Tasks

Task 1: Basic GET request

Use `fetch` to retrieve users from `https://jsonplaceholder.typicode.com/users`. Log the response to the console.

Task 2: Handling JSON

Extract the JSON data from the response in Task 1 and log the array of users.

Task 3: Display data in DOM

Create a `div` element below and append the user names dynamically after fetching them.

Task 4: Error Handling

Make a request to a non-existent URL (e.g., `https://jsonplaceholder.typicode.com/invalid-url`) and handle the error using `.catch()`. Log a friendly error message.

Task 5: Async / Await

Rewrite the logic from Task 1 and 2 using an `async` function and the `await` keyword. Use the `hacerEj()` function structure to organize your code.

Expected Output
