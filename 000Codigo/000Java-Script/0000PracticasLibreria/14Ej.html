You are building a shipping coordination module for an e-commerce platform. You need to fetch quotes from multiple shipping carriers, filter the successful ones, analyze the rates, and determine the fastest option.

// Simulates requesting a shipping quote from a carrier
function solicitarCotizacion(transportista, destino) {
    return new Promise((resolve, reject) => {
        const tiempo = Math.floor(Math.random() * 1500) + 500; // 500ms to 2000ms
        const precio = Math.floor(Math.random() * 80) + 20; // $20 to $100
        const diasDeEntrega = Math.floor(Math.random() * 5) + 1; // 1 to 5 days
        const rate = +(Math.random() * 5).toFixed(1); // Rating 0.0 to 5.0

        setTimeout(() => {
            // 75% chance of success
            if (Math.random() > 0.25) {
                resolve({
                    carrier: transportista,
                    destino: destino,
                    costo: precio,
                    dias: diasDeEntrega,
                    rating: rate
                });
            } else {
                reject(new Error(`Error de conexión con ${transportista}`));
            }
        }, tiempo);
    });
}

Tasks

Task 1: Fetch quotes from all carriers

You have an array of carriers. Use Promise.allSettled() to fetch shipping quotes for all of them to the destination "Tokio".
Use only .then() and .catch() (no async/await) to handle the results. 

const transportistas = ["FedEx", "DHL", "UPS", "Seur", "Correos"];

Task 2: Filter successful quotes & Identify failed ones

From the allSettled results, filter out the fulfilled ones and map them to extract their quote details. Log them in a table.
Also, extract a list of carrier names that failed (rejections) to log them as "Failed carriers".

Task 3: Find the fastest shipping option

From the successful quotes, use .reduce() to find the carrier with the lowest dias (delivery time).
If there is a tie, choose the one with the lowest costo. Log the winner.

Task 4: Sort by price and rating

Create a copy of the successful quotes array and sort it in ascending order by costo.
If two carriers have the exact same cost, sort them by rating descending.

Task 5: Calculate Average shipping cost

Use .reduce() to calculate the average shipping cost of all successfully retrieved quotes.

Task 6: Instant Booking Race & Retry (Bonus)

You need to book a slot instantly with the fastest successful responder. Use Promise.any() to race all carriers.
If the race fails (all carriers reject), catch the error and retry the booking using only the list of failed carriers you identified in Task 2.
