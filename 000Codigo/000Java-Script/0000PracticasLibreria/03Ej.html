Objetivo: Convertir la lógica de Promises a sintaxis async/await.

Tu tarea:

Escribe una async function verificarEdadAsync(edad).
Dentro de ella, usa await con una Promise que tenga un delay de 1 segundo.
Después del delay, verifica la edad:

  • Si es válida (>= 18), retorna el mensaje de éxito
  • Si no es válida (< 18), lanza un throw new Error

Escribe otra async function probarVerificacion() que use try/catch para llamar a verificarEdadAsync.
Pruébala con ambas edades (20 y 15).
