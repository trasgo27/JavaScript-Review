Exercise 18: Master find() and findIndex()

Practice locating elements with Array.prototype.find() and Array.prototype.findIndex(): searching by condition, object properties, and handling not-found cases.

// find signature:
// const element = array.find((currentValue, index, array) => {

// findIndex signature:
// const index = array.findIndex((currentValue, index, array) => {

// });

Reference

array.find((currentValue, index, array) => condition);
// Returns: element | undefined

array.findIndex((currentValue, index, array) => condition);
// Returns: index (number) | -1
