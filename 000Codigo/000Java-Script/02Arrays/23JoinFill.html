join() and fill() Mastery

Exercise 23: Master join() and fill()

Practice converting arrays to strings with Array.prototype.join() and filling arrays with Array.prototype.fill().

// join signature:
// const string = array.join(separator);
// separator: string placed between elements (default: ",")
// Returns: a string with all elements joined

// fill signature:
// array.fill(value, start, end);
// value: the value to fill with
// start: start index (default: 0)
// end: end index, exclusive (default: array.length)
// Returns: the MODIFIED array (mutates in place)

Setup

const words = ["reduce", "map", "filter", "find", "some", "every", "flat"];
const numbers = [5, 12, 8, 130, 44, 3, 27, 9, 150, 1];
const matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
];

Tasks

Task 1: Join with default separator

Use .join() on words with no separator argument. Log the result.

Task 2: Join with comma and space

Use .join() on words with ", " as the separator. Log the result.

Task 3: Join numbers into a string

Use .join() on numbers with " - " as the separator. Log the result.

Task 4: Build a sentence

Use .join(" ") on words to create a sentence. Log it.

Task 5: Fill an array with zeros

Create a new array of length 10 and use .fill(0) to fill it with zeros. Log the result.

Task 6: Fill a portion

Use .fill() on a copy of numbers to replace elements from index 3 to index 6 (exclusive) with 0. Log the modified copy.

Task 7: Fill with a mapped value

Create a new array of length 5 and use .fill(null) then .map() to fill it with random numbers. Log the result.

Task 8: Join matrix rows

Use .map() on matrix to join each row with " | ", then join the result with "\n" to create a formatted grid. Log it.

// Expected:
// 1 | 2 | 3
// 4 | 5 | 6
// 7 | 8 | 9

Task 9: Fill an array of objects

Create an array of length 3 and use .fill({ count: 0 }). Then change one element's count to 5. What happens to the others? Why?

Task 10: CSV builder (Bonus)

Given products from previous exercises, use .map() and .join() to create a CSV string with headers "name,price,category".

// Expected:
// name,price,category
// Laptop,1200,electronics
// Phone,800,electronics
// ...

English Challenge

Write 2–3 sentences in English explaining an important caveat when using .fill() with objects. What does "fill by reference" mean?

Reference

array.join(separator = ",");
// Returns: string

array.fill(value, start = 0, end = array.length);
// Returns: the mutated array (same reference)

// ⚠️ fill with objects fills by reference:
// .fill({}) creates ONE object shared by all slots
