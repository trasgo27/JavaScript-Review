filter() Mastery

Exercise 17: Master the filter() Method

Practice selecting elements from arrays with Array.prototype.filter(): callback conditions, index usage, and chaining.

// filter signature:
// const newArray = array.filter((currentValue, index, array) => {
//     return true;  // keep element
//     return false; // discard element
// });

// filter returns a NEW array containing only elements
// for which the callback returned true.
// It does NOT mutate the original array.

Setup

const numbers = [5, 12, 8, 130, 44, 3, 27, 9, 150, 1];
const words = ["reduce", "map", "filter", "find", "some", "every", "flat"];
const products = [
    { name: "Laptop", price: 1200, category: "electronics", rating: 4.5 },
    { name: "Phone", price: 800, category: "electronics", rating: 4.7 },
    { name: "Shirt", price: 30, category: "clothing", rating: 3.8 },

    { name: "Jeans", price: 60, category: "clothing", rating: 4.0 },
    { name: "Headphones", price: 150, category: "electronics", rating: 4.6 },
];

English Challenge

Write 2–3 sentences in English explaining how .filter() decides which elements to keep. What does the callback function need to return?

Reference (filter signature)

array.filter((currentValue, index, array) => {
    // return truthy  → element is kept
    // return falsy   → element is discarded
});

// Returns: a new array with kept elements
