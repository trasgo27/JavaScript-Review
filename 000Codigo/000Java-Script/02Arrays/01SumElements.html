✅ 01SumElements.html — Sum Elements with reduce()

✅ Key concepts

  • Named function: add is defined separately and passed to reduce()
  • Initial value 0: without it, the first element 4 would be used as acc, skipping one iteration
  • accumulator pattern: the return value of each call becomes the first argument of the next call
