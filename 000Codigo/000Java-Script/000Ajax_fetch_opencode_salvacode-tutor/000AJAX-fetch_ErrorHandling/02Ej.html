Ejercicio 02 — Catch Errores HTTP (404, 500)

fetch() NO lanza error en respuestas 404 o 500. Hay que verificar response.ok manualmente.

Tareas:

  1. Fetch a /posts/99999 (404) y verificar !response.ok
  2. Fetch a /invalid-endpoint y manejar 404
  3. Crear función checkStatus(response) que lance error si !ok
  4. Mostrar en DOM: status, statusText, URL solicitada

Abre la consola del navegador (F12) para ver los resultados.
