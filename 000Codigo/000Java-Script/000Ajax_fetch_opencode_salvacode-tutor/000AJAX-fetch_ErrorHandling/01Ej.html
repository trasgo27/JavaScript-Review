Ejercicio 01 — Catch Errores de Red

Aprender a capturar errores de red: sin internet, URLs muertas, DNS que falla, etc.

Tareas:

  1. Fetch a una URL que falle (dominio inexistente)
  2. Capturar TypeError de red en catch
  3. Mostrar mensaje amigable en el DOM
  4. Crear función fetchSafe(url) que maneje errores de red

Abre la consola del navegador (F12) para ver los resultados.
