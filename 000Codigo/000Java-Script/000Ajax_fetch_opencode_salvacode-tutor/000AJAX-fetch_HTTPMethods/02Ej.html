Ejercicio 02 — POST: Crear un Recurso Nuevo

Crea nuevos recursos en el servidor con el método HTTP POST.

Tareas:

  1. Crear objeto { title, body, userId }
  2. Fetch POST a /posts con method, headers, body stringify
  3. Parsear respuesta, verificar que devolvió objeto con id
  4. Demostrar error: olvidar JSON.stringify()
  5. Demostrar error: olvidar Content-type header

Abre la consola del navegador (F12) para ver los resultados.
