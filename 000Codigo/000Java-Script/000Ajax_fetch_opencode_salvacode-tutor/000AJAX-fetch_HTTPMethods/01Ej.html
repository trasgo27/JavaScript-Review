Ejercicio 01 — GET con Query String

Aprende a pasar parámetros de consulta en URLs con fetch().

Tareas:

  1. Fetch con query params: /posts?userId=1
  2. Fetch con múltiples params: /posts?userId=1&_limit=3
  3. Crear función buildUrl(base, params) que construya URLs con query strings

Abre la consola del navegador (F12) para ver los resultados.
