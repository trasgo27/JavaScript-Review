Ejercicio 02 — Tu Primera Petición fetch()

Realiza tu primer GET con fetch() y entiende por qué la respuesta no es JSON directamente.

Tareas:

  1. Fetch GET a /users/1 y logear respuesta cruda
  2. Explicar por qué la respuesta NO es JSON directamente
  3. Encadenar .then(r => r.json()) y logear datos
  4. Comparar: cuántos .then() vs XMLHttpRequest

Abre la consola del navegador (F12) para ver los resultados.
