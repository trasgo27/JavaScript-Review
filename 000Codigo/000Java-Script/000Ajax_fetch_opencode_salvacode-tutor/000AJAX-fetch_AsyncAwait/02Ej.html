Ejercicio 02 — try/catch/finally con fetch

Usar try, catch, y finally para manejar peticiones con indicador de carga visual.

Tareas:

  1. Crear funcion cargarDatos(url) con async/await
  2. Usar try para la peticion exitosa
  3. Usar catch para errores de red y HTTP
  4. Usar finally para limpiar loading indicator en DOM
  5. Agregar spinner visual durante carga

Abre la consola del navegador (F12) para ver los resultados.
