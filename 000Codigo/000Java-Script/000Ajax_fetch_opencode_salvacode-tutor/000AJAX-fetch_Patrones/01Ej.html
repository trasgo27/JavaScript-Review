Patrones Avanzados y Optimización

Exercise 01: Cache Simple de Respuestas

Implementa un sistema de cache en memoria para no repetir peticiones ya hechas.

Tasks

Task 1: Cache con Map

Crea un new Map() como cache. Primera llamada = fetch real, segunda = cache hit.

Task 2: fetchCached()

Función que verifique el cache antes de hacer fetch.

Task 3: TTL de 30 segundos

Agregar timestamp al cache. Si tiene más de 30s, re-fetch.

Task 4: Botón Limpiar Cache

Botón que vacíe el Map y resetee el contador.

Nota: Revisa la consola y el script linked abajo para la implementación.
