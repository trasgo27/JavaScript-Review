Ejercicio 1 — Búsqueda con debounce

Descripción

Implementa búsqueda en tiempo real con debounce y AbortController para cancelar peticiones anteriores.

Tareas

  1. Implementar debounce(fn, delay) desde cero
  2. Conectarla a un input de búsqueda
  3. Fetch a /users?name_like={valor} después de 300ms de inactividad
  4. Mostrar resultados debajo del input
  5. Indicador "Buscando..." mientras la petición está en curso
  6. Cancelar petición anterior con AbortController
