Ejercicio 5 — Loading, Empty y Error States

Descripción

Implementa componentes reutilizables para diferentes estados de la UI: carga, vacío y error.

Tareas

  1. Crear componentes: LoadingSpinner, EmptyState, ErrorState
  2. Implementar flujo completo: Loading → Datos | Error | Empty
  3. Mostrar spinner durante fetch
  4. Mostrar "No hay resultados" si array vacío
  5. Mostrar error con botón "Reintentar"
  6. Estilos CSS inline para cada estado
