Headers, Autenticación y Seguridad

Exercise 01: Headers Personalizados y DevTools

Aprende a enviar headers personalizados en tus peticiones fetch y a inspeccionarlos en DevTools.

fetch('https://jsonplaceholder.typicode.com/posts', {
  headers: {
    'X-Custom-Header': 'salvacode',
    'Accept': 'application/json',
    'X-Request-Source': 'exercise-01'
  }
})

Tasks

Task 1: Header personalizado simple

Fetch a /posts con el header 'X-Custom-Header': 'salvacode'. Abre DevTools → Network y verifica que el header aparece en la petición.

Task 2: Header Accept

Fetch con 'Accept': 'application/json'. Compara la respuesta con y sin este header.

Task 3: Múltiples headers

Fetch con 3 headers personalizados simultáneos. Muestra todos los headers enviados en el DOM.

Task 4: Inspección en DevTools

Instrucciones: Abre DevTools (F12) → pestaña Network → haz una petición → haz click en la petición → pestaña Headers → busca "Request Headers". ¿Ves tus headers custom?

Task 5: Función fetchConHeaders

Crea una función fetchConHeaders(url, customHeaders) que mergear headers por defecto con los que el usuario pase.
