Headers, Autenticación y Seguridad

Exercise 02: Simular Login con Token

Crea un formulario de login, guarda el token en localStorage, y crea funciones para leerlo.

Formulario de Login (Simulado)

Tasks

Task 1: Capturar credenciales del formulario

Al hacer click en Login, captura los valores de usuario y contraseña.

Task 2: POST simulado

Envía un POST a /posts (mock) con las credenciales. Simula la respuesta con un token ficticio.

Task 3: Guardar token en localStorage

Guarda el token con timestamp para poder verificar expiración después.

Task 4: getAuthHeaders()

Crea una función que lea el token de localStorage y retorne el header Authorization.

Task 5: isAuthenticated()

Crea una función que verifique si el token existe y no ha expirado (TTL de 1 hora).
