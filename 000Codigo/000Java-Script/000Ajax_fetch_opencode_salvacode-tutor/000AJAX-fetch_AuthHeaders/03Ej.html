Headers, Autenticación y Seguridad

Exercise 03: Peticiones con Token

Envía peticiones autenticadas usando el token guardado en localStorage.

Tasks

Task 1: fetchAuth() con GET

Crea fetchAuth(url, options) que añada el Authorization header automáticamente. Úsalo para GET /users.

Task 2: fetchAuth() con POST

Usa fetchAuth para hacer un POST a /posts con body.

Task 3: Mostrar headers en DOM

Muestra los headers que se enviarían en cada petición.

Task 4: Verificar autenticación previa

Si no hay token, mostrar mensaje "Inicia sesión primero" (con link al Ejercicio 02).
