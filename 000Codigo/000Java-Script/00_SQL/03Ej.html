Exercise 03: UPDATE and DELETE Records

Learn to modify existing records and safely delete entries from your tables while tracking how many changes were made.

Your Tasks

Task 1: Update user email

Update Bob's email from bob@example.com to bob.smith@example.com. Log the number of database changes using info.changes.

Task 2: Increase product prices (Inflation)

Increase the price of all products in the electronics category by 10%. (Hint: use price * 1.1 in your update query).

Task 3: Safely restock item

Add 15 items to the stock of Jeans. (Hint: stock = stock + ?).

Task 4: Delete users by age limit

Delete users who are under 25 years old. Log how many users were removed.

Task 5: Delete out-of-stock products

Delete products that have a stock of 0. Ensure you check how many rows were affected.

💡 Key Hints
  • Statements like UPDATE and DELETE use stmt.run(...) and return metadata: { changes: number, lastInsertRowid: number }.
  • Always use a WHERE clause in UPDATE and DELETE statements! Omitting it will update or delete every single row in the table.

Expected Terminal Output

=== Task 1: Update Bob's email ===
Bob's email updated. Changes: 1

=== Task 2: Increase electronics prices by 10% ===
Prices increased. Affected items: 3

=== Task 3: Restock Jeans ===
Jeans restocked. Affected items: 1

=== Task 4: Delete users under 25 ===
Deleted users. Count: 1

=== Task 5: Delete out-of-stock products ===
Deleted products. Count: 1
