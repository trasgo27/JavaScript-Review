Exercise 06: Build a CLI Todo List with SQLite

Combine your JavaScript CLI logic (using Node's readline) with SQLite queries to build a persistent command-line application.

App Specification

The application should store tasks in a todos table with columns: id, task, and completed (0 for false, 1 for true).

Interactive Commands

  • add <task name> — Inserts a new uncompleted task.
  • list — Lists all tasks with their completion status.
  • complete <id> — Marks a task as completed (updates completed to 1).
  • delete <id> — Deletes a task by ID.
  • exit — Closes the database and exits the application.

Your Tasks

Task 1: Table Initialization

Initialize the todos table inside `06Ej.js`. Ensure columns use appropriate data types (e.g., completed INTEGER DEFAULT 0).

Task 2: Implement listTasks()

Write a function to read all rows from the database and print them nicely to the terminal. If the database is empty, display a friendly message.

Task 3: Implement addTask(name)

Write the statement to insert a task. Log a confirmation message showing the new ID.

Task 4: Implement completeTask(id)

Update the status of a task. Verify if the task actually existed (check changes === 0 to handle invalid IDs).

Task 5: Implement deleteTask(id)

Delete the row from the database. Output a message indicating success or failure.

💡 Readline Integration

We've already set up the readline interface in the template. Focus on replacing the SQL comments with active statements inside each function block!
