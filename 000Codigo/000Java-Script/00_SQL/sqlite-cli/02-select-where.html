02 — SELECT & WHERE

Filter data with conditions, pattern matching, and ranges.

Database file: store.db. First copy-paste the seed SQL below to populate it.

Step 0: Seed the Database

Run this entire block to create tables and insert sample data:

sqlite3 store.db
-- Then copy-paste this inside the sqlite> prompt:
CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  email TEXT NOT NULL UNIQUE,
  age INTEGER
);

CREATE TABLE products (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT,
  price REAL,
  stock INTEGER DEFAULT 0,
  category TEXT
);

Set pretty mode: .mode column and .headers on

Task 1: SELECT All Users

SELECT * FROM users;

Task 2: SELECT Specific Columns

SELECT name, email FROM users;

Task 3: WHERE with Comparison

SELECT * FROM users WHERE age > 25;

Task 4: WHERE with LIKE (Pattern Matching)

SELECT name, email FROM users WHERE email LIKE '%@gmail.com';

% matches any sequence of characters.

Task 5: WHERE with BETWEEN (Range)

SELECT name, price FROM products WHERE price BETWEEN 20 AND 100;

Task 6: WHERE with IN (Multiple Values)

SELECT * FROM products WHERE category IN ('electronics', 'books');

Task 7: AND / OR Logic

-- Electronics OR cheap products, with stock available
SELECT * FROM products
WHERE (category = 'electronics' OR price < 50)
  AND stock > 0;

Task 8: DISTINCT (Unique Values)

SELECT DISTINCT category FROM products;
