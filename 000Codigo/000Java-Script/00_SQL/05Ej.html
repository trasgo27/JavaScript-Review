Exercise 05: JOIN Two Tables

Practice writing queries that draw relations between tables using INNER JOIN, LEFT JOIN, and multiple joins to compile structured, relational reports.

Your Tasks

Task 1: Inner Join users and orders

Find which users placed orders. Query should return: order_id, user_name, and quantity.

Task 2: Left Join users and orders

Retrieve all users and any order details they have. If a user hasn't ordered anything, the order details should show NULL (which JS retrieves as null).

Task 3: Joining 3 tables

Connect orders, users, and products to list all orders. Return: order_id, user_name, product_name, quantity, and the calculated total_price (calculated as quantity * price).

Task 4: High-purchasing users

Find the names of users who have spent more than $100 in total across all their orders. (Hint: Use JOIN, GROUP BY users.id, and HAVING SUM(quantity * price) > 100).

💡 Key Hints
  • Use table aliases to keep queries clean: FROM orders o JOIN users u ON o.user_id = u.id.
  • To reference columns with matching names from different tables (like id or name), qualify them explicitly: u.name AS user_name, p.name AS product_name.
