SQLite + JS Mastery

Exercise 01: CREATE TABLE & INSERT

Practice creating tables and inserting data using better-sqlite3 in Node.js.

const Database = require('better-sqlite3');
const db = new Database('ex01.db');

db.exec('CREATE TABLE IF NOT EXISTS ...');
const stmt = db.prepare('INSERT INTO ... VALUES (?, ?)');
stmt.run(val1, val2);

Setup

const Database = require('better-sqlite3');
const db = new Database('ex01.db');

Tasks

Task 1: Create a users table

Create a table called users with columns: id (INTEGER PRIMARY KEY AUTOINCREMENT), name (TEXT NOT NULL), email (TEXT NOT NULL UNIQUE), age (INTEGER).

Task 2: Insert single user

Insert one user: name "Alice", email "alice@example.com", age 30. Use db.prepare().run().

Task 3: Insert multiple users

Insert at least 5 users in a loop using an array of objects and stmt.run() inside a transaction:

const insert = db.prepare('INSERT INTO users ...');
const many = db.transaction((users) => {
    for (const u of users) insert.run(...);
});

Task 4: Insert with RETURNING

Insert a user and retrieve the inserted id using stmt.run().lastInsertRowid. Log the new ID.

Task 5: Handle UNIQUE violation

Try inserting a duplicate email. Catch the error and log a friendly message instead of crashing.

try {
    insert.run(...);
} catch (err) {
    console.log('Duplicate email:', err.message);
}

Task 6: Create a products table

Create a table called products with columns: id (INTEGER PRIMARY KEY AUTOINCREMENT), name (TEXT), price (REAL), stock (INTEGER DEFAULT 0), category (TEXT).

Task 7: Bulk insert products

Insert 8 products across 4 categories (electronics, clothing, food, books). Use a transaction.

Task 8: Insert with DEFAULT values

Insert a product with only name and price, letting stock default to 0. Verify with a SELECT.

Task 9: Create an orders table

Create an orders table with: id (INTEGER PRIMARY KEY AUTOINCREMENT), user_id (INTEGER), product_id (INTEGER), quantity (INTEGER), order_date (TEXT DEFAULT CURRENT_DATE). Use FOREIGN KEY constraints.

Task 10: Insert related data

Insert 5 orders linking existing users and products. Each order must have a valid user_id and product_id. Handle foreign key violations gracefully.

English Challenge

Write 2–3 sentences explaining the difference between db.exec() and db.prepare().run(). When would you use each?

Reference

// Run SQL directly (no placeholders)
db.exec('CREATE TABLE ...');

// Prepare a statement (with ? placeholders)
const stmt = db.prepare('INSERT INTO t (col) VALUES (?)');
stmt.run(value);           // insert one
const info = stmt.run(v);  // returns { changes, lastInsertRowid }
console.log(info.lastInsertRowid);

// Transaction (atomic batch)
const insertMany = db.transaction((items) => {
    for (const item of items) stmt.run(item);
});

// Catch errors
try { stmt.run(val); } catch (e) { console.log(e.message); }
