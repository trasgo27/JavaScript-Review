Good attempt, trasgo. The main issue is that entries in a `Map` are arrays, not objects with a `.value` property.

When you do:

```javascript
[...recuento]
```

you get something like:

```javascript
[
  ["A", 3],
  ["B", 2],
  ["C", 1]
]
```

Each element is:

```javascript
[key, value]
```

So:

```javascript
a.value
```

doesn't exist.

### Correct version

To sort by the count (the value):

```javascript
const recuentoAsc = [...recuento].sort((a, b) => {
    return a[1] - b[1];
});

console.log("Ord Ascendente:", recuentoAsc);
```

Or more concisely:

```javascript
const recuentoAsc = [...recuento].sort((a, b) => a[1] - b[1]);
```

### Even better: destructuring

Since each entry is `[key, value]`, you can write:

```javascript
const recuentoAsc = [...recuento].sort(
    ([, valorA], [, valorB]) => valorA - valorB
);
```

The commas mean:

```javascript
[key, value]
```

but we're ignoring the key.

### Example

Given:

```javascript
Map {
  "A" => 3,
  "B" => 2,
  "C" => 1
}
```

After sorting:

```javascript
[
  ["C", 1],
  ["B", 2],
  ["A", 3]
]
```
