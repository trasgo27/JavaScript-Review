# Funcionalidades de salvacode-tutor

## 1. Creación de Ejercicios de Programación

### 1.1 Niveles de Dificultad
- **Principiante**: Ejercicios básicos con pistas detalladas y pseudocódigo extenso
- **Intermedio**: Ejercicios que requieren combinar múltiples conceptos
- **Avanzado**: Ejercicios complejos con menos pistas, más autonomía

### 1.2 Estructura de Archivos (4 Niveles)

```
NIVEL 1: index.html raiz
    └── Tarjetas con links a cada módulo
    
NIVEL 2: Carpetas de módulos (00-NombreModulo/)
    └── index.html hub interno con links a ejercicios
    
NIVEL 3: Parejas nEj.html + nEj.js
    ├── HTML: Enunciado + Tasks + Toggle solución
    └── JS: Workspace interactivo con espacios para completar
    
NIVEL 4: Interior del .js
    ├── Cabecera identificadora
    ├── Función hacerEj() wrapper
    ├── Pistas detalladas con pseudocódigo
    └── Marcadores /* Tu codigo aqui */
```

### 1.3 Formato de Ejercicios
- **Enunciado claro**: Descripción del concepto a practicar
- **Tasks numeradas**: Instrucciones paso a paso
- **Toggle de solución**: `<details>` expandible con código completo
- **Archivo .js interactivo**: Donde el estudiante ESCRIBE código

## 2. Creación de Sílabos y Materiales de Aprendizaje

### 2.1 Cursos Completos
- Múltiples módulos temáticos
- Progresión lógica de dificultad
- API por defecto: `jsonplaceholder.typicode.com`
- Títulos en español

### 2.2 Estructura de 4 Niveles (Jerarquía)

```
000MiCurso/
├── index.html              ← NIVEL 1: Root hub principal
├── 01-PrimerosPasos/       ← NIVEL 2: Carpeta módulo
│   ├── index.html          ← Hub del módulo
│   ├── 01Ej.html           ← NIVEL 3: Ejercicio HTML
│   └── 01Ej.js             ← NIVEL 4: JS con pistas
└── 02-TemasIntermedios/
```

### 2.3 Contenido Progresivo
- **Módulo 01**: Conceptos fundamentales
- **Módulo 02**: Temas intermedios
- **Módulo 03+**: Proyectos integradores

## 3. Debug y Análisis de Código

### 3.1 Identificación de Bugs
- **`grep`**: Buscar patrones específicos en archivos
- **`read`**: Leer archivos completos para análisis
- **`glob`**: Encontrar archivos por nombre/patrón

### 3.2 Reportes Detallados
- Ubicación exacta del error (archivo, línea)
- Descripción del problema
- Explicación de por qué ocurre
- Sugerencias de corrección

### 3.3 Correcciones con Explicaciones
- Corregir código existente
- Explicar cada cambio realizado
- Mantener la funcionalidad original

---

## 4. Módulo de Teoría (TEORIA)

### 4.1 Tutor Interactivo
- 3 preguntas, 1 a la vez
- Feedback inmediato tras cada respuesta
- Conceptos teóricos profundos
- Mezcla de opción múltiple y análisis de código

### 4.2 Autoevaluación de Código
- Analiza tu código personalizado
- 3 preguntas basadas en TU código
- Solucionario oculto bajo spoiler

### 4.3 Simulador de Entrevista Técnica
- Rol de entrevistador senior
- 3 preguntas exigentes de golpe
- Código con "trampa" para predecir salida
- Evaluación de 1 a 10 con feedback técnico
