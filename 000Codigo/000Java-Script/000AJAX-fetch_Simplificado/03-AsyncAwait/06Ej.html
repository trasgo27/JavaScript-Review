Ejercicio 06: Promise.allSettled

Manejo de exitos y fallos parciales

Contexto

Promise.all es potente, pero tiene un problema: si UNA sola promesa falla, TODO falla.

Promise.allSettled es la alternativa segura: NUNCA falla. En cambio, retorna el estado de cada promesa:

Estructura del resultado: 
{
  status: 'fulfilled',   // o 'rejected'
  value: Response        // si fue exitoso
  reason: Error          // si fallo
}
Diferencia clave: Si tu necesitas que TODOS los fetch tengan exito, usa Promise.all. Si quieres manejar exitos y fallos individualmente, usa Promise.allSettled.

Tareas 4 tareas

Task 1: Crear array de URLs

Crea un array con 3 URLs validas y 1 URL que podria fallar (userId=999).

const urls = [
  'https://jsonplaceholder.typicode.com/users/1',  // valida
  'https://jsonplaceholder.typicode.com/users/2',  // valida
  'https://jsonplaceholder.typicode.com/users/3',  // valida
  'https://jsonplaceholder.typicode.com/users/999' // podria fallar
];

Task 2: Promise.allSettled

Ejecuta Promise.allSettled con los fetch de todas las URLs.

const resultados = await Promise.allSettled(
  urls.map(url => fetch(url))
);
console.log(resultados);

Task 3: Contar exitos y fallos

Recorre los resultados y cuenta cuantos tienen status: 'fulfilled' vs 'rejected'.

let exitos = 0, fallos = 0;
resultados.forEach(r => {
  if (r.status === 'fulfilled') exitos++;
  else fallos++;
});
console.log('Exitos:', exitos, '| Fallos:', fallos);

Task 4: Mostrar usuarios exitosos

Filtra solo los exitosos y convierte sus Response a JSON.

const exitosos = resultados
  .filter(r => r.status === 'fulfilled')
  .map(r => r.value);

const usuarios = await Promise.all(
  exitosos.map(resp => resp.json())
);
usuarios.forEach(u => console.log(u.name));

async function main() {
  const urls = [
    'https://jsonplaceholder.typicode.com/users/1',
    'https://jsonplaceholder.typicode.com/users/2',
    'https://jsonplaceholder.typicode.com/users/3',
    'https://jsonplaceholder.typicode.com/users/999'
  ];

  console.log('--- Task 2: Promise.allSettled ---');
  const resultados = await Promise.allSettled(
    urls.map(url => fetch(url))
  );
  console.log('Resultados crudos:', resultados);

  console.log('\n--- Task 3: Contar exitos y fallos ---');
  let exitos = 0, fallos = 0;
  resultados.forEach(r => {
    if (r.status === 'fulfilled') exitos++;
    else fallos++;
  });
  console.log('Exitos:', exitos, '| Fallos:', fallos);

  console.log('\n--- Task 4: Usuarios exitosos ---');
  const exitosos = resultados
    .filter(r => r.status === 'fulfilled')
    .map(r => r.value);

  const usuarios = await Promise.all(
    exitosos.map(resp => resp.json())
  );

  console.log('=== Usuarios exitosos ===');
  usuarios.forEach(u => console.log(u.name));
}

main();

Abre la consola (F12) para ver los resultados.
