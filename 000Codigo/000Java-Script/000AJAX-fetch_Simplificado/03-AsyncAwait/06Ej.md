## Bugs Encontrados

### Bug 1: Strings en vez de Promises (líneas 44-49)

```javascript
const peticiones1 = await Promise.allSettled([
    'https://jsonplaceholder.typicode.com/users/1',  // ❌ String
    'https://jsonplaceholder.typicode.com/users/2',  // ❌ String
    'https://jsonplaceholder.typicode.com/users/3',  // ❌ String
    'https://jsonplaceholder.typicode.com/users/999' // ❌ String
]);
```

**Problema:** `Promise.allSettled` espera un array de **Promises** (`fetch()`), no strings.

**Corrección:**
```javascript
const peticiones1 = await Promise.allSettled([
    fetch('https://jsonplaceholder.typicode.com/users/1'),  // ✅ Promise
    fetch('https://jsonplaceholder.typicode.com/users/2'),
    fetch('https://jsonplaceholder.typicode.com/users/3'),
    fetch('https://jsonplaceholder.typicode.com/users/999')
]);
```

---

### Bug 2: Arrow function sin `return` (líneas 91-93)

```javascript
const resultados10 = await Promise.allSettled(
    urls.map((url)=>{fetch(url)})  // ❌ Sin return
);
```

**Problema:** Con `{}` pero sin `return`, la función retorna `undefined`.

**Corrección:**
```javascript
const resultados10 = await Promise.allSettled(
    urls.map((url) => fetch(url))  // ✅ Return implícito
);
```

---

### Bug 3: Filter con parámetros incorrectos (líneas 168-170)

```javascript
const exitosos = resultados.filter((acc, pres) => {
    (pres === 'fulfilled') ? acc + pres : acc;  // ❌ Parámetros equivocados
}, []);
```

**Problema:**
1. `.filter()` recibe `(elemento, índice, array)` — no `(acumulador, valor)`
2. `pres` es el **índice** (0, 1, 2...), no el `status`
3. No hay `return` — retorna `undefined`

**Corrección:**
```javascript
const exitosos = resultados.filter((r) => r.status === 'fulfilled');
```

---

### Bug 4: Promise sin resolver (líneas 173-178)

```javascript
const usuarios = exitosos.map((item) => {
    return item.json();  // ❌ Retorna Promise, no datos
});

usuarios.forEach(u => console.log(u.name));  // ❌ u es Promise, no objeto
```

**Problema:** `.json()` retorna una Promise. Necesitas `await Promise.all()` para resolverlas.

**Corrección:**
```javascript
const usuarios = await Promise.all(
    exitosos.map((item) => item.json())
);
usuarios.forEach(u => console.log(u.name));
```

## Código Corregido

```javascript
console.log('=== Ejercicio 06: Promise.allSettled — Exitos y fallos parciales ===');

function hacerEj(taskName, taskFunction) {
    console.log(`\n--- ${taskName} ---`);
    try { taskFunction(); } catch (error) { console.error(`Error:`, error); }
}

async function main() {
  try {
    const urls = [
      'https://jsonplaceholder.typicode.com/users/1',
      'https://jsonplaceholder.typicode.com/users/2',
      'https://jsonplaceholder.typicode.com/users/3',
      'https://jsonplaceholder.typicode.com/users/999'
    ];

    // TAREA 1 & 2: Promise.allSettled
    console.log('--- Tarea 1-2: Promise.allSettled ---');
    const resultados = await Promise.allSettled(
      urls.map((url) => fetch(url))
    );
    console.log('Resultados crudos:', resultados);

    // TAREA 3: Contar éxitos y fallos
    console.log('--- Tarea 3: Contar éxitos y fallos ---');
    let exitos = 0;
    let fallos = 0;
    resultados.forEach((r) => {
      if (r.status === 'fulfilled') exitos++;
      else fallos++;
    });
    console.log('Exitos:', exitos, '| Fallos:', fallos);

    // TAREA 4: Filtrar y mostrar exitosos
    console.log('--- Tarea 4: Usuarios exitosos ---');
    const exitosos = resultados.filter((r) => r.status === 'fulfilled');
    const usuarios = await Promise.all(
      exitosos.map((r) => r.value.json())
    );
    console.log('=== Usuarios exitosos ===');
    usuarios.forEach((u) => console.log(u.name));

  } catch (error) {
    console.error('Error:', error);
  }
}

main();
```

## Conceptos Clave

| Original | Corregido |
|----------|-----------|
| `Promise.allSettled(['url1', 'url2'])` | `Promise.allSettled([fetch('url1'), fetch('url2')])` |
| `.map((url) => {fetch(url)})` | `.map((url) => fetch(url))` |
| `.filter((acc, pres) => ...)` | `.filter((r) => r.status === 'fulfilled')` |
| `.map(r => r.value.json())` | `await Promise.all(.map(r => r.value.json()))` |

# Bug Adicional: "Body is unusable: Body has already been read"

## Error encontrado al ejecutar

```
TypeError: Body is unusable: Body has already been read
    at consumeBody (node:internal/deps/undici/undici:6405:31)
    at _Response.json (node:internal/deps/undici/undici:6356:18)
```

## Causa

Los objetos **Response** de `fetch()` solo pueden leerse **una vez**. Si intentas llamar `.json()` o `.text()` dos veces sobre el mismo Response, obtienes este error.

```javascript
const response = await fetch(url);
await response.json();  // ✅ Primera lectura
await response.json();  // ❌ Body is unusable: Body has already been read
```

## Solución: Re-fetch directamente

En lugar de reutilizar el Response, vuelve a hacer fetch con la URL:

```javascript
// ❌ Error: Reusar Response
const resultados = await Promise.allSettled(urls.map(url => fetch(url)));
const exitosos = resultados.filter(r => r.status === 'fulfilled');
const usuarios = await Promise.all(exitosos.map(r => r.value.json())); // Error

// ✅ Correcto: Extraer URLs y re-fetch
const urlsExitosas = resultados
    .filter(r => r.status === 'fulfilled')
    .map(r => r.value.url);  // Extraer solo la URL

const usuarios = await Promise.all(
    urlsExitosas.map(url => fetch(url).then(r => r.json()))  // Re-fetch
);
```
