Ejercicio 07: Async iterators

for await...of para iterar sobre multiples fetch

Contexto

A veces necesitas procesar multiples recursos uno por uno, en orden. El for...of con await te permite iterar sobre un array y hacer await en cada iteracion.

for...of con await es SECUENCIAL: espera a que termine cada fetch antes de empezar el siguiente.

Promise.all es PARALELO: lanza todos los fetch al mismo tiempo.

¿Cual usar? Depende: si el orden no importa, usa Promise.all (es mas rapido). Si necesitas el orden, usa for...of.

Tareas 4 tareas

Task 1: Crear array de URLs

Crea un array con 3 URLs de usuarios.

const urls = [
  'https://jsonplaceholder.typicode.com/users/1',
  'https://jsonplaceholder.typicode.com/users/2',
  'https://jsonplaceholder.typicode.com/users/3'
];

Task 2: for...of SIN await (diferencia clave)

Observa que fetch() sin await retorna una Promesa pendiente, no el resultado.

for (const url of urls) {
  const promesa = fetch(url);  // Sin await!
  console.log(url, '->', promesa);  // Promise {}
}

Task 3: for...of CON await (secuencial)

Ahora agrega await para que cada fetch termine antes del siguiente.

for (const url of urls) {
  const resp = await fetch(url);    // Espera la respuesta
  const data = await resp.json();   // Espera el JSON
  console.log(data.name);           // Muestra el nombre
}

Task 4: Acumular resultados en un array

Crea un array vacio y haz push de cada resultado.

const usuarios = [];
for (const url of urls) {
  const resp = await fetch(url);
  const data = await resp.json();
  usuarios.push(data);
}
console.log('Total:', usuarios.length);

console.log('=== Ejercicio 07: Async iterators ===');

async function main() {
  const urls = [
    'https://jsonplaceholder.typicode.com/users/1',
    'https://jsonplaceholder.typicode.com/users/2',
    'https://jsonplaceholder.typicode.com/users/3'
  ];

  console.log('--- Task 2: for...of SIN await ---');
  for (const url of urls) {
    const promesa = fetch(url);
    console.log(url, '->', promesa);  // Promise {}
  }

  console.log('\n--- Task 3: for...of CON await ---');
  for (const url of urls) {
    const resp = await fetch(url);
    const usuario = await resp.json();
    console.log('Usuario:', usuario.name);
  }

  console.log('\n--- Task 4: Acumular resultados ---');
  const usuarios = [];
  for (const url of urls) {
    const resp = await fetch(url);
    const usuario = await resp.json();
    usuarios.push(usuario);
  }
  console.log('=== Todos los usuarios ===');
  console.log('Total:', usuarios.length);
  usuarios.forEach(u => console.log('-', u.name, '(' + u.email + ')'));
}

main();

Abre la consola (F12) para ver los resultados.
