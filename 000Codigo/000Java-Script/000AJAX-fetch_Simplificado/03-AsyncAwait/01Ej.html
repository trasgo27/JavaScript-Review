Módulo 03: Async/Await

Ejercicio 01: De .then() a async/await

Convierte una cadena de .then() en código async/await equivalente.

Tareas

Tarea 1: Versión con .then()

Escribe un fetch con cadena .then() para obtener el usuario 1 de la API y mostrarlo en consola.

Tarea 2: Reescribir con async/await

Escribe la misma lógica pero usando async/await. Debe producir el mismo resultado.

Tarea 3: Comparar ambos estilos

Ambos métodos están llamados en consola. Observa que producen el mismo resultado con sintaxis diferente.

Abre la consola (F12) para ver los resultados.
