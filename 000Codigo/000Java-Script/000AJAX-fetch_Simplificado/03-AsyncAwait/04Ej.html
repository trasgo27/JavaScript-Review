Ejercicio 04: Debugging async/await

Encuentra y corrige los bugs en código async/await

Contexto

El siguiente código tiene 8 bugs. Tu trabajo es:

  1. Leer el código y entender qué intenta hacer
  2. Identificar cada bug (hay una pista por cada uno)
  3. Escribir la versión corregida en el archivo 04Ej.js

    });

  console.log('--- Tarea 3 ---');

obtenerDatos();

Pistas por cada bug lee antes de intentar

Bug 1 — Línea fetchUsuario: ¿Por qué crear una función async interna si la función padre ya es async?
Bug 2 — Línea fetchUsuario().then(): Si estás dentro de una función async, ¿por qué usas .then() en vez de await?
Bug 3 — Línea albumCount = await r.json(): Estás creando una variable global por accidente. Busca el operador de asignación en el return.
Bug 4 — Línea albumes().then(): Mismo problema que Bug 2. Estás mezclando .then() con async/await.
Bug 5 — La tarea 2 nunca espera a que termine antes de seguir: Las líneas de la Tarea 3 se ejecutan antes de que la Tarea 2 termine.
Bug 6 — Tarea 3 está vacía: Falta implementar la lógica para obtener fotos del primer album.
Bug 7 — usuario no existe en el scope de Tarea 4: La variable usuario está atrapada dentro del .then() y no se puede usar fuera.
Bug 8 — albumCount no existe en Tarea 4: Es una variable global creada accidentalmente dentro de la función albumes(). Nunca es confiable.

async function obtenerDatos() {
  try {
    // ── TAREA 1: Obtener usuario ──
    console.log('--- Tarea 1 ---');
    const respUsuario = await fetch('https://jsonplaceholder.typicode.com/users/1');
    const usuario = await respUsuario.json();
    console.log('Usuario:', usuario);

    // ── TAREA 2: Obtener albumes del usuario ──
    console.log('--- Tarea 2 ---');
    const respAlbumes = await fetch(
      'https://jsonplaceholder.typicode.com/albums?userId=' + usuario.id
    );
    const albumes = await respAlbumes.json();
    console.log('Albumes:', albumes);

    // ── TAREA 3: Obtener fotos del primer album ──
    console.log('--- Tarea 3 ---');
    const primerAlbum = albumes[0];
    const respFotos = await fetch(
      'https://jsonplaceholder.typicode.com/photos?albumId=' + primerAlbum.id
    );
    const fotos = await respFotos.json();
    console.log('Fotos del album "' + primerAlbum.title + '":', fotos);

    // ── TAREA 4: Mostrar resumen ──
    console.log('--- Tarea 4 ---');
    console.log(
      usuario.name + ' tiene ' + albumes.length + ' albumes'
    );

  } catch (error) {
    console.error('Error:', error);
  }
}

obtenerDatos();
