Ejercicio 05: Promise.all

Multiples fetch en paralelo con Promise.all

Contexto

Hasta ahora has hecho fetch secuencialmente: primero obtienes un dato, luego otro. Pero... ¿que pasa si necesitas 3 recursos que no dependen entre si?

Promise.all() recibe un array de promesas y las ejecuta simultaneamente. Cuando TODAS terminan, retorna un array con los resultados.

Ventaja: Si cada fetch tarda 500ms, hacer 3 secuencialmente = 1500ms. Con Promise.all = 500ms.

Tareas 5 tareas

Task 1: Obtener usuario con id=1

Usa await fetch() para obtener el usuario de la API.

const resp = await fetch('https://jsonplaceholder.typicode.com/users/1');
const usuario = await resp.json();
console.log('Usuario:', usuario.name);

Task 2: Obtener posts del usuario

Usa el filtro ?userId=1 para obtener sus publicaciones.

const resp = await fetch('https://jsonplaceholder.typicode.com/posts?userId=1');
const posts = await resp.json();
console.log('Posts:', posts.length, 'publicaciones');

Task 3: Obtener albums del usuario

Mismo patron que Task 2 pero con albums.

const resp = await fetch('https://jsonplaceholder.typicode.com/albums?userId=1');
const albums = await resp.json();
console.log('Albums:', albums.length, 'albumes');

Task 4: Promise.all en paralelo

Ahora combina los 3 fetch en un solo Promise.all. Recuerda:

  1. Primero lanza los 3 fetch (sin await)
  2. Luego convierte todos a JSON con otro Promise.all
const [resp1, resp2, resp3] = await Promise.all([
  fetch(url1), fetch(url2), fetch(url3)
]);
const [data1, data2, data3] = await Promise.all([
  resp1.json(), resp2.json(), resp3.json()
]);

Task 5: Mostrar resumen

Muestra un resumen con el nombre del usuario, cantidad de posts y albums.

Ver solucion completa (click para expandir) 
console.log('=== Ejercicio 05: Promise.all ===');

async function main() {
  console.log('--- Task 1-3: Fetch secuencial (lento) ---');
  const respUsuario = await fetch('https://jsonplaceholder.typicode.com/users/1');
  const usuario = await respUsuario.json();
  console.log('Usuario:', usuario.name);

  const respPosts = await fetch('https://jsonplaceholder.typicode.com/posts?userId=1');
  const posts = await respPosts.json();
  console.log('Posts:', posts.length, 'publicaciones');

  const respAlbums = await fetch('https://jsonplaceholder.typicode.com/albums?userId=1');
  const albums = await respAlbums.json();
  console.log('Albums:', albums.length, 'albumes');

  console.log('\n--- Task 4: Promise.all en paralelo (rapido) ---');
  const [rU, rP, rA] = await Promise.all([
    fetch('https://jsonplaceholder.typicode.com/users/1'),
    fetch('https://jsonplaceholder.typicode.com/posts?userId=1'),
    fetch('https://jsonplaceholder.typicode.com/albums?userId=1')
  ]);
  const [user, postsArr, albumsArr] = await Promise.all([
    rU.json(), rP.json(), rA.json()
  ]);
  console.log('Promise.all completado!');

  console.log('\n--- Task 5: Resumen ---');
  console.log('=== RESUMEN ===');
  console.log('Usuario:', user.name);
  console.log('Posts:', postsArr.length, 'publicaciones');
  console.log('Albums:', albumsArr.length, 'albumes');
}

main();

Abre la consola (F12) para ver los resultados.
