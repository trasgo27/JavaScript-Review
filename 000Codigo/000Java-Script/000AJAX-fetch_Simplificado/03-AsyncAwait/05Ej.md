## Bugs Encontrados

### Bug 1: Promise.all no convierte a JSON correctamente (líneas 105-111)

```javascript
let vector = [];
vector = await [
    respUsuario.json(), 
    respPosts.json(), 
    respAlbums.json()
] ;
```

**Problemas:**
1. `await [...]` **no funciona** — las promesas dentro del array no se resuelven
2. Necesitas `await Promise.all([...])` para esperar todas las promesas
3. `vector` contiene objetos Promise pendientes, no datos resueltos

**Corrección:**
```javascript
const [usuario, posts, albums] = 
await Promise.all([
    respUsuario.json(),
    respPosts.json(),
    respAlbums.json()
]);
```

## Código Corregido

```javascript
console.log('=== Ejercicio 05: Promise.all — Multiples fetch en paralelo ===');

function hacerEj(taskName, taskFunction) {
    console.log(`\n--- ${taskName} ---`);
    try { taskFunction(); } catch (error) { console.error(`Error:`, error); }
}

async function main() {
  try {
    // TAREA 1-3: Fetch secuencial (ya correctas)
    console.log('--- Tarea 1: Obtener usuario ---');
    const respUsuario = await fetch('https://jsonplaceholder.typicode.com/users/1');
    const usuario = await respUsuario.json();
    console.log('Usuario:', usuario.name);

    console.log('--- Tarea 2: Obtener posts ---');
    const respPosts = await fetch('https://jsonplaceholder.typicode.com/posts?userId=1');
    const posts = await respPosts.json();
    console.log('Posts:', posts.length, 'publicaciones');

    console.log('--- Tarea 3: Obtener albums ---');
    const respAlbums = await fetch('https://jsonplaceholder.typicode.com/albums?userId=1');
    const albums = await respAlbums.json();
    console.log('Albums:', albums.length, 'albumes');

    // TAREA 4: Promise.all en paralelo
    console.log('--- Tarea 4: Promise.all ---');
    const [rU, rP, rA] = await Promise.all([
      fetch('https://jsonplaceholder.typicode.com/users/1'),
      fetch('https://jsonplaceholder.typicode.com/posts?userId=1'),
      fetch('https://jsonplaceholder.typicode.com/albums?userId=1')
    ]);
    const [user, postsArr, albumsArr] = await Promise.all([
      rU.json(), rP.json(), rA.json()
    ]);
    console.log('✅ Promise.all completado!');

    // TAREA 5: Resumen
    console.log('--- Tarea 5: Resumen ---');
    console.log('=== RESUMEN ===');
    console.log('Usuario:', user.name);
    console.log('Posts:', postsArr.length, 'publicaciones');
    console.log('Albums:', albumsArr.length, 'albumes');

  } catch (error) {
    console.error('Error:', error);
  }
}

main();
```

## Conceptos Clave

| Original | Corregido |
|----------|-----------|
| `await [promise1, promise2]` | `await Promise.all([promise1, promise2])` |
| `let vector = []; vector = await [...]` | `const [a, b] = await Promise.all([...])` |
| Código fuera de funciones | Todo dentro de `try/catch` |

### Promise.all - Flujo correcto:

```javascript
// Paso 1: Lanzar fetch simultáneamente
const [resp1, resp2, resp3] = await Promise.all([
  fetch(url1), fetch(url2), fetch(url3)
]);

// Paso 2: Convertir todos a JSON
const [data1, data2, data3] = await Promise.all([
  resp1.json(), resp2.json(), resp3.json()
]);
```
