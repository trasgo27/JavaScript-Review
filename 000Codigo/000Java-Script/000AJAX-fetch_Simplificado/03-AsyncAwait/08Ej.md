## Error 1: Código duplicado con múltiples errores de variable

**Ubicación:** Líneas 43-61 (código duplicado FUERA de la tarea)

**Código con error:**
```javascript
async function fetchConTimeout(url, timeout = 3000) {
    const controlador = new AbortController();
    const señal = controlador.signal;        // ← Variable "señal"
    const tiempo = setTimeout(()=>
        controlador.abort(), timeout);
    try{
        const respuesta = await fetch(url,{signal});  // ← ERROR: usa "signal" pero la variable es "señal"
        clearTimeout(timer);                           // ← ERROR: usa "timer" pero la variable es "tiempo"
        return await respuesta.json();
    }
    catch (err){
        clearTimeout(tiempo);
        if(error.name === 'Error Aborto Tiempo'){     // ← ERROR: usa "error" pero el parámetro es "err"
            console.log('Timeout: La petición tardo demasiado ...');
        }
        throw error;                                  // ← ERROR: usa "error" pero el parámetro es "err"
    }
}
```

**Problemas:**
1. **Línea 45:** Se declara `señal` pero se usa `signal` en línea 50
2. **Línea 51:** Se usa `timer` pero la variable se llama `tiempo`
3. **Línea 56:** Se usa `error` pero el parámetro del catch es `err`
4. **Línea 59:** Se usa `error` pero el parámetro del catch es `err`
5. **Línea 56:** El nombre del error es incorrecto (`'Error Aborto Tiempo'` vs `'AbortError'`)

**Corrección:**
```javascript
async function fetchConTimeout(url, timeout = 3000) {
    const controlador = new AbortController();
    const signal = controlador.signal;        // ← Cambiar "señal" por "signal"
    const tiempo = setTimeout(()=>
        controlador.abort(), timeout);
    try{
        const respuesta = await fetch(url,{signal});  // ← Ahora coincide con la variable
        clearTimeout(tiempo);                           // ← Cambiar "timer" por "tiempo"
        return await respuesta.json();
    }
    catch (err){
        clearTimeout(tiempo);
        if(err.name === 'AbortError'){                  // ← Cambiar "error" por "err" y corregir nombre
            console.log('Timeout: La petición tardo demasiado ...');
        }
        throw err;                                      // ← Cambiar "error" por "err"
    }
}
```

## Error 2: Sintaxis incorrecta en llamada a función

**Ubicación:** Línea 146

**Código con error:**
```javascript
const resultado = fetchConTimeout(url, tiempo= .5); /* Tu codigo aqui — fetchConTimeout con 1ms */;
```

**Problemas:**
1. **`url` no está definido** en este scope - se debe usar una URL completa
2. **`tiempo= .5` no es válido** - el parámetro se llama `timeout`, no `tiempo`, y la sintaxis `tiempo= .5` no es válida en JavaScript
3. **Falta `await`** antes de `fetchConTimeout` - la función es async y retorna una promesa
4. **El valor `.5` no es válido** - el timeout debe estar en milisegundos, no en décimas

**Corrección:**
```javascript
try {
    console.log('Probando con timeout de 1ms (deberia fallar)...');
    const resultado = await fetchConTimeout(                    // ← Agregar "await"
        'https://jsonplaceholder.typicode.com/users/1',        // ← URL completa
        1                                                       // ← 1 milisegundo, sin nombre de variable
    );
    console.log('Inesperado - funciono:', resultado);
} catch (e) {
    console.log('Fallo como esperaba:', e.name);
}
```

## Error 3: Uso de `const` en incremento de bucle

**Ubicación:** Línea 177

**Código con error:**
```javascript
for (const contador = 1 ; contador <= maxReintentos ; contador++) {
```

**Problema:**
- `const` declara una constante que **no puede ser reasignada**
- El incremento `contador++` intenta reasignar el valor de `contador` en cada iteración
- Esto genera un error: `TypeError: Assignment to constant variable`

**Corrección:**
```javascript
for (let contador = 1 ; contador <= maxReintentos ; contador++) {
```

**Explicación:**
- `let` permite declarar una variable que puede ser reasignada
- El incremento `contador++` funcionará correctamente con `let`

## Error 4: Sintaxis incorrecta en llamada a función

**Ubicación:** Línea 229

**Código con error:**
```javascript
const resultado = fetchConReintentos('https://jsonplaceholder.typicode.com/users/99999',maxReintentos=3)/* Tu codigo aqui — fetchConReintentos con URL invalida */;
```

**Problemas:**
1. **`maxReintentos=3` no es válido** - no se pueden pasar argumentos con nombre en JavaScript de esta manera
2. **Falta `await`** antes de `fetchConReintentos` - la función es async y retorna una promesa
3. **Sintaxis confusa** - el valor 3 ya es el valor por defecto del parámetro, no es necesario especificarlo

**Corrección:**
```javascript
try {
    console.log('Probando con URL invalida (deberia fallar 3 veces):');
    const resultado = await fetchConReintentos(                   // ← Agregar "await"
        'https://jsonplaceholder.typicode.com/users/99999'       // ← Solo URL, usar valor por defecto
    );
    console.log('Inesperado - funciono:', resultado);
} catch (e) {
    console.log('Todos los reintentos fallaron. Error final:', e.message);
}
```

## Notas Adicionales

1. **Código duplicado:** Las líneas 43-61 contienen una versión con errores de la función `fetchConTimeout` que está FUERA del bloque de la tarea. Esta versión no debería existir ya que la función se redeclara dentro de `hacerEj('TASK 1: fetchConTimeout', ...)`.

2. **Nombres de variables inconsistentes:** Se observa un patrón de mezclar español (`señal`, `tiempo`, `controlador`) con inglés (`signal`, `timer`, `controller`). Se recomienda mantener consistencia en un solo idioma.

3. **Mejores prácticas para AbortController:**
   - Usar `AbortError` como nombre del error (estándar del navegador)
   - Siempre limpiar el timer con `clearTimeout` en el bloque `finally` o en ambos caminos (éxito y error)

4. **Mejores prácticas para retry:**
   - Usar `let` en lugar de `const` para variables de control de bucle
   - No pasar argumentos con nombre en JavaScript (no soportado)
   - Aprovechar los valores por defecto de los parámetros
