Módulo 03: Async/Await

Ejercicio 03: try/catch con async/await

Maneja errores en código asíncrono usando try/catch/finally.

Tareas

Tarea 1: Envolver fetch en try/catch

Escribe un fetch dentro de un bloque try.

Tarea 2: Mostrar error amigable en catch

Captura el error y muestra error.message en la consola.

Tarea 3: Probar con URL inválida

Cambia la URL a una que no exista y verifica que el catch funciona.

Tarea 4: Añadir finally

Añade un bloque finally que imprima un mensaje de limpieza.

Abre la consola (F12) para ver los resultados.
