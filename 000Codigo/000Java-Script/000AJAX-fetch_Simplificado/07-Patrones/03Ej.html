Módulo 07 — Patrones de fetch

Ejercicio 03: Cache simple con Map

Implementa caché de resultados para evitar peticiones repetidas a la misma URL.

Tareas

Tarea 1: Crear el Map de caché

Crea const cache = new Map() para almacenar resultados.

Tarea 2: Verificar cache antes de fetch

Antes de hacer fetch, verifica si la URL ya está en el cache con cache.has(url).

Tarea 3: Guardar en cache

Si la URL no está en cache, haz fetch y guarda el resultado con cache.set(url, datos).

Tarea 4: Probar la cache

Llama dos veces con la misma URL. La segunda debe ser instantánea desde el cache.

Abre la consola (F12) para ver los resultados.
