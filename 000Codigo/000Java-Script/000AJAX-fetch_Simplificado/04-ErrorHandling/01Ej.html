Módulo 04: Manejo de Errores

Ejercicio 01: fetch() NO falla en 404

Algo que sorprende a muchos: fetch() NO lanza error cuando el servidor responde con 404, 500, etc. Solo falla si hay un problema de red.

Tareas

Tarea 1: Fetch a recurso inexistente

Haz fetch a /posts/99999 (un ID que no existe).

Tarea 2: Verificar que NO entró al catch

Comprueba que el código del .then() SÍ se ejecuta, aunque el post no exista.

Tarea 3: Inspeccionar response.ok y response.status

Muestra en consola que response.ok es false y response.status es 404.

Abre la consola (F12) para ver los resultados.
