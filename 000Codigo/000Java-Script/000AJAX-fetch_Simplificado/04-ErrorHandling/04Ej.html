Módulo 04: Manejo de Errores

Ejercicio 04: Wrapper fetchJSON seguro

Crea tu propia función reutilizable que encapsule todo el manejo de errores de fetch.

Tareas

Tarea 1: Crear función fetchJSON

Crea fetchJSON(url) que haga fetch, verifique response.ok, lance error si no es OK, y retorne el JSON parseado.

Tarea 2: Probar con URL válida

Usa fetchJSON con /users/1. Debe funcionar correctamente.

Tarea 3: Probar con URL inválida

Usa fetchJSON con /posts/99999. Debe lanzar un error claro.

Abre la consola (F12) para ver los resultados.
