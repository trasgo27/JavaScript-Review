## Errores encontrados

### Error 1: Confusión entre `status` y `statusText` en TASK 1
**Línea:** 21  
**Código con error:**
```javascript
throw new Error('Problema HTTP, codigo Error: '+ respuesta.status + 'explicación: ' + respuesta.status);
```  
**Problema:** Se utiliza `respuesta.status` dos veces. La segunda vez debería ser `respuesta.statusText` para obtener la descripción del error (ej: "Not Found" para 404). Además, faltan espacios en el mensaje concatenado.  
**Corrección:**
```javascript
throw new Error('Problema HTTP, código Error: ' + respuesta.status + ' explicación: ' + respuesta.statusText);
```

### Error 2: Estructura anidada innecesaria en TASK 1
**Líneas:** 24-26  
**Código con error:**
```javascript
return respuesta.json()
.then((datos)=>
  console.log('Datos ...', datos));
```  
**Problema:** Se anida un `.then()` dentro de otro `.then()` sin necesidad. Esto dificulta la lectura y el manejo de errores.  
**Corrección:**
```javascript
return respuesta.json()
  .then(datos => console.log('Datos ...', datos));
```
O aún mejor, usar async/await para mayor claridad:
```javascript
const datos = await respuesta.json();
console.log('Datos ...', datos);
```

### Error 5: Falta `return` en la función `fetchConVerificacion`
**Líneas:** 78-94  
**Código con error:**
```javascript
function fetchConVerificacion(url) {
  fetch(url)
    .then(...)
    .catch(...);
  // No hay return
}
```  
**Problema:** La función no retorna la Promise de `fetch()`. Esto hace que no se pueda encadenar `.then()` después de llamar a la función.  
**Corrección:**
```javascript
function fetchConVerificacion(url) {
  return fetch(url)
    .then(respuesta => {
      if (!respuesta.ok) {
        throw new Error('Error HTTP: ' + respuesta.status + ' - ' + respuesta.statusText);
      }
      console.log('✅ Petición exitosa para:', url);
      return respuesta.json();
    })
    .then(datos => console.log('Datos de', url, ':', datos.title || datos))
    .catch(error => console.error('❌ Error con', url, ':', error.message));
}
```

## Lecciones Aprendidas

1. **Siempre usar `statusText` para descripciones:** `status` es el código numérico (404, 500), mientras que `statusText` es la descripción legible ("Not Found", "Internal Server Error").

2. **Evitar `.then()` anidados:** Prefiere encadenar `.then()` en lugar de anidarlos. Esto mejora la legibilidad y facilita el manejo de errores.

3. **Las funciones que usan `fetch` deben retornar la Promise:** Si no retornas `fetch()`, el código que llame a la función no podrá manejar el resultado correctamente.

4. **Siempre ejecutar las funciones que defines:** Definir una función no la ejecuta. Asegúrate de llamarla con los parámetros correctos.

5. **Manejar errores consistentemente:** Usa `.catch()` al final de cada cadena de promesas para capturar errores de red, parsing, o lógica personalizada.
