Ejercicio 02: Verificar response.ok SIEMPRE

La solución al problema del ejercicio anterior: siempre verifica response.ok antes de usar la respuesta.

Tareas

Tarea 1: Hacer fetch genérico

Haz fetch a una URL de la API.

Tarea 2: Verificar response.ok

Si response.ok es false, lanza un error manualmente con throw new Error(...).

Tarea 3: Probar con URL válida y URL 404

Ejecuta con /posts/1 (válida) y /posts/99999 (404) para ver la diferencia.

Abre la consola (F12) para ver los resultados.
