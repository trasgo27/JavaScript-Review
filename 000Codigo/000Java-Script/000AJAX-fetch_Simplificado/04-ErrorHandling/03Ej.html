Módulo 04: Manejo de Errores

Ejercicio 03: Errores de red vs HTTP

No todos los errores de fetch son iguales. Aprende a diferenciar un error de red (DNS caído, sin conexión) de un error HTTP (404, 500).

Tareas

Tarea 1: Error de red (TypeError)

Haz fetch a una URL rota/inexistente en un dominio falso. Esto genera un TypeError.

Tarea 2: Error HTTP (404)

Haz fetch a /posts/99999 con la API real. Esto resuelve pero con response.ok === false.

Tarea 3: Diferenciar ambos en catch

Escribe código que detecte si el error es de red o HTTP y muestre un mensaje diferente para cada caso.

Abre la consola (F12) para ver los resultados.
