## What is a Custom Header?

A custom header is an extra field you invent and add to the HTTP request.

### Analogy
Sending a request is like mailing a letter. The envelope already has standard
fields (From, To, Content-Type). A custom header is an extra field you define:

- **X-Custom-Header:** salvacode

### Real examples
| Header | What it does |
|---|---|
| `Authorization: Bearer abc123` | Authenticates the user |
| `X-Request-Id: 12345` | Identifies the request for logs |
| `Accept-Language: es` | Tells the server your preferred language |

### Server behavior
The server receives the header but ignores it if it's not programmed to read it.
In your own backend you could read it with: `request.headers.get('X-Custom-Header')`

## fetch Second Parameter

`fetch` accepts up to 2 parameters: `fetch(url, options)`

The second is an object with properties like:

| Property | What it does |
|---|---|
| `method` | GET, POST, PUT, DELETE... (GET by default) |
| `headers` | Object with headers to send |
| `body` | Data to send (POST, PUT) |
| `mode` | CORS, no-cors, same-origin |
| `cache` | no-cache, reload, force-cache... |

Full example:
```js
fetch('https://api.ejemplo.com/users', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer token123'
  },
  body: JSON.stringify({ name: 'Juan', age: 30 })
})
```

If you only need GET with headers, you can omit `method` since GET is the default — that's why in the code only `headers` is passed.

#### Bug 3: Redundant `API + url` concatenation (line 101)
The hint expects the full URL to be passed to the function (`${API}/posts/3`).
Concatenating `API + url` inside generates a duplicated URL if the full URL is passed.
Use `url` directly.
```js
// Wrong
const urlCompleta = API + url;
const respuesta = await fetch(urlCompleta, ...)

// Correct
const respuesta = await fetch(url, ...)
```

#### Bug 4: Missing quotes on `/posts/3` (line 109)
`/posts/3` without quotes is interpreted as regex or division, not a string.
```js
// Wrong

// Correct

```

#### Bug 5: Missing `await` (line 109)
