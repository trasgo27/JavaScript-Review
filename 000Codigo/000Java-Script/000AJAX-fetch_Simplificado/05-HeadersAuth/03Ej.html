Módulo 05: Headers y Autenticación

Ejercicio 03: Token de autorización básico

Almacena un token ficticio en localStorage y envíalo como header de autorización.

Tareas

Tarea 1: Guardar token en localStorage

Crea un token ficticio (string inventado) y guárdalo con localStorage.setItem().

Tarea 2: Función getAuthHeaders()

Crea una función que lea el token de localStorage y devuelva un objeto con el header Authorization.

Tarea 3: Fetch con token de autorización

Haz un fetch a /posts/1 usando la función getAuthHeaders() para incluir el token. Muestra la respuesta.

Abre la consola (F12) para ver los resultados.
