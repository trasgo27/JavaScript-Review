Módulo 05: Headers y Autenticación

Ejercicio 01: Headers personalizados

Aprende a enviar headers personalizados en tus peticiones fetch.

Tareas

Tarea 1: Header X-Custom-Header

Haz un fetch a /posts/1 incluyendo el header 'X-Custom-Header' con valor 'salvacode'. Muestra la respuesta en consola.

Tarea 2: Header Accept

Haz un fetch a /posts/2 incluyendo el header 'Accept' con valor 'application/json'. Muestra la respuesta en consola.

Tarea 3: Función fetchConHeaders()

Crea una función fetchConHeaders(url, headersObj) que haga fetch con los headers recibidos como objeto. Pruébala con diferentes headers.

Abre la consola (F12) para ver los resultados.
