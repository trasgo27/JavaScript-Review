Módulo 05: Headers y Autenticación

Ejercicio 02: Content-Type y body JSON

Envía datos al servidor en formato JSON configurando el header Content-Type.

Tareas

Tarea 1: Crear objeto con datos

Crea un objeto con las propiedades title, body y userId.

Tarea 2: POST con Content-Type JSON

Haz un POST a /posts con header 'Content-type': 'application/json; charset=UTF-8' y el objeto convertido con JSON.stringify() en el body.

Tarea 3: Mostrar la respuesta

Muestra el id y title del recurso creado en consola.

Abre la consola (F12) para ver los resultados.
