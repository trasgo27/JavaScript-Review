Módulo 02 — Métodos HTTP con fetch

Ejercicio 01: GET con query params

Usa parámetros de consulta en la URL para filtrar datos de la API.

Tareas

Tarea 1: Filtrar por userId

Fetch a /posts?userId=1 y muestra cuántos posts devuelve.

Tarea 2: Filtrar y limitar

Fetch a /posts?userId=1&_limit=3 y muestra solo 3 posts.

Tarea 3: Usar variable para parámetros

Crea una variable con los parámetros y úsala en la URL.

Abre la consola (F12) para ver los resultados.
