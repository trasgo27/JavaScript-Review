Módulo 02 — Métodos HTTP con fetch

Ejercicio 03: PUT vs PATCH

Comprende la diferencia entre PUT (reemplazo completo) y PATCH (actualización parcial).

Tareas

Tarea 1: PUT a /posts/1

Envía un objeto completo con body entero (title, body, userId).

Tarea 2: PATCH a /posts/1

Envía solo { title: 'Nuevo título' } — solo lo que quieres cambiar.

Tarea 3: Comparar resultados

Ambas respuestas se muestran en consola para compararlas.

Abre la consola (F12) para ver los resultados.
