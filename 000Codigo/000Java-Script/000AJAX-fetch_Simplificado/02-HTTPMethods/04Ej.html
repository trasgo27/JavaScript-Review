Módulo 02 — Métodos HTTP con fetch

Ejercicio 04: DELETE — eliminar recurso

Elimina un recurso de la API y verifica que ya no existe.

Tareas

Tarea 1: DELETE a /posts/1

Envía una petición DELETE para eliminar el post con id 1.

Tarea 2: Verificar response

Comprueba response.ok y response.status.

Tarea 3: Confirmar con GET

Haz un GET a /posts/1 para confirmar el resultado.

Abre la consola (F12) para ver los resultados.
