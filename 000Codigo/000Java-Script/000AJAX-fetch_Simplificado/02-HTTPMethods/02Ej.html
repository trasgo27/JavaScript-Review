Módulo 02 — Métodos HTTP con fetch

Ejercicio 02: POST — crear un recurso

Crea un nuevo recurso enviando datos en el cuerpo de la petición con el método POST.

Tareas

Tarea 1: Crear objeto con los datos

Declara un objeto con title, body y userId.

Tarea 2: Hacer fetch POST

Envía el objeto con method: 'POST', headers y body serializado.

Tarea 3: Leer la respuesta

Muestra el id del recurso creado por la API.

Abre la consola (F12) para ver los resultados.
