Módulo 01 — Fundamentos de AJAX y fetch

Ejercicio 02: Tu primer fetch() GET

Haz tu primera petición real a una API pública y muestra el resultado en consola.

Tareas

Tarea 1: Hacer fetch a /posts/1

Usa await fetch() para obtener el post con id 1 de jsonplaceholder.

Tarea 2: Convertir a JSON

Usa .json() para convertir la respuesta a un objeto JavaScript.

Tarea 3: Mostrar el título

Accede a la propiedad title del objeto y muéstrala en consola.

Abre la consola (F12) para ver los resultados.
