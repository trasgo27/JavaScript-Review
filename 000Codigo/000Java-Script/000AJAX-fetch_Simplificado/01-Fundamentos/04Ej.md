## Mezcla de estilos: async/await con .then()

El error principal es mezclar `async/await` con `.then()/.catch()` en un mismo flujo, lo que genera una estructura confusa y errores de sintaxis. Hay que elegir **un solo estilo**:
- **Opción A:** Todo con `await` (dentro de `async function`) — más moderno y legible.
- **Opción B:** Todo con `.then().catch()` encadenado — más clásico.

**Bugs:**

1. **Línea 9:** `fetch(...)` no tiene `await` ni `return`, pero el código mezcla `.then()` con `async/await`. El resto del código intenta encadenar `.then()` sobre `fetch(...)` pero no lo hace — lo que sigue en la línea 17 es un `.then()` suelto sin conexión sintáctica porque no hay operador de punto encadenado.

2. **Línea 18:** `await response.json()` dentro de un `.then()` — error de sintaxis. `response.json()` ya retorna una promesa, no necesita `await` dentro de un `.then()`. Debería ser `return response.json()`.

3. **Línea 35:** `datos.then(...)` — `datos` es el resultado del `fetch` (una promesa), no el `response`. Además, dentro del callback se usa `datos.title` en vez de `resp.title`.

4. **Línea 62:** `.try()` no existe en JavaScript. Es un error sintáctico.

**Bug principal (línea que causa fallo):** **Línea 62** — `.try()` provoca un `SyntaxError` al ejecutarse, rompiendo totalmente el script.

   Se dispara la petición HTTP GET a la API de jsonplaceholder. `fetch()` devuelve una **Promise** que se guarda en `datos`.

2. **Línea 17** — `.then((response) => { return response.json(); })`

4. **Línea 53** — `.catch((err) => { console.error('Hubo fallo', err); })`  
   Si **cualquier** `.then()` del encadenamiento falla (error de red, JSON malformado, etc.), salta directamente al `.catch()` y muestra el error. Como todo salió bien, este bloque no se ejecutó.

## Sintaxis correcta de fetch()

`fetch()` recibe **dos parámetros**:

```js
fetch(url, opciones)
```

- **URL** (obligatorio) — la dirección a la que se hace la petición.
- **Opciones** (opcional) — un objeto donde se especifica el método HTTP, cabeceras, cuerpo, etc.

Ejemplos:

```js
// GET (por defecto)
fetch('https://api.ejemplo.com/posts')

// GET explícito
fetch('https://api.ejemplo.com/posts', { method: 'GET' })

// POST con datos
fetch('https://api.ejemplo.com/posts', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ title: 'Nuevo post' })
})

// PUT
fetch('https://api.ejemplo.com/posts/1', { method: 'PUT' })

// DELETE
fetch('https://api.ejemplo.com/posts/1', { method: 'DELETE' })
```

**No es correcto** pasar el método como primer parámetro tipo `fetch('GET', url)`. El método va dentro del objeto de opciones.
