Este error ocurre porque el navegador no te permite usar la palabra clave `await` suelta en cualquier parte de un archivo JavaScript tradicional. Para poder usar este "botón de pausa", necesitas estar dentro de una función declarada como asíncrona (`async`) o indicarle al navegador que tu archivo de JavaScript es un "módulo".

Tienes dos formas muy sencillas de solucionarlo:

### Opción 1: Convertir tu archivo en un módulo (La solución más limpia)

En tu archivo HTML, busca la etiqueta donde importas este script de JavaScript y añade el atributo `type="module"`.

Debería quedar con este aspecto:
`<script type="module" src="02Ej.js"></script>`

Al hacer este pequeño cambio, el navegador activará el soporte de "Top-Level Await", lo que significa que te dejará usar `await` directamente en cualquier parte del archivo sin que proteste.

### Opción 2: Envolver tus tareas en una función asíncrona

Si prefieres no modificar el HTML, debes meter el código de tus tres tareas dentro de una caja protectora asíncrona.

Para hacerlo:

1. Escribe `async function iniciar() {` justo antes de tu Tarea 1.
2. Cierra la llave `}` al final de tu Tarea 3.
3. Justo debajo, ejecuta la función escribiendo `iniciar();` para que todo se ponga en marcha.
