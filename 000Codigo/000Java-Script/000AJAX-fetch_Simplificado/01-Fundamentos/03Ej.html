Módulo 01 — Fundamentos de AJAX y fetch

Ejercicio 03: Entender el objeto Response

Explora las propiedades del objeto que fetch devuelve antes de extraer los datos.

Tareas

Tarea 1: Examina response.ok

Haz fetch a /posts/1 y comprueba si response.ok es true.

Tarea 2: Examina response.status

Muestra el código de estado HTTP (debe ser 200).

Tarea 3: Examina response.statusText

Muestra el texto del estado (debe ser "OK").

Abre la consola (F12) para ver los resultados.
