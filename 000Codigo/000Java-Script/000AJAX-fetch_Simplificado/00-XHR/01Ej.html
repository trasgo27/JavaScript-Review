Módulo 00: XMLHttpRequest

Ejercicio 01 — Tu primer XHR

XMLHttpRequest es el objeto que existía ANTES de fetch(). Aunque ya no se usa mucho, es importante entenderlo.

const xhr = new XMLHttpRequest();
xhr.open('GET', 'https://jsonplaceholder.typicode.com/posts/1');
xhr.onload = function() { console.log(xhr.responseText); };
xhr.send();

Tasks

Task 1: Crear y configurar un XHR

Crea un XMLHttpRequest, ábrelo con GET a /posts/1, y envíalo.

Task 2: Mostrar la respuesta

En el evento onload, parsea la respuesta con JSON.parse() y muestra el título.

Task 3: Comparar con fetch

Escribe la misma petición pero con fetch() para ver la diferencia.

💡 Ver solución completa (click para expandir) 
// ══════════════════════════════════════════════════════════════
// SOLUCIÓN Ejercicio 01 — Tu primer XHR
// ══════════════════════════════════════════════════════════════

console.log('=== Ejercicio 01: Tu primer XHR ===');

// ─── TASK 1: Crear, abrir y enviar ──────────────────────────
const xhr = new XMLHttpRequest();
xhr.open('GET', 'https://jsonplaceholder.typicode.com/posts/1');

xhr.onload = function() {
    // ─── TASK 2: Parsear y mostrar ──────────────────────────
    const datos = JSON.parse(xhr.responseText);
    console.log('Título del post:', datos.title);
    console.log('Cuerpo:', datos.body);
};

xhr.onerror = function() {
    console.error('Error de red');
};

xhr.send();
