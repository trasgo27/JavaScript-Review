Módulo 06: DOM y APIs

Ejercicio 02: Input de búsqueda + resultados

Crea un campo de búsqueda que filtre usuarios de la API en tiempo real al escribir.

Tareas

Tarea 1: Escuchar evento input

Selecciona el campo de búsqueda y escucha el evento 'input'.

Tarea 2: Fetch + filtrar por nombre

Cada vez que el usuario escriba, haz fetch a /users y filtra por nombre usando .includes().

Tarea 3: Mostrar resultados en #results

Renderiza los usuarios filtrados como HTML dentro de #results.

Tarea 4: Mensaje si no hay resultados

Si la búsqueda no encuentra nada, muestra "No encontrado".

Abre la consola (F12) para ver los resultados.
