Módulo 06: DOM y APIs

Ejercicio 01: Fetch + renderizar en DOM

Obtén usuarios de la API y muéstralos como elementos HTML en la página.

Tareas

Tarea 1: Fetch de usuarios

Haz fetch a /users?_limit=5 para obtener los primeros 5 usuarios.

Tarea 2: Crear elementos HTML por cada usuario

Para cada usuario, crea un <div> con su nombre y email.

Tarea 3: Insertar en #output

Inserta todos los divs generados en el contenedor #output.

Tarea 4: Mostrar contador

Muestra el mensaje "Cargados X usuarios" en consola.

Abre la consola (F12) para ver los resultados.
