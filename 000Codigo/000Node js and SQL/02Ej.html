Exercise 02: SELECT with WHERE Conditions

Learn to query and filter SQLite data using specific conditions, logical operators (AND, OR), patterns (LIKE), and ranges (BETWEEN).

Your Tasks

Task 1: Fetch users older than 25

Retrieve all columns for users where age > 25. Use db.prepare().all().

Task 2: Find Gmail users

Retrieve the name and email of users whose emails end with @gmail.com using LIKE '%@gmail.com'.

Task 3: Search products by price range

Find products priced between $20 and $100 using BETWEEN ? AND ?.

Task 4: Wildcard product search

Find products whose names contain "book" or "guide" (case-insensitive). Use LIKE with % wildcard.

Task 5: Logical combinations

Retrieve products that are either in the electronics category OR have a price under $50, AND also have stock greater than 0.

💡 Key Hints
  • Use db.prepare(sql).all(...) when you expect multiple rows back.
  • For dynamic values, always use placeholders: db.prepare('SELECT * FROM users WHERE age > ?').all(25).
  • Concatenate wildcards in JS: stmt.all(`%${searchTerm}%`).
