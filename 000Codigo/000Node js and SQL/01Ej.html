Exercise 01: CREATE TABLE & INSERT

Practice creating tables and inserting data using better-sqlite3 in Node.js.

Your Tasks

Task 1: Create a users table

Create a table called users with columns: id (INTEGER PRIMARY KEY AUTOINCREMENT), name (TEXT NOT NULL), email (TEXT NOT NULL UNIQUE), age (INTEGER).

Task 2: Insert a single user

Insert one user — name "Alice", email "alice@example.com", age 30. Use db.prepare().run().

Task 3: Insert multiple users via transaction

Insert at least 5 users in a loop using an array of objects and db.transaction().

const insert = db.prepare('INSERT INTO users (name, email, age) VALUES (?, ?, ?)');
const insertMany = db.transaction((list) => {
    for (const u of list) insert.run(u.name, u.email, u.age);
});

Task 4: Capture lastInsertRowid

Insert one more user and log the auto-generated ID using info.lastInsertRowid.

Task 5: Handle a UNIQUE constraint violation

Try inserting a duplicate email. Catch the error and log a friendly message instead of crashing.

try {
    insert.run(...);
} catch (err) {
    console.log('Duplicate email:', err.message);
}

Task 6: Create a products table

Create a table called products: id (INTEGER PRIMARY KEY AUTOINCREMENT), name (TEXT), price (REAL), stock (INTEGER DEFAULT 0), category (TEXT).

Task 7: Bulk insert products

Insert 8 products across 4 categories (electronics, clothing, food, books) using a transaction.

Task 8: Insert with DEFAULT values

Insert a product with only name and price, letting stock default to 0. Verify with a SELECT.

Task 9: Create an orders table with FOREIGN KEYs

Create an orders table: id, user_id (FOREIGN KEY → users), product_id (FOREIGN KEY → products), quantity, order_date (TEXT DEFAULT CURRENT_DATE).

Task 10: Insert related data

Insert 5 orders linking existing users and products. Handle foreign key violations gracefully.

💡 Key Hints
  • Use db.exec() for DDL statements (CREATE, DROP) — no placeholders.
  • Use db.prepare().run() for DML (INSERT, UPDATE, DELETE) — placeholders ? prevent SQL injection.
  • Enable foreign keys at startup: db.pragma('foreign_keys = ON').
