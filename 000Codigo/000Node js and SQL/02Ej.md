## Improving COUNT queries

**Problem:** Using `.all()` for `COUNT(*)` returns an array of objects like `[{ "COUNT(*)": 9 }]` which is not readable.

**Solution:** Use `.get()` instead since `COUNT(*)` returns only one row, and access the value directly using an alias:

```javascript
const numeroProd = db.prepare('SELECT COUNT(*) AS count FROM products').get();
console.log('Total Productos:', numeroProd.count);
```

This gives you:
- `.get()` returns a single object `{ count: 9 }` instead of an array
- Using `AS count` gives you a clean property name to access

## Task 4: Wildcard product search

```javascript
const bookOrGuide = db.prepare('SELECT * FROM products WHERE name LIKE ? OR name LIKE ?').all('%book%', '%guide%');
```

## Task 5: Logical combinations

```javascript
const conditionalProducts = db.prepare(
  'SELECT * FROM products WHERE (category = ? OR price < ?) AND stock > ?'
).all('electronics', 50, 0);
```

Note: The parentheses around the OR conditions are important to get the correct precedence.
