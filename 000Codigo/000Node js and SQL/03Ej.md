## LIKE vs = in SQL

It's not about the placeholder — it's about what you're matching:

- **`=`** — exact match. `'Bob'` matches exactly `"Bob"`
- **`LIKE`** — pattern match with wildcards. `'%gmail.com'` matches anything ending in `@gmail.com`

So in UPDATE, you use `=` because you're targeting a specific user by exact name. In SELECT with wildcards, you use `LIKE` because you want to match a pattern (emails containing `@gmail.com`).

You *could* use `LIKE` in UPDATE too, but it would be unnecessary:

```sql
-- These both work for matching 'Bob':
WHERE name = 'Bob'
WHERE name LIKE 'Bob'
```

Use `LIKE` when you need wildcards (`%`, `_`). Use `=` for exact values — it's clearer and slightly faster.
