React Exercises

Interactive learning path from basics to advanced concepts

💡 Tips:
  • Each exercise runs directly in the browser - no build step needed!
  • Open DevTools (F12) → Console to see detailed logs and explanations
  • Try modifying the code in each exercise to experiment
  • Exercises are ordered from basic to advanced - follow the sequence!

🟢 Beginner - Fundamentals

  • 01 JSX Basics Syntax, expressions, attributes, fragments, inline styles Beginner
  • 02 Components & Props Reusable components, passing data, children prop, composition Beginner
  • 03 useState Hook State management, counters, toggles, forms, arrays Beginner
  • 04 Event Handling Click, form, keyboard events, synthetic events Beginner
  • 05 Conditional Rendering Ternary, && operator, switch, loading states Beginner
  • 06 Lists & Keys Rendering arrays, .map(), keys, filtering, nested lists Beginner

🟡 Intermediate - Hooks & Patterns

  • 07 Forms (Controlled Components) Controlled inputs, validation, dynamic fields Intermediate
  • 08 useEffect Hook Side effects, data fetching, timers, cleanup, dependencies Intermediate
  • 09 useContext Hook Context API, providers, avoiding prop drilling, theme toggle Intermediate
  • 10 useRef Hook DOM access, persisting values, timers, scroll-to-element Intermediate
  • 11 Custom Hooks useLocalStorage, useToggle, useFetch, useWindowSize Intermediate
  • 12 useReducer Hook Reducer pattern, complex state, todo list, shopping cart Intermediate

🔴 Advanced - Performance & Patterns

  • 13 Performance Optimization React.memo, useMemo, useCallback, preventing re-renders Advanced
  • 14 Error Boundaries Class components, error handling, graceful fallbacks Advanced
