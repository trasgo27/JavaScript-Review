01 · Componentes Básico

Un componente es la unidad fundamental de Angular. Combina template, lógica y estilos en una clase decorada con @Component.

Ejercicios

Ejercicio 1 Fácil

Objetivo: Crear tu primer componente "Hola Mundo".

import { Component } from '@angular/core';

// Crea un componente que muestre "¡Hola Angular!"
@Component({
  selector: 'app-hola',
  standalone: true,
  template: `<h1>¡Hola Angular!</h1>`
})
export class HolaComponent {}

✅ Reto: Añade un párrafo con tu nombre debajo del título.

Ejercicio 2 Fácil

Objetivo: Usar la sintaxis inline template vs templateUrl.

// Opción A: template inline
@Component({
  selector: 'app-tarjeta',
  template: `<div class="card">Contenido</div>`
})

// Opción B: archivo externo
@Component({
  selector: 'app-tarjeta',
  templateUrl: './tarjeta.component.html',
  styleUrls: ['./tarjeta.component.css']
})

✅ Reto: Crea un componente con template externo y al menos 3 elementos HTML.

Ejercicio 3 Medio

Objetivo: Declarar propiedades en el componente y usarlas en el template.

@Component({
  selector: 'app-perfil',
  template: `
    <h2>{{ nombre }}</h2>
    <p>Edad: {{ edad }}</p>
  `
})
export class PerfilComponent {
  nombre = 'Ana García';
  edad = 28;
}

✅ Reto: Añade 3 propiedades más (email, ciudad, profesión).

Ejercicio 4 Medio

Objetivo: Crear métodos en el componente y llamarlos desde el template.

@Component({
  selector: 'app-contador',
  template: `
    <p>Contador: {{ contador }}</p>
    <button (click)="incrementar()">+1</button>
    <button (click)="decrementar()">-1</button>
  `
})
export class ContadorComponent {
  contador = 0;
  incrementar() { this.contador++; }
  decrementar() { this.contador--; }
}

✅ Reto: Añade un botón "Reset" que ponga el contador a 0.

Ejercicio 5 Difícil

Objetivo: Crear un componente con ciclo de vida (ngOnInit).

import { Component, OnInit } from '@angular/core';

@Component({
  selector: 'app-reloj',
  template: `<p>Hora actual: {{ hora }}</p>`
})
export class RelojComponent implements OnInit {
  hora = '';

  ngOnInit() {
    this.actualizarHora();
    setInterval(() => this.actualizarHora(), 1000);
  }

  actualizarHora() {
    this.hora = new Date().toLocaleTimeString();
  }
}

✅ Reto: Implementa ngOnDestroy para limpiar el setInterval al destruir el componente.
