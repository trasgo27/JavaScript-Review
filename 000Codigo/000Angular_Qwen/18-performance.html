Optimiza tu app con ChangeDetectionStrategy.OnPush, @defer, signals y Angular SSR con hydration.

Ejercicios

Ejercicio 1 Fácil

Activa OnPush change detection.

@Component({
  selector: 'app-heavy',
  standalone: true,
  changeDetection: ChangeDetectionStrategy.OnPush,
  template: `...`
})
export class HeavyComponent {
  // Angular solo re-renderiza cuando:
  // - Cambia un @Input por referencia
  // - Se dispara un event handler
  // - Se usa un signal o async pipe
  // - Se llama markForCheck() manualmente
}

Ejercicio 2 Fácil

Usa @defer para carga diferida.

// Template:
<article>
  <h1>Contenido principal</h1>

  @defer (on viewport; prefetch on idle) {
    <app-heavy-chart />
  } @placeholder {
    <div class="skeleton">Cargando gráfico...</div>
  } @loading (after 100ms; minimum 1s) {
    <app-spinner />
  } @error {
    <p>Error al cargar</p>
  }
</article>

Ejercicio 3 Medio

Condiciones de @defer: on idle, on viewport, on interaction, on timer.

// Carga cuando el usuario hace hover
@defer (on hover) { <app-tooltip /> }

// Carga cuando entra en viewport
@defer (on viewport) { <app-image-gallery /> }

// Carga tras 3 segundos
@defer (on timer(3s)) { <app-ad /> }

// Combinación: viewport Y después de idle
@defer (on viewport; prefetch on idle) { ... }

Ejercicio 4 Medio

Configura SSR con Angular 18+.

// app.config.server.ts
export const serverConfig: ApplicationConfig = {
  providers: [
    provideServerRendering()
  ]
};

// server.ts (Express):
import { AngularNodeAppEngine } from '@angular/ssr/node';

app.use('*', (req, res, next) => {
  new AngularNodeAppEngine(appBootstrap, req)
    .render(req.url, { request: req })
    .then(response => res.send(response.body))
    .catch(next);
});

Ejercicio 5 Difícil

Hydration y transferencia de estado.

// app.config.ts:
providers: [
  provideClientHydration(),
  withEventReplay()  // replay de eventos durante hidratación
]

// Transfer state (compartir datos SSR → client):
import { TransferState, makeStateKey } from '@angular/core';

const USER_KEY = makeStateKey<User>('user');

constructor(private state: TransferState) {}

ngOnInit() {
  if (this.state.hasKey(USER_KEY)) {
    this.user = this.state.get(USER_KEY, null);
  } else {
    this.http.get<User>('/api/user').subscribe(u => {
      this.user = u;
      this.state.set(USER_KEY, u);
    });
  }
}

✅ Reto: Combina @defer con TransferState para cachear datos de una API.
