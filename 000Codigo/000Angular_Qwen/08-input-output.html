08 · Input / Output Intermedio

La nueva API de Angular 17+: input(), output() y model() para comunicar componentes.

Ejercicios

Ejercicio 1 Fácil

Pasa datos de padre a hijo con input().

// Hijo: saludo.component.ts
import { Component, input } from '@angular/core';

@Component({ selector: 'app-saludo', template: `<p>Hola {{ nombre() }}</p>` })
export class SaludoComponent {
  nombre = input.required<string>();
}

// Padre template:
// <app-saludo [nombre]="'Carlos'" />

Ejercicio 2 Fácil

Emite eventos con output().

// Hijo
contadorCambio = output<number>();
valor = 0;

incrementar() {
  this.valor++;
  this.contadorCambio.emit(this.valor);
}

// Padre template:
// <app-contador (contadorCambio)="onCambio($event)" />

Ejercicio 3 Medio

Two-way binding con model().

// Hijo
valor = model<string>('');

// Template hijo:
// <input [value]="valor()" (input)="valor.set($any($event.target).value)" />

// Padre:
// <app-input [(valor)]="textoPadre" />

Ejercicio 4 Medio

Input con valor por defecto y transform.

// Con valor por defecto
tamano = input<'sm' | 'md' | 'lg'>('md');

// Con transform
cantidad = input(0, { transform: (v: string) => parseInt(v, 10) });
// Uso: <app-x cantidad="42" /> (acepta string y lo convierte)

Ejercicio 5 Difícil

Componente completo con input, output y model.

@Component({
  selector: 'app-rating',
  template: `
    @for (star of [1,2,3,4,5]; track star) {
      <span (click)="seleccionar(star)"
            [class.active]="star <= valor()">⭐</span>
    }
  `
})
export class RatingComponent {
  valor = model(0);
  cambio = output<number>();

  seleccionar(n: number) {
    this.valor.set(n);
    this.cambio.emit(n);
  }
}

✅ Reto: Añade un input readonly que deshabilite los clicks.
