07 · Control Flow Avanzado Intermedio

Profundiza en el control flow: filtros en @for, variables locales, @if con else-if chain, y @switch exhaustivo.

Ejercicios

Ejercicio 1 Fácil

Filtra elementos en un @for con @if.

numeros = [1, 2, 3, 4, 5, 6];

@for (n of numeros; track n) {
  @if (n % 2 === 0) {
    <span>{{ n }} es par</span>
  }
}

Ejercicio 2 Fácil

Cadena @if / @else if / @else.

nota = 85;

@if (nota >= 90) {
  <p>Sobresaliente 🌟</p>
} @else if (nota >= 70) {
  <p>Notable 👍</p>
} @else if (nota >= 50) {
  <p>Aprobado ✓</p>
} @else {
  <p>Suspenso ❌</p>
}

Ejercicio 3 Medio

Usa todas las variables locales de @for.

tareas = [
  { id: 1, texto: 'Comprar pan' },
  { id: 2, texto: 'Estudiar Angular' }
];

@for (t of tareas; track t.id;
      let i = $index, first = $first, last = $last, even = $even) {
  <div [class.first]="first" [class.last]="last" [class.even]="even">
    {{ i + 1 }}. {{ t.texto }}
  </div>
}

Ejercicio 4 Medio

@switch con tipos complejos.

estado = 'cargando'; // 'cargando' | 'exito' | 'error'

@switch (estado) {
  @case ('cargando') { <app-spinner /> }
  @case ('exito') { <app-datos /> }
  @case ('error') { <app-error /> }
}

Ejercicio 5 Difícil

Combina todo: @for con @if, @switch anidado y @empty.

pedidos = [
  { id: 1, estado: 'enviado', items: ['📦', '📦'] },
  { id: 2, estado: 'pendiente', items: [] },
  { id: 3, estado: 'cancelado', items: ['📦'] }
];

@for (p of pedidos; track p.id) {
  <h3>Pedido #{{ p.id }}</h3>
  @switch (p.estado) {
    @case ('enviado') { <span class="badge-enviado">✅ Enviado</span> }
    @case ('pendiente') { <span class="badge-pend">⏳ Pendiente</span> }
    @default { <span class="badge-cancel">❌ Cancelado</span> }
  }
  @if (p.items.length > 0) {
    @for (item of p.items; track $index) {
      <span>{{ item }}</span>
    }
  } @empty {
    <p>Sin productos</p>
  }
}
