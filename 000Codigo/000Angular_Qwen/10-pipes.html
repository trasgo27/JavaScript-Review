10 · Pipes Avanzado

Los pipes transforman datos en el template. Angular incluye muchos built-in y puedes crear los tuyos.

Ejercicios

Ejercicio 1 Fácil

Usa pipes built-in: uppercase, lowercase, date, currency.

nombre = 'ana garcía';
fecha = new Date();
precio = 1234.56;

// Template:
// {{ nombre | uppercase }}          → ANA GARCÍA
// {{ fecha | date:'dd/MM/yyyy' }}   → 11/07/2026
// {{ precio | currency:'EUR' }}     → €1,234.56
// {{ precio | number:'1.2-2' }}     → 1,234.56

Ejercicio 2 Fácil

Encadena pipes.

// Template:
// {{ nombre | lowercase | slice:0:5 }} → "ana g"
// {{ precio | currency:'EUR' | uppercase }} → "€1,234.56"

Ejercicio 3 Medio

Crea un pipe personalizado.

import { Pipe, PipeTransform } from '@angular/core';

@Pipe({ name: 'truncate', standalone: true })
export class TruncatePipe implements PipeTransform {
  transform(value: string, limit = 20): string {
    return value.length > limit ? value.substring(0, limit) + '...' : value;
  }
}
// Uso: {{ textoLargo | truncate:30 }}

Ejercicio 4 Medio

Pipe con parámetros.

@Pipe({ name: 'filtro', standalone: true })
export class FiltroPipe implements PipeTransform {
  transform(items: any[], campo: string, valor: any): any[] {
    return items.filter(i => i[campo] === valor);
  }
}
// Uso: {{ usuarios | filtro:'rol':'admin' }}

Ejercicio 5 Difícil

Pipe puro vs impuro (con pure: false).

@Pipe({ name: 'ordenar', standalone: true, pure: false })
export class OrdenarPipe implements PipeTransform {
  transform(items: any[], campo: string, asc = true): any[] {
    return [...items].sort((a, b) => {
      if (a[campo] < b[campo]) return asc ? -1 : 1;
      if (a[campo] > b[campo]) return asc ? 1 : -1;
      return 0;
    });
  }
}
// Uso: {{ productos | ordenar:'precio':false }}

✅ Reto: Hazlo pure: true y explica la diferencia de rendimiento.
