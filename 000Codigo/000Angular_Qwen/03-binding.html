03 · Property & Event Binding Básico

El binding conecta el componente con el DOM: [prop] para datos, (evento) para acciones, [(ngModel)] para dos vías.

Ejercicios

Ejercicio 1 Fácil

Property Binding: Enlaza el atributo src de una imagen.

imagenUrl = 'https://angular.io/assets/images/logos/angular/angular.svg';
// Template: <img [src]="imagenUrl" alt="Angular" />

Ejercicio 2 Fácil

Event Binding: Escucha un click y ejecuta un método.

contador = 0;
saludar() { alert('¡Hola!'); }
// Template: <button (click)="saludar()">Saludar</button>

Ejercicio 3 Medio

Accede al evento con $event.

mostrarValor(evento: Event) {
  console.log((evento.target as HTMLInputElement).value);
}
// Template: <input (input)="mostrarValor($event)" />

Ejercicio 4 Medio

Two-way binding con [(ngModel)].

// Importa FormsModule en el componente
nombre = '';
// Template:
// <input [(ngModel)]="nombre" />
// <p>Hola {{ nombre }}</p>

Ejercicio 5 Difícil

Combina property + event binding en un formulario completo.

email = '';
enviado = false;

enviar() {
  if (this.email.includes('@')) {
    this.enviado = true;
  }
}
// Template:
// <input [value]="email" (input)="email = $any($event.target).value" />
// <button (click)="enviar()" [disabled]="!email">Enviar</button>

✅ Reto: Añade un mensaje de confirmación que aparezca solo si enviado es true.
