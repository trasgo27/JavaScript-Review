06 · Signals Intermedio

Los Signals son el sistema de reactividad moderno de Angular. Son primitivos reactivos que permiten detectar cambios de forma granular.

Ejercicios

Ejercicio 1 Fácil

Crea un signal writable y lee su valor.

import { signal } from '@angular/core';

contador = signal(0);

// Leer: this.contador()
// Escribir: this.contador.set(5)
// Actualizar: this.contador.update(v => v + 1)

✅ Reto: Crea un signal de tipo string para un nombre.

Ejercicio 2 Fácil

Usa computed() para derivar valores.

precio = signal(100);
cantidad = signal(3);
total = computed(() => this.precio() * this.cantidad());
// Template: <p>Total: {{ total() }}€</p>

Ejercicio 3 Medio

Usa effect() para ejecutar lógica reactiva.

import { signal, effect } from '@angular/core';

nombre = signal('Ana');

constructor() {
  effect(() => {
    console.log(`Nombre cambió a: ${this.nombre()}`);
  });
}

✅ Reto: Guarda el valor en localStorage cada vez que cambie.

Ejercicio 4 Medio

Signal con objetos (actualización inmutable con update).

usuario = signal({ nombre: 'Luis', edad: 25 });

cumplirAnos() {
  this.usuario.update(u => ({ ...u, edad: u.edad + 1 }));
}

Ejercicio 5 Difícil

Crea un "contador con historial" usando signals.

contador = signal(0);
historial = signal([]);

incrementar() {
  const nuevo = this.contador() + 1;
  this.contador.set(nuevo);
  this.historial.update(h => [...h, nuevo]);
}

totalAcumulado = computed(() =>
  this.historial().reduce((a, b) => a + b, 0)
);

✅ Reto: Añade un botón "Deshacer" que elimine el último valor del historial.
