04 · Directivas Estructurales Básico

Angular 17+ introdujo el nuevo control flow: @if, @for y @switch, más legibles y performantes.

Ejercicios

Ejercicio 1 Fácil

Usa @if para mostrar/ocultar contenido.

logueado = false;
// Template:
@if (logueado) {
  <p>Bienvenido de vuelta 👋</p>
} @else {
  <p>Por favor, inicia sesión</p>
}

Ejercicio 2 Fácil

Itera un array con @for.

frutas = ['Manzana', 'Pera', 'Plátano'];
// Template:
@for (fruta of frutas; track fruta) {
  <li>{{ fruta }}</li>
} @empty {
  <li>No hay frutas</li>
}

Ejercicio 3 Medio

Usa $index, $even, $odd y $first, $last.

@for (item of lista; track item.id; let i = $index, even = $even, last = $last) {
  <div [class.par]="even" [class.ultimo]="last">
    {{ i + 1 }}. {{ item.nombre }}
  </div>
}

Ejercicio 4 Medio

Usa @switch para múltiples condiciones.

rol = 'admin';
// Template:
@switch (rol) {
  @case ('admin') { <p>Panel de administración 🔑</p> }
  @case ('editor') { <p>Editor de contenido ✏️</p> }
  @case ('viewer') { <p>Solo lectura 👁️</p> }
  @default { <p>Acceso denegado ❌</p> }
}

Ejercicio 5 Difícil

Combina @for anidado con @if.

categorias = [
  { nombre: 'Frutas', items: ['🍎', '🍌'] },
  { nombre: 'Verduras', items: [] }
];

// Template:
@for (cat of categorias; track cat.nombre) {
  <h3>{{ cat.nombre }}</h3>
  @if (cat.items.length > 0) {
    @for (item of cat.items; track item) {
      <span>{{ item }}</span>
    }
  } @else {
    <p>Vacío</p>
  }
}
