05 · Directivas de Atributo Básico

Las directivas de atributo modifican la apariencia o comportamiento de un elemento: ngClass, ngStyle y binding directo de clases.

Ejercicios

Ejercicio 1 Fácil

Aplica una clase condicional con [class.nombre].

activo = true;
// Template:
// <div [class.activo]="activo">Elemento</div>
// CSS: .activo { color: green; }

Ejercicio 2 Fácil

Usa ngClass con objeto de clases.

esGrande = true;
esRojo = false;
// Template:
// <div [ngClass]="{ 'grande': esGrande, 'rojo': esRojo }">Texto</div>

Ejercicio 3 Medio

Usa ngStyle para estilos dinámicos.

tamano = 20;
color = 'blue';
// Template:
// <p [ngStyle]="{ 'font-size.px': tamano, 'color': color }">Texto dinámico</p>

Ejercicio 4 Medio

Combina múltiples clases según el estado.

estado = 'exito'; // 'error' | 'warning' | 'exito'

getClases() {
  return {
    'alerta-exito': this.estado === 'exito',
    'alerta-error': this.estado === 'error',
    'alerta-warning': this.estado === 'warning'
  };
}
// Template: <div [ngClass]="getClases()">Mensaje</div>

Ejercicio 5 Difícil

Crea un "theme switcher" con ngClass y ngStyle.

temaOscuro = true;
tamanoFuente = 16;

toggleTema() { this.temaOscuro = !this.temaOscuro; }

// Template:
// <div [ngClass]="{ 'oscuro': temaOscuro, 'claro': !temaOscuro }"
//      [ngStyle]="{ 'font-size.px': tamanoFuente }">
//   <button (click)="toggleTema()">Cambiar tema</button>
//   <input type="range" min="12" max="24" [(ngModel)]="tamanoFuente" />
// </div>

✅ Reto: Añade un tercer tema (sepia) y un selector con 3 opciones.
