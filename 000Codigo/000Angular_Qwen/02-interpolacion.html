02 · Interpolación Básico

La interpolación {{ }} permite insertar valores de TypeScript directamente en el HTML.

Ejercicios

Ejercicio 1 Fácil

Muestra el valor de una variable string en el template.

titulo = 'Mi primera app';
// Template:
// <h1>{{ titulo }}</h1>

Ejercicio 2 Fácil

Realiza operaciones matemáticas dentro de la interpolación.

precio = 100;
iva = 0.21;
// Template: <p>Total: {{ precio + precio * iva }}€</p>

✅ Reto: Muestra también el precio sin IVA formateado a 2 decimales.

Ejercicio 3 Medio

Concatena strings y usa el operador ternario.

nombre = 'Carlos';
esAdmin = true;
// Template:
// <p>Hola {{ nombre }}, eres {{ esAdmin ? 'administrador' : 'usuario' }}</p>

Ejercicio 4 Medio

Accede a propiedades de objetos.

usuario = {
  nombre: 'Laura',
  email: 'laura@mail.com',
  direccion: { ciudad: 'Madrid' }
};
// Template: <p>{{ usuario.nombre }} vive en {{ usuario.direccion.ciudad }}</p>

✅ Reto: Usa el operador ?. (safe navigation) para evitar errores si el objeto es null.

Ejercicio 5 Difícil

Llama a un método desde la interpolación.

calcularDescuento(precio: number): number {
  return precio * 0.85;
}
// Template: <p>Precio final: {{ calcularDescuento(200) }}€</p>

✅ Reto: Crea un método que reciba un array y devuelva su longitud.
