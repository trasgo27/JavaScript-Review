12 · Servicios e Inyección de Dependencias Avanzado

Los servicios encapsulan lógica de negocio y son inyectados donde se necesiten. Angular gestiona su ciclo de vida.

Ejercicios

Ejercicio 1 Fácil

Crea un servicio básico con @Injectable.

import { Injectable } from '@angular/core';

@Injectable({ providedIn: 'root' })
export class SaludoService {
  saludar(nombre: string): string {
    return `Hola ${nombre} 👋`;
  }
}

// En componente:
saludoService = inject(SaludoService);
mensaje = this.saludoService.saludar('Ana');

Ejercicio 2 Fácil

Servicio con estado compartido (contador global).

@Injectable({ providedIn: null })
export class ContadorService {
  valor = signal(0);
  incrementar() { this.valor.update(v => v + 1); }
  decrementar() { this.valor.update(v => v - 1); }
}

Ejercicio 3 Medio

Inyecta un servicio en otro servicio.

@Injectable({ providedIn: 'root' })
export class LoggerService {
  log(msg: string) { console.log(`[LOG] ${msg}`); }
}

@Injectable({ providedIn: 'root' })
export class UserService {
  private logger = inject(LoggerService);

  crear(nombre: string) {
    this.logger.log(`Usuario creado: ${nombre}`);
  }
}

Ejercicio 4 Medio

Scope del servicio: root vs componente.

// Singleton global
@Injectable({ providedIn: 'root' })
export class AuthService { }

// Nueva instancia por componente
@Component({
  providers: [MiServicioLocal]
})

Ejercicio 5 Difícil

useFactory con dependencias.

@Injectable()
export class ApiService {
  constructor(private url: string) {}
}

// En providers:
providers: [
  {
    provide: ApiService,
    useFactory: (config: ConfigService) => new ApiService(config.apiUrl),
    deps: [ConfigService]
  }
]
