## ✅ Grammar — The Latch

### 🔩 Latch — Vocabulario

🔹 **Latch** /lætʃ/ (noun) = pestillo, cerrojo, picaporte  
🔹 **Latch** (verb) = cerrar con pestillo  

> 🚪 *"Turn the **latch** to lock the door."*

---

### ✅ Correct vs ❌ Incorrect

| Sentence | ✅ / ❌ |
|----------|:-------:|
| ✅ **"The latch is closed."** | ✅ Correct |
| ❌ **"The latch is close."** | ❌ Wrong (*close* = adjective meaning "nearby" → no tiene sentido con *latch*) |
| ✅ **"I close the latch."** | ✅ Correct (*close* = verbo, presente) |
| ✅ **"I closed the latch."** | ✅ Correct (*close* → *closed*, pasado) |
| ✅ **"The latch is closed."** | ✅ Correct (*closed* = adjetivo, "cerrado") |
| ❌ **"The door is latch."** | ❌ Wrong (*latch* es sustantivo, no adjetivo) |
| ✅ **"The door is latched."** | ✅ Correct (*latched* = adjetivo, "cerrado con pestillo") |

---

### ⚡ Regla rápida

| Palabra | Función | Ejemplo |
|---------|---------|---------|
| **close** 🚪 | Verbo ("cerrar") | *"Please **close** the door."* |
| **close** 📏 | Adjetivo ("cerca") | *"The store is **close** to my house."* |
| **closed** 🔒 | Adjetivo ("cerrado") | *"The latch is **closed**."* |
| **latch** 🔩 | Sustantivo ("pestillo") | *"The **latch** is broken."* |
| **latched** 🔒 | Adjetivo ("con pestillo") | *"The door is **latched**."* |
