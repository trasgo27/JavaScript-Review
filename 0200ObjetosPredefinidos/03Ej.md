# 03Ej.js — Array Transformation Exercise

## Objective

Parse a list of student strings in `"apellidos, nombre"` format into structured objects with cleaned and derived fields.

## Input

```javascript
const alumnosMatriculados = [
    "  alonso garcia, nacho  ",
    "MARTINEZ GOMEZ, ANA",
    "  perez lopez, JAVIER  ",
    " sanchis blas, marta "
];
```

## Output

Each student becomes an object with:

| Field | Derivation |
|-------|------------|
| `apellidos` | Surname part, trimmed + lowercased |
| `nombre` | Given name part, trimmed + lowercased |
| `nombre_completo` | `"nombre apellidos"` |
| `nombre_usuario` | First 3 chars of nombre + first 3 of apellidos |
| `email` | `nombre_usuario@iesserpis.edu` |

## Original Issues

| # | Issue |
|---|-------|
| 1 | Two `.map()` calls instead of one combined pass |
| 2 | `.trim().toLowerCase().slice(0,3)` repeated 6× per student |
| 3 | Object keys with colons/spaces (`'apellidos: '`) make access awkward |
| 4 | Single-letter param `a`; inconsistent naming |

## Refactored Version

```javascript
const alumnos = alumnosMatriculados.map((item) => {
    const [apellidos, nombre] = item.split(',').map(s => s.trim().toLowerCase());
    const nomPart = nombre.slice(0, 3);
    const apePart = apellidos.slice(0, 3);

    return {
        apellidos,
        nombre,
        nombre_completo: `${nombre} ${apellidos}`,
        nombre_usuario: nomPart + apePart,
        email: `${nomPart}${apePart}@iesserpis.edu`
    };
});
```

## Key Takeaways

- **Destructuring** cleans up index-based access (`a[0]`, `a[1]`)
- **Cache repeated operations** to avoid redundant `.trim().toLowerCase()` chains
- **Template literals** (`${}`) are cleaner than string concatenation with `+`
- A single `.map()` pass is more efficient and readable than chaining two
