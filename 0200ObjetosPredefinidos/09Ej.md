# Debug Report: `09Ej.js`

## Bugs

### 🐛 Bug 1 (Critical) — `.replace()` result discarded (line 16-18)
```javascript
if(p.guest.includes('_')){
    p.guest.replace('_',' ')  // ← return value never assigned
}
```
`String.replace()` returns a new string — it does not mutate the original. `p.guest` is never updated, so `"marta_smith"` keeps the underscore.

**Fix:** `p.guest = p.guest.replace('_', ' ')`

---

### 🐛 Bug 2 (Critical) — `nombAp[1]` is `undefined` → crash (line 24)
```javascript
const nombAp = p.guest.trim().split(' ');     // ["marta_smith"] (1 element)
const nombre1 = nombAp[0].trim().charAt(0).toUpperCase();  // OK
const apellido1 = nombAp[1].trim().charAt(0).toUpperCase(); // ❌ crash
```
Because Bug 1 prevents `_` → space replacement, `"marta_smith".split(' ')` yields a single-element array. Accessing index `[1]` returns `undefined`, and `.trim()` throws:

> `TypeError: Cannot read properties of undefined (reading 'trim')`

**Fix:** Fix Bug 1 first. Optionally add a guard for single-word names: `if (nombAp.length < 2) { ... }`

---

### 🐛 Bug 3 — Missing space between nombre and apellido (line 28)
```javascript
const nombre_completo = nombre + apellido;  // "LuisGarcia"
```
No separator between first and last name. Should produce `"Luis Garcia"`.

**Fix:** `` const nombre_completo = `${nombre} ${apellido}` ``

---

### 🐛 Bug 4 — `console.table` argument order (line 36)
```javascript
console.table("mapa1: ", mapa1);
```
`console.table` uses the **first argument** as the tabular data. Passing a string renders a single-cell table of that string. The second argument is treated as an **optional columns array** and is ignored.

**Fix:**
```javascript
console.log("mapa1:", mapa1);
console.table(mapa1);
```
Or simply `console.table(mapa1)`.

---

### 🐛 Bug 5 (Design) — Map drops all original properties (lines 31-34)
The returned object contains only `guest`. Fields `checkIn`, `nights`, `roomPrice`, `status` are lost. If the pipeline continues downstream this breaks everything.

**Fix:** Either spread `...p` or explicitly return the remaining fields.

