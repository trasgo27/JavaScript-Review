## Init block analysis

### `document.cookie`
Returns all cookies as a single string, e.g. `"modoOscuro=true; theme=dark; token=abc"`.

### `.split('; ')`
Splits that string into an **array** of individual cookie pairs, using `"; "` (semicolon + space) as the delimiter.

**Result:** `["modoOscuro=true", "theme=dark", "token=abc"]`

### `.find(row => row.startsWith('modoOscuro='))`
`find()` returns the **first array element** where the condition is `true`. The condition checks if the cookie string starts with `"modoOscuro="`.

**Result:** `"modoOscuro=true"` — or `undefined` if no match.

### `?.split('=')[1]`
The **optional chaining** (`?.`) only calls `.split()` if the previous result is not `null`/`undefined`. `.split('=')` breaks `"modoOscuro=true"` into `["modoOscuro", "true"]`. `[1]` takes the second element (the value).

**Result:** `"true"` — or `undefined` if the cookie wasn't found.

### Why `'; '` instead of `';'`?
`document.cookie` typically returns cookies separated by `"; "` (with a space). Using `'; '` avoids needing the `while` trim loop from your `getCookie` function. However, some browsers may vary — a more robust version would trim each entry.

## 2. Funciones de ayuda para Cookies (Helper Functions)

Las cookies en JavaScript se manejan como una única cadena de texto larga (`document.cookie`). Estas dos funciones automatizan el proceso de escribir y leer en esa cadena.

### Crear / Modificar Cookie (`setCookie`)

```javascript
function setCookie(name, value, days = 30) {
    const date = new Date();
    date.setTime(date.getTime() + (days * 24 * 60 * 60 * 1000));
    const expires = "; expires=" + date.toUTCString();
    document.cookie = name + "=" + (value || "") + expires + "; path=/; SameSite=Lax";
}

```

* **Parámetros:** Recibe el nombre de la cookie, su valor y los días de duración (por defecto, 30 días si no se especifica).
* **Cálculo del tiempo:** `date.getTime()` obtiene la hora actual en milisegundos. Se le suma el equivalente de los días en milisegundos ($días \times 24\text{ horas} \times 60\text{ min} \times 60\text{ seg} \times 1000\text{ ms}$).
* **Formateo de fecha:** Transforma esa fecha futura al formato estándar que entienden los navegadores (`.toUTCString()`).
* **Inyección en el navegador:** Construye la cadena de texto de la cookie de forma segura:
* `path=/`: Hace que la cookie sea accesible en cualquier página de tu sitio web.
* `SameSite=Lax`: Una medida de seguridad moderna que protege la cookie de ser enviada en solicitudes de terceros (protección CSRF).



### Leer Cookie (`getCookie`)

```javascript
function getCookie(name) {
    const nameEQ = name + "=";
    const ca = document.cookie.split(';');
    for(let i = 0; i < ca.length; i++) {
        let c = ca[i];
        while (c.charAt(0) == ' ') c = c.substring(1, c.length);
        if (c.indexOf(nameEQ) == 0) return c.substring(nameEQ.length, c.length);
    }
    return null;
}

```

Como `document.cookie` devuelve algo como `"cookie1=valor1; cookie2=valor2"`, esta función sirve para buscar una cookie concreta por su nombre:

* **`split(';')`**: Divide esa cadena larga en un array de cookies individuales.
* **`while (...) c.substring(...)`**: Limpia los espacios en blanco que suelen quedar delante de cada cookie tras el punto y coma.
* **`indexOf(nameEQ) == 0`**: Comprueba si la cookie actual empieza por el nombre que estamos buscando. Si la encuentra, extrae y devuelve únicamente su valor. Si termina el bucle y no encuentra nada, devuelve `null`.

## 3. Comprobación inicial al cargar la página

```javascript
const cookieModo = getCookie('modoOscuro');
if (cookieModo === 'si') {
    divPantalla.classList.add('modoOscuro');
    divPantalla.innerHTML = `<h2>Modo Oscuro PUESTO</h2>`;
    inputOscuro.checked = true;
} else {
    divPantalla.classList.remove('modoOscuro');
    divPantalla.innerHTML = `<h2>Modo Oscuro QUITADO</h2>`;
    inputOscuro.checked = false;
}

```

Este bloque se ejecuta de forma inmediata cuando el script se carga en el navegador:

1. Llama a `getCookie('modoOscuro')` para ver si el usuario ya había estado en la web y configurado su preferencia.
2. **Si la cookie vale `'si'**`: Añade la clase CSS `modoOscuro` al contenedor, actualiza el texto en pantalla y marca visualmente el *checkbox* como activado (`true`).
3. **Si no existe o vale cualquier otra cosa**: Se asegura de quitar la clase CSS, actualiza el texto indicando que está quitado y desmarca el *checkbox* (`false`).

## 4. Escucha de eventos (Interacción del usuario)

```javascript
inputOscuro.addEventListener('change', (e) => {
    if (e.target.checked) {
        divPantalla.classList.add('modoOscuro');
        divPantalla.innerHTML = `<h2>Modo Oscuro PUESTO</h2>`;
        setCookie('modoOscuro', 'si');
    } else {
        divPantalla.classList.remove('modoOscuro');
        divPantalla.innerHTML = `<h2>Modo Oscuro QUITADO</h2>`;
        setCookie('modoOscuro', 'no');
    }
});

```

Este bloque añade un "escuchador" que reacciona cada vez que el usuario cambia el estado del *checkbox* (hace clic en él):

* El parámetro `e` representa el evento del cambio, y `e.target.checked` devuelve `true` si el *checkbox* se acaba de activar o `false` si se acaba de desactivar.
* **Si se activa (`true`)**: Aplica los estilos visuales oscuros inmediatamente en el DOM y llama a `setCookie('modoOscuro', 'si')` para que el navegador recuerde la decisión en futuras visitas.
* **Si se desactiva (`false`)**: Retira los estilos oscuros del DOM y actualiza la cookie a `'no'`.
