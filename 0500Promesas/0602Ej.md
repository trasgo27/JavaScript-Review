# 0602Ej.js — Debug Report

**3 bugs found and fixed.**

### Bug 1 — `reject()` / `resolve()` called without definition (line 8, 14 → crash)

The function is an `async function`, not a `new Promise((resolve, reject) => ...)` callback. The names `resolve` and `reject` don't exist in scope.

> `ReferenceError: resolve / reject is not defined`

**Fix:** In an async function:
- **Reject** → `throw new Error('...')`
- **Resolve** → `return '...'`

### Bug 2 — `await setTimeout(...)` does not wait (line 13)

`setTimeout` returns a timer ID (number), not a Promise. `await` on a non-Promise resolves immediately, so the delay never happens.

**Fix:** Wrap `setTimeout` in a Promise:
```js
await new Promise(resolve => setTimeout(resolve, 3000));
```

### Bug 3 — `.try()` is not a Promise method (line 23 → crash)

Promises have `.then()`, `.catch()`, `.finally()`. There is no `.try()`.

> `TypeError: Promise(...).try is not a function`

**Fix:** Use `.then()` instead.

### El Planteamiento del Ejercicio: "Gestión de Descargas con Async/Await"

**Objetivo:** 1. Conserva la misma función lógica `descargarArchivo(nombreArchivo)` del ejercicio anterior que devuelve una Promesa con un `setTimeout` de 3 segundos.
2. Crea una **nueva función** declarada con la palabra clave **`async`** llamada `procesarFlujoDescargas()`.
3. Dentro de ella, utiliza el operador **`await`** para pausar la ejecución y esperar el resultado de la descarga.
4. Envuelve las llamadas en una estructura **`try...catch`** para capturar tanto los mensajes de éxito como los posibles errores.

---

### Resolución del Código

```javascript
// 1. Mantenemos la función constructora de la promesa original
function descargarArchivo(nombreArchivo) {
  return new Promise((resolve, reject) => {
    if (!nombreArchivo || nombreArchivo.trim() === "") {
      reject("Error: El nombre del archivo no puede estar vacío.");
      return;
    }

    console.log(`Iniciando descarga de: "${nombreArchivo}"...`);

    setTimeout(() => {
      resolve(`¡Éxito! El archivo "${nombreArchivo}" se ha bajado correctamente.`);
    }, 3000); 
  });
}

// 2. NUEVA FUNCIÓN ASÍNCRONA PARA CONTROLAR EL FLUJO
async function procesarFlujoDescargas() {
  try {
    console.log("--- INICIO DE LAS PETICIONES ---");

    // El operador 'await' pausa la función hasta que la promesa se resuelve.
    // El valor que viaja dentro de 'resolve()' se asigna directamente a la constante.
    const resultado1 = await descargarArchivo("manual_angular.pdf");
    console.log(resultado1); // Se ejecuta a los 3 segundos

    const resultado2 = await descargarArchivo("ejercicios_javascript.zip");
    console.log(resultado2); // Se ejecuta a los 6 segundos (3s después del primero)

    console.log("--- Intentando descargar un archivo inválido ---");
    // Al provocar un error, la promesa llamará a 'reject()'.
    // En ese mismo instante, el código salta directamente al bloque 'catch'.
    const resultadoInvalido = await descargarArchivo("");
    console.log(resultadoInvalido); // Esta línea NUNCA se llegará a ejecutar

  } catch (error) {
    // Cualquier 'reject()' de las promesas anteriores es capturado aquí automáticamente
    console.error(`Se ha capturado una excepción: ${error}`);
  } finally {
    console.log("--- PROCESO FINALIZADO ---");
  }
}

// 3. EJECUCIÓN DE LA FUNCIÓN ASÍNCRONA
procesarFlujoDescargas();

```

### Conceptos clave para tu examen basados en este ejercicio:

* **¿Dónde se captura el error?** Como vimos en las preguntas del test, las promesas rechazadas dentro de un bloque `async/await` no usan `.catch()`, sino que se capturan en el bloque **`catch(error)`** de la estructura tradicional `try...catch`, exactamente igual que si fuera una excepción síncrona del lenguaje.
* **Comportamiento Secuencial:** Nota que `resultado2` espera obligatoriamente a que termine `resultado1`. El tiempo total de ejecución de las dos descargas correctas consecutivas será de **6 segundos**. Si hubiéramos querido lanzarlas en paralelo para que tardaran solo 3 segundos en total, habríamos combinado este flujo con un `await Promise.all([...])`.
* **Retorno implícito:** Recuerda que por el mero hecho de ponerle la palabra clave `async` a `procesarFlujoDescargas()`, esa función ahora devuelve de forma automática e implícita una nueva `Promise`.
