## 2026-07-16 — Preposiciones + Revisión

### Preposiciones (Prepositions)

- **to / at / for (direction)** → **a** (llegó **a** la oficina, viajé **a** Madrid)
- **from / of / about** → **de** (soy **de** México, hablé **de** diseños)
- **in / on / at (place/time)** → **en** (vive **en** Barcelona, **en** solo dos días)
- **through / because of / for (exchange)** → **por** (caminé **por** el parque, pagué **por** la cena)
- **to (purpose) / for (recipient) / for (deadline)** → **para** (estudio **para** aprobar, regalo **para** ti)
- **with** → **con** (fui al cine **con** mis amigos)
- **without** → **sin** (salí de casa **sin** llaves)
- **on (surface) / about (topic)** → **sobre** (libro **sobre** la mesa, hablamos **sobre** moda)
- **between / among** → **entre** (mi casa **entre** la farmacia y el banco)
- **since / from (starting point)** → **desde** (trabajo **desde** las ocho)
- **until / as far as** → **hasta** (estudié **hasta** las diez)

### Vocabulario nuevo (New Vocabulary)

- **to drip** → **gotear / gotear** (La botella gotea = The bottle drips)
- **discussion / argument** → **discusión** (un tema de discusión = a topic of discussion)
- **to argue / to discuss** → **discutir** (Ellos discutieron toda la tarde)
- **to relax** → **relajarse** (Me gusta pasear para relajarme)
- **dirty** → **sucio / sucia** (Mi barrio está muy sucio)
- **package** → **paquete** (Entregué el paquete al cliente)
- **midnight** → **medianoche** (Trabajé hasta la medianoche)
- **predefined** → **predefinido / predefinida** (Patrones predefinidos)
- **accessories** → **accesorios** (La colección va de vestidos a accesorios)
- **to distribute / to share** → **repartir** (Repartí el pastel entre los invitados)
- **to deliver** → **entregar** (Entregué el paquete al cliente)

### Expresiones clave (Key Expressions)

- **Entre tú y yo** → Between you and me (very common expression)
- **De... a...** → From... to... (de las 6 a las 10, de 100 a 500 euros)
- **Desde... hasta...** → Since... until... (desde enero hasta marzo)
- **A través de** → Through (A través de la práctica = Through practice)
- **Sin + infinitivo** → Without + -ing (Estudié sin descansar = I studied without resting)

## 2026-07-03 — Primera Clase

### Vocabulario difícil (Difficult Vocabulary)

- **worried** → **preocupado / preocupada** (Estoy preocupado por el problema)
- **broken** → **roto** (El móvil está roto)
- **nowadays** → **hoy en día** (Hoy en día, la gente trabaja desde casa)
- **all the time** → **todo el rato** (Él habla todo el rato)
- **so-so / neither good nor bad** → **ni fu, ni fa** (Me siento ni fu, ni fa)
- **doll / wrist** → **muñeca** (same word! La muñeca está en la estantería / Me lastimé la muñeca)
- **too much** → **demasiado** (Hay demasiado ruido)
- **a lot of** → **mucho** (Bebo mucho café)
- **notebook** → **libreta** (not "notebook" — Necesito mi libreta)
- **to focus** → **enfocar** (Vamos a enfocar la idea principal)
- **calm / quiet** → **tranquilo / tranquila** (No te preocupes, ¡tranquilo!)
- **I hear** → **oigo** (No oigo bien = I can't hear well)
- **I'm able to hear** → **puedo oír** (No puedo oír la música)
