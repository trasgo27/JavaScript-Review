01 - Lo Básico de Angular

Objetivo del módulo: Comprender los fundamentos de Angular: cómo se estructuran los componentes, cómo se enlazan datos con la plantilla y cómo se manejan eventos del usuario.

Tiempo estimado: 3-4 horas

Conceptos Clave

  • Estructura de un proyecto Angular y el rol de los componentes
  • El decorador @Component y sus propiedades principales (selector, template, styles)
  • Interpolación de datos con {{ }}
  • Property Binding: enlazar propiedades del DOM a variables del componente
  • Event Binding: escuchar eventos del usuario con ( )
  • Control Flow moderno: @if, @for, @switch
  • Directivas de atributo: ngClass y ngStyle
01Mi Primer Componente ⭐
Objetivo
Crear un componente Angular funcional que muestre información básica en pantalla.
Enunciado
Genera un componente llamado perfil-usuario que muestre nombre, edad y una breve biografía. El componente debe renderizarse correctamente en la aplicación.
Requisitos
  • Usa ng generate component perfil-usuario o créalo manualmente
  • El decorador @Component debe tener selector, standalone: true, template y styles
  • Declara al menos 3 propiedades con valores
  • Muestra las propiedades en el template usando interpolación
Recuerda que un componente standalone no necesita declararse en ningún módulo. Solo impórtalo directamente donde se use.
02Interpolación de Datos ⭐⭐
Objetivo
Practicar el uso de interpolación para mostrar datos dinámicos en el template.
Enunciado
Crea un componente calculadora-perfil que reciba un nombre y calcule automáticamente la edad en días, meses aproximados y años. Muestra todos los valores en la plantilla.
Requisitos
  • Define propiedades para nombre, edad en años, y calcula los demás valores
  • Usa interpolación {{ }} para mostrar cada valor
  • Permite expresiones simples dentro de la interpolación (ej. multiplicación)
  • El template debe mostrar una tarjeta con toda la información formateada
Dentro de {{ }} puedes usar expresiones JavaScript como multiplicaciones, concatenaciones y llamadas a métodos del componente.
03Property Binding con Imágenes ⭐⭐
Objetivo
Controlar atributos HTML del DOM mediante property binding.
Enunciado
Crea un componente galeria-avatar que muestre una imagen cuyo src, alt y width se controlen dinámicamente desde el componente. Agrega un botón que cambie la imagen mostrada.
Requisitos
  • Usa [src], [alt] y [width] en el template
  • Define un array con al menos 3 objetos de imágenes (url, texto alternativo, ancho)
  • Un botón debe alternar entre las imágenes del array
  • El atributo disabled del botón debe desactivarse cuando no haya más imágenes
Para alternar entre imágenes usa un índice que se incremente con cada clic. Cuando el índice supere la longitud del array, vuelve al inicio o desactiva el botón con [disabled].
04Event Binding Interactivo ⭐⭐
Objetivo
Capturar eventos del usuario y responder a ellos actualizando el estado del componente.
Enunciado
Crea un componente contador-clicks que muestre un botón y un contador. Cada vez que el usuario haga clic, el contador aumenta. Agrega un segundo botón para reiniciar y muestra un mensaje especial cuando el contador supere 10.
Requisitos
  • Usa (click) para manejar los clics
  • El contador debe mostrarse con interpolación
  • Cuando el contador sea mayor a 10, muestra un mensaje de "logro desbloqueado"
  • El botón de reiniciar debe volver el contador a 0
Define un método incrementar() y otro reiniciar() en el componente. Usa una propiedad contador para almacenar el estado.
05Input y Teclado ⭐⭐⭐
Objetivo
Capturar valores de entrada de texto y responder a eventos de teclado en tiempo real.
Enunciado
Crea un componente buscador-sencillo con un campo de texto. Muestra en tiempo real lo que el usuario escribe y un contador de caracteres. Cuando el texto supere 50 caracteres, muestra una alerta visual.
Requisitos
  • Usa (input) o (keyup) para capturar cada pulsación
  • Muestra el texto ingresado debajo del campo
  • El contador de caracteres se actualiza en cada tecla
  • Cuando supere 50 caracteres, aplica un estilo rojo al contador
El evento (input) se dispara en cada cambio del campo. Accede al valor con $event.target.value o usa una referencia de template con #ref.
06Lista de Tareas con @for ⭐⭐⭐
Objetivo
Renderizar listas dinámicas usando la directiva de control flow @for.
Enunciado
Crea un componente lista-tareas que muestre una lista de tareas predefinidas. Cada tarea debe tener un título y un estado (completada/pendiente). Permite marcar tareas como completadas y eliminarlas de la lista.
Requisitos
  • Usa @for (tarea of tareas; track tarea.id) para iterar
  • Incluye un bloque @empty para mostrar un mensaje cuando no haya tareas
  • Al hacer clic en una tarea, alterna su estado completada
  • Un botón "Eliminar" al lado de cada tarea la remueve del array
Para que @for funcione correctamente, cada elemento necesita un identificador único para el track. Usa track tarea.id o track tarea.
07Formulario Condicional con @if ⭐⭐⭐
Objetivo
Usar la directiva @if para mostrar u ocultar elementos del DOM condicionalmente.
Enunciado
Crea un componente formulario-registro con campos de nombre, email y contraseña. La contraseña solo se muestra cuando el usuario hace clic en un ojo. El botón de envío solo se activa cuando todos los campos tienen contenido.
Requisitos
  • Usa @if para mostrar/ocultar la contraseña
  • Usa @if con una condición para habilitar/deshabilitar el botón
  • Incluye un ícono o texto que indique el estado de visibilidad
  • El campo de contraseña debe ser de tipo text o password según el estado
Define una propiedad booleana mostrarPassword que se alterne con cada clic del ojo. La condición del botón requiere verificar que las tres propiedades tengan contenido (longitud mayor a 0).
08Selector con @switch ⭐⭐⭐
Objetivo
Usar la directiva @switch para renderizar contenido diferente según un valor.
Enunciado
Crea un componente panel-temas con un selector que permita elegir entre 4 temas (claro, oscuro, azul, verde). Según la selección, el fondo del panel cambia de color y se muestra un mensaje descriptivo diferente.
Requisitos
  • Usa @switch (temaActual) con @case para cada tema
  • Incluye un @default por si el valor no coincide
  • Cada tema debe cambiar tanto el color de fondo como el texto descriptivo
  • Los botones de selección deben usar (click) para cambiar el tema
@switch funciona similar a switch-case de JavaScript. Define una propiedad temaActual de tipo string y compárala con cada valor posible.
09ngClass y ngStyle Dinámicos ⭐⭐⭐⭐
Objetivo
Aplicar estilos condicionales y dinámicos usando las directivas ngClass y ngStyle.
Enunciado
Crea un componente tarjeta-estado que muestre una tarjeta con un título y varias propiedades visuales. El usuario puede cambiar entre 3 estados (normal, destacado, deshabilitado), y cada estado altera clases CSS, colores de borde y opacidad.
Requisitos
  • Usa [ngClass] para aplicar clases condicionalmente según el estado
  • Usa [ngStyle] para controlar color de borde y opacidad
  • Define al menos 3 clases CSS en el componente (para cada estado)
  • Incluye botones para alternar entre los estados
[ngClass] acepta un objeto donde las claves son nombres de clase y los valores son booleanos. Ejemplo: [ngClass]="{'activo': estaActivo, 'inactivo': !estaActivo}"
10Tarjeta de Producto Interactiva ⭐⭐⭐⭐
Objetivo
Combinar interpolación, property binding, event binding, directivas de control flow y ngClass/ngStyle en un solo componente coherente.
Enunciado
Crea un componente tarjeta-producto que muestre información de un producto (nombre, precio, imagen, descripción, stock). El componente debe permitir agregar al carrito, mostrar un badge de "agotado" cuando no haya stock, y resaltarse visualmente cuando el mouse está encima.
Requisitos
  • Usa interpolación para nombre, precio y descripción
  • Usa [src] para la imagen del producto
  • Usa @if para mostrar el badge de agotado
  • Usa [disabled] en el botón cuando no haya stock
  • Usa (mouseenter) y (mouseleave) para el efecto de resaltado
  • Usa [ngStyle] para la opacidad del botón según el stock
Este ejercicio combina todo lo anterior. Empieza por la estructura estática del template y ve añadiendo la funcionalidad dinámica paso a paso: primero interpolación, luego bindings, luego directivas.
11Mini Dashboard con Estadísticas ⭐⭐⭐⭐⭐
Objetivo
Construir un mini-panel de control que combine múltiples conceptos básicos en un diseño profesional.
Enunciado
Crea un componente dashboard-stats que muestre 4 tarjetas de estadísticas (usuarios, ventas, pedidos, ingresos). Cada tarjeta debe tener un icono, un valor numérico y un porcentaje de cambio. El usuario puede ordenar las tarjetas y filtrar solo las que tengan cambio positivo.
Requisitos
  • Define un array de objetos con las 4 estadísticas
  • Usa @for para renderizar las tarjetas
  • Usa @if para mostrar flechas de subida/bajada según el porcentaje
  • Usa [ngClass] para colorear el porcentaje (verde si positivo, rojo si negativo)
  • Un botón de filtrado que muestre/oculte elementos negativos
  • Un botón de ordenamiento que ordene por valor
Usa .filter() y .sort() del array de estadísticas. El filtrado puede hacerse directamente en el template con un método que retorne el array filtrado, o con una señal/variable que se actualice.
