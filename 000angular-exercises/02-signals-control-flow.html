02 - Signals y Control Flow

Objetivo del módulo: Dominar el sistema de Signals de Angular para manejar estado reactivo de forma simple y eficiente, combinándolo con el control flow moderno.

Tiempo estimado: 3-4 horas

Conceptos Clave

  • signal(): crear señales reactivas que contienen un valor
  • Lectura de señales con () en el template y en el componente
  • Actualización con .set(), .update() y .mutate()
  • computed(): derivar valores que dependen de otras señales
  • effect(): ejecutar efectos secundarios cuando cambian las señales
  • Señales como reemplazo moderno de los Observables simples
01Primera Signal ⭐
Objetivo
Crear y leer una señal básica en Angular.
Enunciado
Crea un componente mi-contador que use una signal para almacenar un número. Muestra el valor de la signal en el template y actualízalo con botones de incremento y decremento.
Requisitos
  • Importa signal desde @angular/core
  • Crea una signal con signal<number>(0)
  • Lee la signal en el template con contador()
  • Usa .update() para incrementar y decrementar
La diferencia clave entre signal y variable normal es que al usar .update() o .set(), Angular sabe que debe re-renderizar las partes del template que usan esa signal.
02Computed: Valores Derivados ⭐⭐
Objetivo
Crear valores derivados automáticamente a partir de señales existentes.
Enunciado
Crea un componente carrito-compras con una signal que contenga un array de productos. Usa computed() para calcular automáticamente el total, el número de items y el item más caro.
Requisitos
  • Define una signal productos con un array de objetos (nombre, precio, cantidad)
  • Crea un computed() para total
  • Crea un computed() para cantidadItems
  • Crea un computed() para productoMasCaro
  • Agrega y elimina productos y verifica que los computed se actualicen
computed() es readonly y se recalcula automáticamente. No necesitas llamarlo manualmente. Solo funciona si se leen dentro de un contexto reactivo (template o effect).
03Effect: Efectos Secundarios ⭐⭐
Objetivo
Ejecutar código automáticamente cuando cambian las señales, usando effect().
Enunciado
Crea un componente tema-dinamico con una signal tema que puede ser "claro" u "oscuro". Usa effect() para aplicar automáticamente una clase al body del documento cuando cambie el tema.
Requisitos
  • Define una signal tema con valor inicial "oscuro"
  • Usa effect() para agregar/quitar la clase dark-mode en document.body
  • Un botón alterna entre "claro" y "oscuro"
  • El efecto se ejecuta cada vez que cambia la signal
effect() se ejecuta automáticamente después del primer render y cada vez que cualquier signal leída dentro de él cambia. Usa inject(Injector) para注册 el effect si es necesario en el constructor.
04Actualización con .update() ⭐⭐
Objetivo
Practicar las diferentes formas de actualizar una signal: .set(), .update() y .mutate().
Enunciado
Crea un componente gestor-lista con una signal que contenga una lista de números. Implementa 3 botones: uno que reemplace toda la lista (.set()), uno que agregue un número al final (.update()) y uno que duplique todos los valores existentes.
Requisitos
  • Signal tipo signal<number[]>([1, 2, 3])
  • Botón "Reiniciar" usa .set([1, 2, 3])
  • Botón "Agregar" usa .update(prev => [...prev, nuevoNumero])
  • Botón "Duplicar" usa .update(prev => prev.map(n => n * 2))
  • Muestra la lista con @for
.set() reemplaza el valor completamente. .update() recibe el valor anterior y retorna el nuevo. Para arrays, siempre crea una nueva referencia (spread o map) en lugar de mutar directamente.
05Señales con Objetos Complejos ⭐⭐⭐
Objetivo
Manejar señales que contienen objetos anidados y arrays de objetos.
Enunciado
Crea un componente perfil-usuario-signal con una signal que contenga un objeto usuario (nombre, email, preferencias: { tema, idioma }). Permite actualizar cada campo individualmente y muestra las preferencias con computed.
Requisitos
  • Signal con objeto { nombre, email, preferencias: { tema, idioma } }
  • Usa .update() con spread para crear nuevos objetos sin mutar el original
  • Crea computed para resumenPerfil que combine nombre y tema
  • Permite cambiar tema e idioma independientemente
Para objetos anidados, usa spread en cada nivel: .update(prev => ({ ...prev, preferencias: { ...prev.preferencias, tema: 'oscuro' } }))
06Toggle y Estado con Signals ⭐⭐⭐
Objetivo
Implementar patrones comunes de UI usando signals para el estado.
Enunciado
Crea un componente acordeon con 4 secciones colapsables. Solo una sección puede estar abierta a la vez. Usa signals para controlar qué sección está activa y muestra el contenido con transiciones.
Requisitos
  • Array de secciones con título y contenido (signal)
  • Signal seccionActiva con el índice de la sección abierta (o -1 para cerrar todas)
  • Al hacer clic en una sección, alterna su estado
  • Usa @if para mostrar/ocultar el contenido
  • Aplica una clase CSS activa a la sección abierta
Para que solo una sección esté abierta, guarda el índice en la signal. Si el índice clickeado es igual al actual, cierra (-1); si no, abre el nuevo.
07Timer con Signals y Effect ⭐⭐⭐
Objetivo
Crear un cronómetro que use signals para el estado y effect para los efectos secundarios.
Enunciado
Crea un componente cronometro con un timer que muestre minutos:segundos:centésimas. Tiene botones de iniciar, pausar y reiniciar. Usa effect() para actualizar el título del documento con el tiempo actual.
Requisitos
  • Signals para: tiempo (en centésimas), ejecutándose (boolean), intervalo ID
  • effect() que actualice document.title con el tiempo formateado
  • Botones de iniciar/pausar que usen setInterval y clearInterval
  • Reiniciar que ponga todo a cero
  • Formato de visualización: MM:SS:CC
Para el intervalo, almacena el ID del setInterval en una signal. En el effect, actualiza el título. Al pausar, limpia el intervalo con clearInterval.
08Filtros con Computed ⭐⭐⭐⭐
Objetivo
Usar múltiples signals y computed para crear un sistema de filtrado interactivo.
Enunciado
Crea un componente catalogo-filtrable con una lista de productos. Tiene signals para el texto de búsqueda, el rango de precio y la categoría seleccionada. Usa computed para calcular los resultados filtrados en tiempo real.
Requisitos
  • Array de al menos 10 productos con nombre, precio y categoría
  • Signals: busqueda, precioMinimo, precioMaximo, categoria
  • Un computed() que combine todos los filtros y retorne los productos que cumplan todas las condiciones
  • Un computed() que cuente cuántos resultados hay
  • Input de búsqueda, sliders de precio y selector de categoría
Dentro del computed(), encadena filtros: primero filtra por categoría, luego por precio, luego por texto. Recuerda que el computed se recalcula cuando cualquiera de las signals leídas cambia.
09Formulario con Signals ⭐⭐⭐⭐
Objetivo
Implementar un formulario completo usando signals como reemplazo de ngModel o formularios reactivos.
Enunciado
Crea un componente registro-signal con un formulario de registro (nombre, email, contraseña, confirmar contraseña). Valida en tiempo real usando signals y computed, y muestra errores debajo de cada campo.
Requisitos
  • Signals para cada campo del formulario
  • computed() para errores que verifique: nombre requerido, email válido, contraseña mínima 8 caracteres, contraseñas coincidentes
  • computed() para formularioValido que sea true solo si no hay errores
  • Botón de envío habilitado solo cuando el formulario es válido
  • Al enviar, muestra un mensaje de éxito y reinicia el formulario
Crea un computed() que retorne un objeto con los errores de cada campo. Cada error es un string o null. El formulario es válido cuando todos los valores del objeto de errores son null.
10Simulador de E-Commerce ⭐⭐⭐⭐⭐
Objetivo
Construir un mini simulador de e-commerce que use signals, computed y effect de forma integrada.
Enunciado
Crea un componente tienda-signal que muestre productos disponibles, un carrito de compras y un resumen de pedido. El usuario puede agregar/quitar productos, aplicar un cupón de descuento y ver el total actualizado en tiempo real. Usa effect() para guardar el carrito en localStorage.
Requisitos
  • Signals: productos (catálogo), carrito (array de items), cupon (string), descuentoAplicado (boolean)
  • computed() para total, totalConDescuento, cantidadCarrito
  • effect() que guarde el carrito en localStorage cada vez que cambie
  • Al cargar el componente, lee localStorage para restaurar el carrito
  • Productos con nombre, precio e imagen
  • Al aplicar cupón válido, muestra 10% de descuento
Para restaurar el carrito desde localStorage, lee el valor al crear la signal inicial. Para el effect de guardado, usa effect(() => localStorage.setItem('carrito', JSON.stringify(this.carrito()))).
