# Resumen de Objetos Predefinidos — Propiedades y Métodos

## 1. String

| Propiedad | Descripción |
|-----------|-------------|
| `length` | Longitud de la cadena |
| `prototype` | Permite añadir propiedades/métodos al objeto String |

| Método | Descripción | Ejemplo |
|--------|-------------|---------|
| `charAt(pos)` | Carácter en la posición `pos` | `"hola".charAt(0)` → `"h"` |
| `charCodeAt(pos)` | Código Unicode del carácter en `pos` | `"a".charCodeAt(0)` → `97` |
| `includes(sub)` | ¿Contiene `sub`? | `"Hola".includes("ol")` → `true` |
| `indexOf(sub)` | Índice de primera aparición o `-1` | `"Hola".indexOf("a")` → `3` |
| `slice(inicio, fin)` | Extrae substring (fin excluido) | `"JavaScript".slice(0,4)` → `"Java"` |
| `split(sep)` | Divide en array por `sep` | `"a/b/c".split('/')` → `["a","b","c"]` |
| `toLowerCase()` | Minúsculas | `"HOLA".toLowerCase()` → `"hola"` |
| `toUpperCase()` | Mayúsculas | `"hola".toUpperCase()` → `"HOLA"` |
| `trim()` | Elimina espacios extremos | `"  hola  ".trim()` → `"hola"` |
| `replace(buscar, nuevo)` | Reemplaza primera coincidencia | `"a_a".replace('_',' ')` → `"a a"` |
| `replaceAll(buscar, nuevo)` | Reemplaza todas las coincidencias | `"a_a".replaceAll('_',' ')` → `"a a"` |
| `startsWith(sub)` | ¿Empieza por `sub`? | `"Hola".startsWith("Ho")` → `true` |
| `endsWith(sub)` | ¿Termina por `sub`? | `"Hola".endsWith("la")` → `true` |
| `localeCompare(str)` | Comparación localizada (-1, 0, 1) | `"a".localeCompare("b")` → `-1` |
| `substring(inicio, fin)` | Similar a `slice` (no acepta negativos) | `"Hola".substring(1,3)` → `"ol"` |

> **Autoboxing**: Al llamar métodos sobre un primitivo string, JS lo envuelve temporalmente en un objeto `String`, ejecuta el método y lo destruye.

## 2. Number

| Valor Especial | Descripción |
|----------------|-------------|
| `Infinity` | Supera la precisión máxima del lenguaje |
| `NaN` | *Not a Number* — operación no numérica (`3 * "a"`) |

| Método | Descripción | Ejemplo |
|--------|-------------|---------|
| `toFixed(n)` | Formatea a `n` decimales (devuelve `string`) | `(3.1).toFixed(2)` → `"3.10"` |
| `toString(base)` | Convierte a string en base `base` | `(255).toString(16)` → `"ff"` |
| `Number.parseInt(str)` | Entero desde string | `Number.parseInt("42px")` → `42` |
| `Number.parseFloat(str)` | Decimal desde string | `Number.parseFloat("3.14€")` → `3.14` |
| `Number.isInteger(val)` | ¿Es entero? | `Number.isInteger(3.5)` → `false` |
| `Number.isNaN(val)` | ¿Es NaN? (más robusto que `isNaN()`) | `Number.isNaN(NaN)` → `true` |
| `Number.isFinite(val)` | ¿Es finito? | `Number.isFinite(Infinity)` → `false` |

> Notaciones: decimal, binario (`0b`), octal, hexadecimal (`0x`).
> `.toFixed()` devuelve **string**. Para operar, convertirlo con `Number()`.

## 3. Math

| Propiedad | Descripción |
|-----------|-------------|
| `Math.E` | Número de Euler (~2.718) |
| `Math.PI` | Pi (~3.1416) |
| `Math.SQRT2` | Raíz cuadrada de 2 (~1.414) |
| `Math.LN2` | Logaritmo natural de 2 |

| Método | Descripción | Ejemplo |
|--------|-------------|---------|
| `abs(x)` | Valor absoluto | `Math.abs(-5)` → `5` |
| `pow(x, y)` | x elevado a y | `Math.pow(2, 3)` → `8` |
| `sqrt(x)` | Raíz cuadrada | `Math.sqrt(9)` → `3` |
| `random()` | Aleatorio [0, 1) | `Math.random()` → `0.234...` |
| `round(x)` | Redondeo clásico (≥.5 arriba) | `Math.round(4.5)` → `5` |
| `ceil(x)` | **Techo** — hacia arriba siempre | `Math.ceil(4.1)` → `5` |
| `floor(x)` | **Suelo** — hacia abajo siempre | `Math.floor(4.9)` → `4` |
| `trunc(x)` | Trunca decimales (sin redondeo) | `Math.trunc(4.9)` → `4` |
| `max(a, b, ...)` | Valor máximo | `Math.max(1, 5, 3)` → `5` |
| `min(a, b, ...)` | Valor mínimo | `Math.min(1, 5, 3)` → `1` |

> **Sin constructor** — `new Math()` no existe. Se usa como objeto estático.

## 4. Date

| Constructor | Descripción |
|-------------|-------------|
| `new Date()` | Fecha/hora actual |
| `new Date("YYYY-MM-DD")` | Desde string ISO (UTC midnight) |
| `new Date(year, monthIndex, day)` | Desde números (month 0-indexed) |

| Getter | Devuelve | Rango |
|--------|----------|-------|
| `getFullYear()` | Año (4 dígitos) | ej. `2026` |
| `getMonth()` | Mes | **0–11** (0=Enero) |
| `getDate()` | Día del mes | 1–31 |
| `getDay()` | Día de la semana | **0–6** (0=Domingo) |
| `getHours()` | Horas | 0–23 |
| `getMinutes()` | Minutos | 0–59 |
| `getSeconds()` | Segundos | 0–59 |
| `getTime()` | Milisegundos desde 01/01/1970 UTC | |

| Setter | Descripción |
|--------|-------------|
| `setDate(n)` | Establece día del mes (soporta overflow) |
| `setFullYear(n)` | Establece año |
| `setMonth(n)` | Establece mes (0-indexed) |
| `setTime(ms)` | Establece timestamp |

| Conversión | Descripción |
|------------|-------------|
| `toLocaleDateString()` | Fecha local (`"14/6/2026"`) |
| `toLocaleTimeString()` | Hora local (`"12:30:00"`) |
| `toLocaleString()` | Fecha y hora local |
| `toUTCString()` | Fecha en UTC |
| `toISOString()` | ISO 8601 (`"2026-06-14T00:00:00.000Z"`) |

> **Truco con fechas:**
> - Sumar días: `date.setDate(date.getDate() + n)` — maneja cambio de mes/año automáticamente.
> - Restar fechas: `date1 - date2` → milisegundos. Dividir por `(1000*60*60*24)` para días.
> - Meses empiezan en **0** (Enero) y terminan en **11** (Diciembre).
> - `"YYYY-MM-DD"` se parsea como UTC midnight → posible desplazamiento horario local.

## 5. RegExp

| Sintaxis | Descripción |
|----------|-------------|
| `/patron/modificadores` | Literal (recomendado) |
| `new RegExp("patron", "mod")` | Constructor |

### Modificadores (flags)

| Flag | Nombre | Efecto |
|------|--------|--------|
| `i` | Case-insensitive | Ignora mayúsculas/minúsculas |
| `g` | Global | Busca todas las coincidencias |
| `m` | Multiline | `^` y `$` por línea |

### Metacaracteres

| Clase | Significado |
|-------|-------------|
| `.` | Cualquier carácter (excepto salto de línea) |
| `\d` | Dígito `[0-9]` |
| `\D` | No dígito |
| `\w` | Palabra `[a-zA-Z0-9_]` |
| `\W` | No palabra |
| `\s` | Espacio en blanco |
| `\S` | No espacio |

### Anclas

| Ancla | Significado |
|-------|-------------|
| `^` | Inicio de string (o línea con `m`) |
| `$` | Fin de string (o línea con `m`) |
| `\b` | Límite de palabra |

### Cuantificadores

| Cuantificador | Significado |
|---------------|-------------|
| `*` | 0 o más |
| `+` | 1 o más |
| `?` | 0 o 1 (opcional) |
| `{n}` | Exactamente `n` |
| `{n,}` | `n` o más |
| `{n,m}` | Entre `n` y `m` |

### Grupos y Rangos

| Sintaxis | Significado |
|----------|-------------|
| `[abc]` | Cualquier carácter del conjunto |
| `[^abc]` | Cualquier carácter NO del conjunto |
| `[a-z]` | Rango |
| `(abc)` | Grupo capturador |
| `\|` | OR |

### Métodos

| Método | Pertenece a | Descripción |
|--------|-------------|-------------|
| `regex.test(str)` | RegExp | `true`/`false` si cumple el patrón |
| `regex.exec(str)` | RegExp | Array con coincidencias o `null` |
| `str.match(regex)` | String | Array con coincidencias o `null` |
| `str.search(regex)` | String | Índice de la coincidencia o `-1` |
| `str.replace(regex, str)` | String | Reemplaza coincidencia(s) |
| `str.split(regex)` | String | Divide por el patrón |

## 6. Bonus: Métodos de Array usados en ejercicios

| Método | Descripción |
|--------|-------------|
| `map(fn)` | Transforma cada elemento → nuevo array |
| `filter(fn)` | Filtra según condición booleana |
| `reduce(fn, inicio)` | Acumula valores → un solo resultado |
| `sort(fn)` | Ordena (in-place) según comparador |
| `join(sep)` | Une elementos con separador → string |
| `includes(val)` | ¿Array contiene `val`? |
| `indexOf(val)` | Índice de `val` o `-1` |

> **⚠️ `sort()` con números**: Por defecto convierte a **string** → `[1, 10, 2].sort()` → `[1, 10, 2]`.
> Usar función comparadora:
> - Ascendente: `arr.sort((a, b) => a - b)`
> - Descendente: `arr.sort((a, b) => b - a)`
> - Con objetos: `arr.sort((a, b) => a.propiedad - b.propiedad)`

### Formas de usar `sort()`

| Modo | Código | Ejemplo |
|------|--------|---------|
| **Por defecto** (string) | `arr.sort()` | `[1, 10, 2]` → `[1, 10, 2]` |
| **Numérico ascendente** | `arr.sort((a,b) => a - b)` | `[1, 10, 2]` → `[1, 2, 10]` |
| **Numérico descendente** | `arr.sort((a,b) => b - a)` | `[1, 10, 2]` → `[10, 2, 1]` |
| **String localizado** | `arr.sort((a,b) => a.localeCompare(b))` | `["ñ","a"]` → `["a","ñ"]` |
| **String case-insensitive** | `arr.sort((a,b) => a.toLowerCase().localeCompare(b.toLowerCase()))` | |
| **Por propiedad numérica** | `arr.sort((a,b) => a.edad - b.edad)` | ordena objetos por `edad` |
| **Por propiedad string** | `arr.sort((a,b) => a.name.localeCompare(b.name))` | ordena objetos por `name` |
| **Descendente por propiedad** | `arr.sort((a,b) => b.precio - a.precio)` | |
| **Criterios múltiples** | `arr.sort((a,b) => a.edad - b.edad \|\| a.name.localeCompare(b.name))` | 1º edad, 2º nombre |
| **Aleatorio** | `arr.sort(() => Math.random() - 0.5)` | barajar array |

> `sort()` **muta** el array original. Para evitarlo: `[...arr].sort(...)`.
