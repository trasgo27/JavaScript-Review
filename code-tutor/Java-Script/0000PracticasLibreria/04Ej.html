Your Task:

Write an async function called iniciarSesion(username, password) that does the following:

Calls getAuthToken to get a token.
Uses that token to call getUserProfile to get the user's data.
Uses the user's id from the profile to call getUserPosts to get their posts.
Prints the final posts to the console.
Uses a try...catch block to catch and print any errors that might happen at any step in the chain.

Finally, call your function twice: once with the correct credentials ("admin", "1234") and once with incorrect credentials ("admin", "wrong") to test the error handling.
