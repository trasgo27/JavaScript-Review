### 📋 Debug Report for `03Ej`

1. **Incorrect Checkbox State Logic (Critical)**
   * **Issue:** The event handler used `e.target.value === 'oscuro'` to determine if the checkbox was toggled. In HTML, a checkbox's `.value` remains constant (in this case, `"oscuro"`) whether it is checked or unchecked. Thus, the statement was always evaluated as `true`, rendering the toggle dysfunctional.
   * **Fix:** Replaced `e.target.value === 'oscuro'` with `e.target.checked`, which returns a proper boolean (`true` / `false`) representing the checkbox's state.

2. **Missing Cookie Handlers & Storage Implementation**

## Explanation of `getCookie(name)`

```js
function getCookie(name) {
    const nameEQ = name + "=";           // 1
    const ca = document.cookie.split(';'); // 2
    for(let i = 0; i < ca.length; i++) {   // 3
        let c = ca[i];                     // 4
        while (c.charAt(0) == ' ')         // 5
            c = c.substring(1, c.length);  // 6
        if (c.indexOf(nameEQ) == 0)        // 7
            return c.substring(nameEQ.length, c.length); // 8
    }
    return null;                           // 9
}
```

| Step | What it does |
|------|-------------|
| **1** | Prepares the search key, e.g. `"modoOscuro="` |
| **2** | `document.cookie` returns all cookies as one string like `"modoOscuro=si; theme=dark"`. Splitting by `;` gives `["modoOscuro=si", " theme=dark"]` |
| **3–4** | Loops through each cookie pair |
| **5–6** | Trims leading spaces — `document.cookie` may have spaces after `;` |
| **7** | Checks if this cookie starts with the target name (e.g. `"modoOscuro="`) |
| **8** | Extracts the value portion — everything after `"modoOscuro="` |
| **9** | If no match found, returns `null` |

**Example:** `getCookie('modoOscuro')` on `"modoOscuro=si; theme=dark"` → `"si"`.

## Debug Report — `getCookie` bugs (regression)

Three bugs were introduced after rewriting `getCookie`:

### Bug 1 (Critical) — `document.cookie(name)` ❌

```js
const vector = document.cookie(name).split(';');
```

`document.cookie` is a property, not a function. Calling it with `(...)` throws `TypeError: document.cookie is not a function`.

**Fix:** Remove parentheses.

---

### Bug 2 (Critical) — `if` trapped inside `while`

```js
while(v.charAt(0) === " "){
    v = v.substring(1, v.length);
    if(v.indexOf(nameEQ) == 0)          // ← inside while
        return v.substring(nameEQ.length, v.length);
}
```

The `if` only runs after trimming a space. If the cookie has no leading spaces, the `while` body never executes and the match is **never checked**.

**Fix:** Move `if` outside the `while`.

---

### Bug 3 — Missing `return null`

If no cookie matches, the function returns `undefined` instead of `null`.

**Fix:** Add `return null;` after the loop.

function getCookie(name) {
    const nameEQ = name + "=";
    const ca = document.cookie.split(';');
