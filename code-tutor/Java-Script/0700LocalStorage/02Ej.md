## Code Review & Feedback

Your code works flawlessly, but here are two tiny observations to make it even cleaner:

1. **Variable Naming (`html` and `html0`):** You named the stringified variables `html` and `html0`. While it works, it might confuse other developers because the data is actually a **JSON string**, not HTML code. Naming them something like `jsonString` or `serializedData` is more accurate.
2. **DRY Principle (Don't Repeat Yourself):** You wrote the exact same code to update the `output.innerHTML` twice (once at the top and once inside `miBotonP`). You could move that logic into a small reusable function to keep your code cleaner.

Here is how that would look:

```javascript
// Function to display the profiles in the HTML
function displayProfiles(profilesArray) {
    output.innerHTML = profilesArray.map(p =>
        `Usuario: ${p.username}, puntos: ${p.score}`
    ).join('<br>');
}

// Cargar al inicio si hay datos guardados
const saved = window.localStorage.getItem('user');

    displayProfiles(JSON.parse(saved));
}

```
