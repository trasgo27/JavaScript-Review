Tasks

Task 1: Check if any number is greater than 100

Use .some() on numbers to check if there is at least one number greater than 100. Log true or false.

Task 2: Check if all numbers are positive

Use .every() on numbers to verify all numbers are greater than 0. Log the result.

Task 3: Check if any word is longer than 6 letters

Use .some() on words to check if any word has more than 6 characters. Log the result.

Task 4: Check if all products are electronics

Use .every() on products to check if every product has category "electronics". What does it return and why?

Task 5: Check if any product is cheap

Use .some() on products to check if any product costs less than 50. Log the result.

Task 6: Check if every product has a rating above 3

Use .every() on products to verify all ratings are above 3. Log the result.

Task 7: Test an empty array

Call .some() and .every() on emptyArray with any callback. What does each return? Log both and observe the behavior.

Task 8: Check mixed values with some

Use .some() on mixedValues to check if there is any truthy value. Log the result.

Task 9: Check mixed values with every

Use .every() on mixedValues to check if every value is truthy. Log the result.

Task 10: Compound condition (Bonus)

Use .some() on products to check if there is any product that is BOTH cheap (under 100) AND has a rating above 4. Log the matching product if found, or "none" if not.

English Challenge

Write 2–3 sentences in English explaining what .some() and .every() return when called on an empty array. Why do they behave this way?

Reference

array.some((currentValue, index, array) => condition);
// Returns: true if ANY element passes, false otherwise
// Empty array → false

array.every((currentValue, index, array) => condition);
// Returns: true if ALL elements pass, false otherwise
// Empty array → true
