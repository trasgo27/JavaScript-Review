flat() and flatMap() Mastery

Exercise 20: Master flat() and flatMap()

Practice flattening nested arrays with Array.prototype.flat() and Array.prototype.flatMap(): depth control, mapping while flattening, and real-world data.

// flat signature:
// const flatArray = array.flat(depth);
// depth: how many levels to flatten (default: 1)
// Returns: a new flattened array

// flatMap signature:
// const result = array.flatMap((currentValue, index, array) => {
//     return array | value; // flattens one level after mapping
// });
// Equivalent to: array.map(callback).flat(1)

Setup

const nested1 = [[1, 2], [3, 4], [5, 6]];
const nested2 = [[1, [2, 3]], [4, [5, 6]], [7, [8, 9]]];
const nested3 = [1, [2, [3, [4, [5]]]]];
const sentences = ["hello world", "good morning", "how are you"];
const products = [
    { name: "Laptop", tags: ["electronics", "computers", "tech"] },
    { name: "Shirt", tags: ["clothing", "fashion"] },
    { name: "Phone", tags: ["electronics", "mobile", "tech"] },
];

Tasks

Task 1: Flatten one level

Use .flat() on nested1 to flatten it into a single array. Log the result.

// Expected: [1, 2, 3, 4, 5, 6]

Task 2: Flatten two levels

Use .flat() with depth 2 on nested2 to fully flatten it. Log the result.

Task 3: Flatten completely with Infinity

Use .flat(Infinity) on nested3 to flatten all levels. Log the result.

Task 4: Split sentences into words with flatMap

Use .flatMap() on sentences to split each sentence into words and produce a single array of all words.

// Expected: ["hello", "world", "good", "morning", "how", "are", "you"]

Task 5: Collect all product tags with flatMap

Use .flatMap() on products to collect all tags into a single array. Log it.

Task 6: flatMap with transformation

Use .flatMap() on nested1 to flatten AND double each number in one step.

// Expected: [2, 4, 6, 8, 10, 12]

Task 7: Filter and flatten with flatMap

Use .flatMap() on numbers (from previous exercises) to return [n] for even numbers and [] for odd numbers, effectively filtering and keeping only evens.

// numbers = [5, 12, 8, 130, 44, 3, 27, 9, 150, 1]
// Expected: [12, 8, 130, 44, 150]

Task 8: flatMap vs map + flat

Rewrite the Task 4 solution using .map() followed by .flat(). Compare the two approaches.

Task 9: Unique tags

Use .flatMap() to collect all product tags, then remove duplicates using Set or .filter().

// Expected: ["electronics", "computers", "tech", "clothing", "fashion", "mobile"]

Task 10: Deep flatten manual (Bonus)

Write a recursive function deepFlatten(arr) that flattens an array to any depth without using .flat(). Test it on nested3.

English Challenge

Write 2–3 sentences in English explaining the advantage of .flatMap() over calling .map() then .flat() separately. Why is it more efficient?
