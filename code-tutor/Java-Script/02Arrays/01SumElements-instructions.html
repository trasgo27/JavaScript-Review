Sum Elements with reduce()

Code Explanation

The original code in 01SumElemets.html does the following:

const vector = [4, 90, 78, 33];

function add(a, b) {
    return a + b;
}

const summatory = vector.reduce(add, 0);
console.log(summatory); // 205

How it works

  • Line 1: Creates an array [4, 90, 78, 33]
  • Lines 3-5: Defines a named function add that takes two parameters and returns their sum
  • Line 7: Calls reduce() with the add function and initial value 0
  • Trace: 0 + 4 = 4 → 4 + 90 = 94 → 94 + 78 = 172 → 172 + 33 = 205

Key Concepts

  • reduce() iterates through the array, calling add(acc, current) for each element
  • The initial value 0 is passed as the first acc
  • The callback function's return value becomes the next acc

Reference (reduce signature)

array.reduce((accumulator, currentValue, index, array) => {
    return newAccumulator;
}, initialValue);

// Without initialValue:
//   - First call: acc = array[0], current = array[1]
//   - Requires array to have at least 1 element
// With initialValue:
//   - First call: acc = initialValue, current = array[0]
//   - Safe for empty arrays
