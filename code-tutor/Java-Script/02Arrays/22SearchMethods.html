includes(), indexOf(), and lastIndexOf() Mastery

Exercise 22: Master includes(), indexOf(), and lastIndexOf()

Practice searching arrays with Array.prototype.includes(), Array.prototype.indexOf(), and Array.prototype.lastIndexOf().

// includes signature:
// const exists = array.includes(searchElement, fromIndex);
// Returns: true if found, false otherwise

// indexOf signature:
// const index = array.indexOf(searchElement, fromIndex);
// Returns: first index found, or -1

// lastIndexOf signature:
// const index = array.lastIndexOf(searchElement, fromIndex);
// Returns: last index found, or -1

Setup

const numbers = [5, 12, 8, 130, 44, 3, 27, 9, 150, 1, 12, 8];
const words = ["reduce", "map", "filter", "find", "some", "every", "flat", "map"];
const people = [
    { name: "Alice", age: 25 },
    { name: "Bob", age: 30 },
    { name: "Charlie", age: 35 },
    { name: "Bob", age: 40 },
    { name: "Diana", age: 28 },
];

Tasks

Task 1: Check if number exists

Use .includes() on numbers to check if 44 is in the array. Log the result.

Task 2: Check if number does NOT exist

Use .includes() on numbers to check if 99 is in the array. Log the result.

Task 3: Find index of a word

Use .indexOf() on words to find the index of "filter". Log it.

Task 4: Find index of a duplicate

Use .indexOf() on words to find the first occurrence of "map". Log the index.

Task 5: Find last index of a duplicate

Use .lastIndexOf() on words to find the last occurrence of "map". Log it.

Task 6: Handle not found

Use .indexOf() on numbers to search for 99. If it returns -1, log "Not found".

Task 7: Search with fromIndex

Use .indexOf() on numbers with a fromIndex of 5 to search for 12 only from index 5 onward. Is it found? Log the index.

Task 8: Check for object with includes

Use .includes() on people to search for { name: "Bob", age: 30 }. Does it find it? Why or why not?

Task 9: Remove duplicates using indexOf

Use .filter() with .indexOf() on a copy of numbers to create a new array with duplicates removed.

Task 10: Custom includes (Bonus)

Write your own function myIncludes(arr, value) that works like .includes(). Use a for loop. Test it.

English Challenge

Write 2–3 sentences in English explaining why .includes() and .indexOf() cannot be used to find objects. What method should you use instead and why?

Reference

array.includes(searchElement, fromIndex = 0);
// Returns: true | false

array.indexOf(searchElement, fromIndex = 0);
// Returns: index (number) | -1

array.lastIndexOf(searchElement, fromIndex = array.length - 1);
// Returns: index (number) | -1
