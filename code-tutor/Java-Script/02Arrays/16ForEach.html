forEach() Mastery

Exercise 16: Master the forEach() Method

Practice iterating over arrays with Array.prototype.forEach(): side effects, index usage, and working with the original array.

// forEach signature:
// array.forEach((currentValue, index, array) => {
//     // perform side effect
// });

// forEach always returns undefined.
// It is used for side effects (logging, mutating, DOM updates).

Setup

const numbers = [5, 12, 8, 130, 44, 3, 27, 9, 150, 1];
const words = ["reduce", "map", "filter", "find", "some", "every", "flat"];
const people = [
    { name: "Alice", age: 25 },
    { name: "Bob", age: 30 },
    { name: "Charlie", age: 35 },
    { name: "Diana", age: 28 },
];

Tasks

Task 1: Log each element

Use .forEach() to log every number in the numbers array to the console.

Task 2: Log element and index

Use .forEach() to log each word and its index in the format "index: word".

Task 3: Double values in place

Use .forEach() to double every number in the numbers array directly (mutate the original array). Log the array after.

Task 4: Build a new array

Use .forEach() on numbers to push each number multiplied by 3 into a new array tripled. Log tripled.

Task 5: Create name tags

Use .forEach() on people to log "Name: X, Age: Y" for each person.

Task 6: Filter with forEach

Use .forEach() on numbers to collect all numbers greater than 50 into a new array bigNumbers. Log it.

Task 7: Uppercase words

Use .forEach() to uppercase each word in words and store the results in a new array upperWords. Log it.

Task 8: Sum with forEach

Use .forEach() to calculate the sum of numbers (without using reduce). Use an external variable.

Task 9: Add age groups

Use .forEach() on people to add a property ageGroup to each object: "young" if under 30, "adult" otherwise. Log the modified array.

Task 10: forEach vs map (Bonus)

Rewrite Task 4 (tripled numbers) using .map() instead of .forEach(). Compare the two approaches. Which is more appropriate and why?

English Challenge

Write 2–3 sentences in English explaining the difference between .forEach() and .map(). When would you use one over the other?

array.forEach((currentValue, index, array) => {
