## Reporte de Debug: `Pract.Arrays\03Ej.js`

### Código actual (solo normaliza)
```js
const logLimpio = logsServidor.map((item) => ({
    userId: item.userId.trim().toLowerCase(),
    action: item.action.trim().toLowerCase(),
    status: item.status.trim().toLowerCase(),
}));
```
El `.map()` limpia espacios y normaliza a minúsculas, **pero no filtra ni elimina duplicados**.

### Problemas identificados

| # | Problema | Datos afectados |
|---|----------|----------------|
| 1 | **Duplicados no eliminados** tras normalizar | `USR_10/purchase` aparece 3 veces (líneas 2, 4, 6) → `usr_10` / `usr_25/view_item` aparece 2 veces (líneas 3, 7) |
| 2 | **No filtra `status: "failed"`** | Línea 5 (`usr_42/PURCHASE/failed`) pasa sin filtrar, aunque el comentario dice `//Filtrar` |
| 3 | **Comentario engañoso** `//Filtrar Limpiar` | Solo hay `map` (limpiar), falta el `filter` |

### Solución propuesta

```js
const logLimpio = logsServidor
    .map(item => ({
        userId: item.userId.trim().toLowerCase(),
        action: item.action.trim().toLowerCase(),
        status: item.status.trim().toLowerCase(),
    }))
    .filter(item => item.status === "completed")          // solo completados
    .filter((item, i, arr) =>                             // eliminar duplicados
        arr.findIndex(e => e.userId === item.userId && e.action === item.action) === i
    );
```

**Resultado esperado** tras el arreglo:
```
[
  { userId: "usr_10", action: "purchase",   status: "completed" },
  { userId: "usr_25", action: "view_item",  status: "completed" },
  { userId: "usr_88", action: "purchase",   status: "completed" }
]
```

### Detalle: `JSON.stringify(valor, reemplazo, espacio)`

| Parámetro | En el ejemplo | Qué hace |
|-----------|--------------|----------|
| `valor` | `logLimpio` | El dato a convertir (array, objeto, primitivo) |
| `reemplazo` | `null` | Función o array para filtrar qué incluir. `null` = incluir todo |
| `espacio` | `2` | Cantidad de espacios para indentar (legibilidad) |

**Sin el 3er parámetro** — todo en una línea, difícil de leer:
```js
// → [{"userId":"usr_10","action":"purchase","status":"completed"},...]
```

**Con `null, 2`** — cada nivel de anidación suma 2 espacios, saltos de línea:
```json
[
  {
    "userId": "usr_10",
    "action": "purchase",
    "status": "completed"
  },
  ...
]
```

**Utilidad:**
- Ver el contenido real (evita `[Object]` en consola)
- Revela errores ocultos (referencias circulares, `undefined`, `BigInt`)
- Depurar estructuras anidadas sin expandir manualmente

**Limitaciones** — omite silenciosamente: `undefined`, `BigInt` (error), funciones, `Symbol`, `NaN`/`Infinity` → `null`.
```js
JSON.stringify({ a: 1, b: undefined, c: function(){} });
// → { "a": 1 }  (b y c desaparecieron)
```

### Por qué `Set` no elimina objetos duplicados

`Set` compara por **referencia** (dirección de memoria), no por valor. Cada objeto literal `{...}` es distinto aunque tenga las mismas propiedades:

```js
{ userId: "usr_10", action: "purchase" } === { userId: "usr_10", action: "purchase" }
// → false  (son dos objetos diferentes en memoria)
```

Por eso `new Set(logLimpio)` mantiene todos los elementos repetidos.

### Soluciones con `Set`

**Opción 1 — Serializar a string como clave única:**
```js
const unicos = [...new Set(logLimpio.map(item => JSON.stringify(item)))]
    .map(item => JSON.parse(item));
```

**Opción 2 — Clave compuesta manual con `Set` como filtro:**
```js
const visto = new Set();
const unicos = logLimpio.filter(item => {
    const clave = `${item.userId}|${item.action}`;
    if (visto.has(clave)) return false;
    visto.add(clave);
    return true;
});
```

### ¿Por qué `JSON.stringify(miSet)` da `{}`?

`JSON.stringify` ignora `Set` porque no tiene propiedades enumerables. Siempre devuelve `{}`.
```js
JSON.stringify(new Set([1, 2, 3])); // → "{}"
```

### Debug: Intentos con `Set` (líneas 29–35 del archivo actual)

```js
// ❌ Código con errores (líneas 29-35)
const miSet = new Set(logLimpio);               // Set de objetos (no elimina dups)
console.log([...miSet]);                         // sigue mostrando repetidos
console.log(JSON.stringify(miSet));              // → "{}"
let miSetDOS = miSet.map(...);                   // ❌ Set no tiene .map()
    ((e) => { return parse(new Set(JSON.stringify(...))); }) // ❌ parse no existe
```

| # | Error | Línea | Causa |
|---|-------|-------|-------|
| 1 | `miSet.map is not a function` | 30 | `Set` no tiene `.map()` — solo `Array` lo tiene |
| 2 | `parse is not defined` | 32 | No existe `parse`. Debe ser `JSON.parse` |
| 3 | `JSON.stringify(e.userId, e.action, e.status)` | 32 | Uso incorrecto: 2º parámetro = replacer, 3º = espacio. `"purchase"` y `"completed"` se interpretan mal |
| 4 | `new Set(JSON.stringify(...))` | 32 | `JSON.stringify` devuelve un string, `new Set("string")` crea Set con 1 solo elemento (el string entero) |

**Línea 32 desglosada:**
```js
JSON.stringify(e.userId, e.action, e.status)
// Equivale a: JSON.stringify("usr_10", "purchase", "completed")
// "purchase" en posición replacer → no es función/array → se ignora
// "completed" como espacio → se usa como indentación literal
// Resultado: "usr_10"  (string plano, no JSON de objeto)
```

**Intención original corregida:**
```js
// Viaje de ida y vuelta: objeto → string → Set elimina dups → string → objeto
const unicos = [...new Set(logLimpio.map(item => JSON.stringify(item)))]
                .map(item => JSON.parse(item));
```

### Error común: `Set.map is not a function`

```js
// ❌ Set no tiene .map()
let miSetDOS = [...new Set(miSet.map(item => JSON.stringify(item)))].map(JSON.parse);

// ✅ Convertir Set a array antes de .map()
let miSetDOS = [...new Set([...miSet].map(JSON.stringify))].map(JSON.parse);
// O mejor, desde el array original sin Set intermedio:
let unicos = [...new Set(logLimpio.map(JSON.stringify))].map(JSON.parse);
```

`miSet.map(...)` falla porque `Set` no hereda métodos de `Array`. Usa `[...miSet]` o `Array.from(miSet)` para convertirlo a array primero.

### Error: `{}` en `map` sin `return` devuelve `undefined`

```js
// ❌ Esto devuelve [undefined, undefined, ...]
const limpiaArray = logsServidor.map((item) => {
    {userId: item.userId.trim().toUpperCase()}
    {action: item.action.trim().toUpperCase()}
    {status: item.status.trim().toUpperCase()}
});
```

**Dos problemas:**

1. Las `{}` del cuerpo son un **bloque de código**, no un objeto literal. Sin `return` explícito → `undefined`.
2. Dentro del bloque, `{userId: ...}` es una **sentencia etiquetada** (label), no crea un objeto.

```js
// Esto dentro de un bloque:
{userId: "USR_10"}
// Se interpreta como:
userId: "USR_10"  // etiqueta + expresión, sin efecto
```

**Soluciones:**

**Con paréntesis** (retorno implícito del objeto):
```js
const limpiaArray = logsServidor.map(item => ({
    userId: item.userId.trim().toUpperCase(),
    action: item.action.trim().toUpperCase(),
    status: item.status.trim().toUpperCase(),
}));
```

**Con `return` explícito:**
```js
const limpiaArray = logsServidor.map(item => {
    return {
        userId: item.userId.trim().toUpperCase(),
        action: item.action.trim().toUpperCase(),
        status: item.status.trim().toUpperCase(),
    };
});
```

### Debug: `[...frecuenciaExito].sort()` sin `return` + `.value` inexistente

```js
// ❌ Código con errores (líneas 77-79)
const frecuenciaExitoAsc = [...frecuenciaExito].sort((a, b) => {
    a.value - b.value;          // sin return, a.value es undefined
})
```

**Dos problemas:**

1. `[...frecuenciaExito]` produce pares `[clave, valor]` (ej: `["PURCHASE", 3]`).  
   `a.value` → `undefined` porque `a` es un array, no un objeto con propiedad `.value`.

2. La arrow function usa `{}` (bloque) pero **no tiene `return`** → devuelve `undefined` → `sort` no intercambia nada.

**Corrección — acceder por índice:**
```js
// Ascendente (menor a mayor)
const frecuenciaExitoAsc = [...frecuenciaExito].sort((a, b) => a[1] - b[1]);

// Descendente (mayor a menor)
const frecuenciaExitoDesc = [...frecuenciaExito].sort((a, b) => b[1] - a[1]);
```

| Destructuring opcional | Equivalente |
|------------------------|-------------|
| `.sort(([claveA, valorA], [claveB, valorB]) => valorA - valorB)` | `.sort((a, b) => a[1] - b[1])` |
