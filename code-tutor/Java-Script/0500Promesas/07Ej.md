# 07Ej.js — Debug Report

**3 bugs found and fixed.**

### Bug 1 — `e.inputN.value` / `e.input1.value` (line 27-28 → crash)

`e` is a `MouseEvent` from the click, which has no `.inputN` or `.input1` property.

> `TypeError: Cannot read properties of undefined (reading 'value')`

**Fix:** Use the already-declared DOM references `inputN` and `input1`:
```js
const nom = inputN.value;
const num = parseInt(input1.value);
```

### Bug 2 — `num.typeof()` is not a function (line 12 → crash)

`typeof` is an operator, not a method. Calling `num.typeof()` throws:

> `TypeError: num.typeof is not a function`

**Fix:** Use the `typeof` operator correctly:
```js
typeof num !== 'number'
```

Also added `isNaN(num)` to catch `NaN` values.

### Bug 3 — `setTimeout(new Promise(...))` (line 18 → crash)

`setTimeout` expects a **function** as the first argument, not a Promise object:

> `TypeError [ERR_INVALID_ARG_TYPE]: The "callback" argument must be of type function`

Additionally, `setTimeout` returns a timer ID (number), not a Promise, so `.then()` chaining also fails.

**Fix:** Wrap the Promise logic **inside** the `setTimeout` callback:
```js
return new Promise((resolve, reject) => {
    setTimeout(() => {
        if (exito) resolve(...);
        else reject(...);
    }, num * 1000);
});
```

### Additional improvement

When validation fails, the function now returns a **rejected Promise** instead of `undefined`, so the caller's `.catch()` handles it properly.
