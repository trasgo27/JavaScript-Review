### Bugs in `destinos.js`

| Bug | Before | After |
|-----|--------|-------|
| `find()` + `.map()` → should be `.filter()` | `catalogo.find(...).map(...)` — `find` returns one element, not an array | `catalogo.filter(...).map(...)` |

| No initial render | `renderCatalogo()` defined but never called | Added `renderCatalogo()` at end of script |
| Incremental render logic | Manual rebuild in click handler | Call `renderCatalogo()` after push |

## Feature: click to delete a destination

### Implementation

Each destination is rendered as a clickable `<span data-index="${i}">` so clicking on it removes it from the array via `splice()`.

### Changes to `renderCatalogo()`

```js
function renderCatalogo() {
    const lista = catalogo.map((d, i) =>
        `<span data-index="${i}" style="cursor:pointer">${i + 1}. ${d.destino} — ${d.continente}</span>`
    ).join('<br>');

    div3.innerHTML = "<h3>Destinos (clic para eliminar)</h3>" + lista +
        "<br><br>" +
        `<button value="Africa">África</button>
        <button value="Asia">Asia</button>
        <button value="Europa">Europa</button>
        <button value="Oceania">Oceania</button>
        <button value="Norteamerica">Norteamerica</button>
        <button value="Sudamerica">Sudamerica</button>`;
}
```

### Updated click handler (delete + filter)

```js
div3.addEventListener('click', (e) => {
    // Delete: clicking a destination text
    const index = e.target.dataset.index;
    if (index !== undefined) {
        catalogo.splice(index, 1);
        renderCatalogo();
        return;
    }

    // Filter: clicking a continent button
    const contiSele = e.target.value;
    if (!contiSele) return;

    const filtrados = catalogo.filter(item =>
        item.continente.toLowerCase() === contiSele.toLowerCase()
    );

    const html = filtrados.map((item, i) =>
        `${i + 1}. ${item.destino}`
    ).join('<br>');

    div3.innerHTML = "<h3>" + contiSele + "</h3>" + html +
        '<br><br><button onclick="renderCatalogo()">Volver</button>';
});
```

### How it works

| Click on | Detected by | Action |
|----------|-------------|--------|
| Destination text | `e.target.dataset.index` | `splice(index, 1)` + re-render |
| Filter buttons | `e.target.value` | Filter by continent |
| Elsewhere | Falls through both guards | No action |

## Deletion by selecting

### Step 1 — Store the index in the HTML

In `renderCatalogo()`, each destination is rendered with a `data-index` attribute:

```html
<span data-index="${i}">${i + 1}. ${d.destino} — ${d.continente}</span>
```

If `catalogo` is:

```js
[{destino:"Paris", continente:"Europa"}, {destino:"Lima", continente:"Sudamerica"}]
```

It renders as:

```
<span data-index="0">1. Paris — Europa</span><br>
<span data-index="1">2. Lima — Sudamerica</span>
```

`data-index="0"` means "this is the element at position 0 in the array."

### Step 2 — One click listener on the parent

```js
div3.addEventListener('click', (e) => {
    const index = e.target.dataset.index;
    if (index !== undefined) {
        catalogo.splice(index, 1);
        renderCatalogo();
        return;
    }
    // ... filter button logic ...
});
```

### What happens when you click "Paris"

| Step | Code | Result |
|------|------|--------|
| User clicks "Paris" | `e.target` → `<span data-index="0">` | Event bubbles up to `div3` |
| Read index | `e.target.dataset.index` → `"0"` | String `"0"` |
| Not `undefined`? | `"0" !== undefined` → `true` | Enters the `if` block |
| Remove from array | `catalogo.splice(0, 1)` | `[{destino:"Lima", ...}]` (Paris gone) |
| Re-render | `renderCatalogo()` | HTML redraws with only Lima |

### Why this is clean

- **No query selectors needed** — the index is right there in the HTML
- **One listener for all items** — not an individual listener per item
- **Index stays in sync** — after `splice()`, the array shrinks and `renderCatalogo()` reassigns fresh `data-index` values

### Visual flow

```
Before click:  catalogo = [Paris, Lima, Roma]
                             ↑ index 0

Click "Paris" → splice(0,1) → [Lima, Roma]

Call renderCatalogo() → <span data-index="0">Lima</span>
                         <span data-index="1">Roma</span>
```

## How click-to-delete works — two pieces working together

### 1. `data-index` attribute in `renderCatalogo()`

Each destination is rendered as a clickable `<span>` with its position stored:

```html
<span data-index="${i}" style="cursor:pointer">
    ${i + 1}. ${d.destino} — ${d.continente}
</span>
```

`data-index="${i}"` stores the array index directly in the HTML.

### 2. Event delegation on `div3`

One listener catches all clicks inside `div3`:

```js
div3.addEventListener('click', (e) => {
    const index = e.target.dataset.index;   // read the data-index
    if (index !== undefined) {               // clicked on a destination?
        catalogo.splice(index, 1);           // remove that item from array
        renderCatalogo();                    // re-render the whole list
        return;
    }
    // ... otherwise check if it's a filter button
});
```

### Step by step

| Event | `e.target` | Action |
|-------|------------|--------|
| Click "Paris" | `<span data-index="0">` | `splice(0, 1)` → removes Paris |
| Click "África" button | `<button value="Africa">` | Filter by continent |

`splice(index, 1)` removes 1 element at position `index` from the array, then `renderCatalogo()` redraws everything minus that item.
