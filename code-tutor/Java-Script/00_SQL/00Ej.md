# Debug Report: 07Ej.js (Mini CRUD App)

## Summary
4 bugs found in route handlers.

---

## Bug 1 — POST /api/todos (Line 49)
**Status:** Hardcoded value instead of using request body
```javascript
// ❌ Current (wrong)
const info = db.prepare('INSERT INTO todos (task) VALUES(?)').run('Pasear Rocky');

// ✅ Fix
const info = db.prepare('INSERT INTO todos (task) VALUES(?)').run(task);
```

---

## Bug 2 — PUT /api/todos/:id (Line 64)
**Status:** Hardcoded ID `1` instead of using route parameter
```javascript
// ❌ Current (wrong)
const todo = db.prepare('SELECT completed FROM todos WHERE id = ?').get(1);

// ✅ Fix
const todo = db.prepare('SELECT completed FROM todos WHERE id = ?').get(id);
```

---

## Bug 3 — PUT /api/todos/:id (Lines 70-74)
**Status:** Status not toggled + missing UPDATE query
```javascript
// ❌ Current (wrong)
const newStatus = 0;
// ... no UPDATE query

// ✅ Fix
const newStatus = 1 - todo.completed;
db.prepare('UPDATE todos SET completed = ? WHERE id = ?').run(newStatus, id);
```

---

## Bug 4 — DELETE /api/todos/:id (Line 88)
**Status:** Invalid SQL syntax (`DELETE id` is not valid)
```javascript
// ❌ Current (wrong)
const info = db.prepare('DELETE id FROM todos WHERE id=?').run(id);

// ✅ Fix
const info = db.prepare('DELETE FROM todos WHERE id = ?').run(id);
```
