Exercise 07: Mini CRUD App (Express + SQLite)

Bridge the gap between frontend and backend. You will build a REST API in Node.js with Express that interacts with SQLite, and connect it to the interactive dashboard below.

API Specifications

  • GET /api/todos — Returns an array of all todos.
  • POST /api/todos — Expects { task: "text" }, inserts it, and returns the new todo.
  • PUT /api/todos/:id — Toggles the completed status (1 or 0) of a todo by ID.
  • DELETE /api/todos/:id — Deletes the todo by ID.

Your Tasks

Task 1: Run your server

Complete the TODOs inside `07Ej.js` to create the Express endpoints. Start the server by running node 07Ej.js.

Task 2: Implement GET /api/todos

Select all tasks and return them using res.json().

Task 3: Implement POST /api/todos

Accept the task text in req.body.task, insert it into SQLite, and return the newly created object with its ID.

Task 4: Implement PUT /api/todos/:id

Fetch the current task status, toggle it (e.g. 1 - currentStatus), update the DB, and return the updated task.

Task 5: Implement DELETE /api/todos/:id

Delete the row and return a success message or status code 204.
