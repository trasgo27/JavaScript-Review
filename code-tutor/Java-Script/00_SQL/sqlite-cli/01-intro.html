01 — Intro & Navigation

Learn the basic SQLite CLI commands: open a database, list tables, view schemas, and export data.

Database file: intro.db — created automatically when you first connect.

Step 1: Open a Database

sqlite3 intro.db
SQLite version 3.x.x
Enter ".help" for usage hints.
sqlite>

If intro.db doesn't exist, SQLite creates it. If it already exists, it opens it.

Step 2: List All Tables

.tables
(empty — no tables yet)

Nothing to see yet. Let's create a table and try again.

Step 3: Create a Table

CREATE TABLE test (id INTEGER, name TEXT, value REAL);

Don't forget the semicolon ; — SQLite won't execute until it sees one.

Step 4: List Tables Again

.tables
test

Step 5: View Table Schema

.schema test
CREATE TABLE test (id INTEGER, name TEXT, value REAL);

Step 6: Insert Some Data

INSERT INTO test VALUES (1, 'Alpha', 10.5);
INSERT INTO test VALUES (2, 'Beta', 20.3);
INSERT INTO test VALUES (3, 'Gamma', 15.7);

Step 7: Query Data

SELECT * FROM test;
1|Alpha|10.5
2|Beta|20.3
3|Gamma|15.7

The default output is pipe-separated. Let's make it prettier.

Step 8: Pretty Output

.mode column
.headers on
SELECT * FROM test;
id  name   value
--  -----  -----
1   Alpha  10.5
2   Beta   20.3
3   Gamma  15.7

Always use these two commands for readable output — they're your best friends.

Step 9: Export (Dump) the Database

.dump
PRAGMA foreign_keys=OFF;
BEGIN TRANSACTION;
CREATE TABLE test (id INTEGER, name TEXT, value REAL);
INSERT INTO test VALUES(1,'Alpha',10.5);
INSERT INTO test VALUES(2,'Beta',20.3);
INSERT INTO test VALUES(3,'Gamma',15.7);
COMMIT;

.dump outputs the full SQL needed to recreate the database — great for backups and sharing.

Step 10: Show Help

.help

Lists every dot-command available. Scroll through to see what's possible.

Step 11: Exit

.quit

Quick Reference — Dot Commands

.tablesList all tables
.schema <table>Show CREATE statement for a table
.dumpExport full database as SQL
.mode columnPretty column output
.headers onShow column names
.helpList all dot-commands
.quitExit SQLite

Practice Tasks

  1. Open intro.db again with sqlite3 intro.db
  2. Use .tables — you should see test (it persists between sessions)
  3. Insert a 4th row: ('Delta', 99.9)
  4. Query only rows where value > 15
  5. Type .quit
