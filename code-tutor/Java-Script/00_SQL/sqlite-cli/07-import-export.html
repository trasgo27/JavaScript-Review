07 — Import & Export

Load CSV files into SQLite, export databases to SQL, and run script files.

Database file: import.db
CSV files: data/users.csv and data/products.csv (provided in this folder)

Task 1: Create Table Matching CSV Structure

CSV files have headers. You need to create a table with matching columns before importing.

sqlite3 import.db

CREATE TABLE users (
  name TEXT,
  email TEXT,
  age INTEGER
);

Task 2: Import CSV into Table

-- Change mode to CSV
.mode csv

-- Import the file (use the full path or run from this folder)
.import data/users.csv users

-- Verify
.mode column
.headers on
SELECT * FROM users;

Task 3: Import Products CSV

CREATE TABLE products (
  name TEXT,
  price REAL,
  stock INTEGER,
  category TEXT
);

.mode csv
.import data/products.csv products

.mode column
SELECT * FROM products;

Task 4: Export to SQL File

-- Send output to a file instead of the screen
.output backup.sql

-- Dump the whole database to the file
.dump

-- Reset output back to the screen
.output stdout

-- Check the file (in another terminal)
.shell type backup.sql

Task 5: Run a SQL Script

-- Exit current session
.quit

Now in your terminal (not in sqlite prompt):

-- Create a script file with multiple SQL commands
echo CREATE TABLE test (id INT, val TEXT); INSERT INTO test VALUES (1, 'hello'); INSERT INTO test VALUES (2, 'world'); > script.sql

(Or create script.sql with a text editor with those contents.)

Then run it:

sqlite3 scripted.db .read script.sql

Open scripted.db to verify:

sqlite3 scripted.db
.mode column
SELECT * FROM test;
.quit

Task 6: Export SELECT Results to CSV

sqlite3 store.db
.headers on
.mode csv
.output electronics.csv
SELECT * FROM products WHERE category = 'electronics';
.output stdout
.quit

-- View the CSV file (from terminal, not sqlite)
type electronics.csv

Quick Reference — Import/Export Commands

.mode csvSwitch to CSV mode
.import file.csv tablenameImport CSV into table (must exist first)
.output filename.sqlRedirect output to file
.output stdoutReset output to screen
.dumpExport full database as SQL
.read script.sqlRun SQL commands from a file
.shell cmdRun a shell command from inside sqlite3
