06 — JOINs

Combine data from multiple tables using JOINs.

Database file: joins.db — seed it fresh below.

sqlite3 joins.db

CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  email TEXT NOT NULL UNIQUE,
  age INTEGER
);

CREATE TABLE products (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT,
  price REAL,
  stock INTEGER DEFAULT 0,
  category TEXT
);

CREATE TABLE orders (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER,
  product_id INTEGER,
  quantity INTEGER,
  order_date TEXT DEFAULT CURRENT_DATE,
  FOREIGN KEY (user_id) REFERENCES users(id),
  FOREIGN KEY (product_id) REFERENCES products(id)
);

Task 1: INNER JOIN (Only Matching)

Users who have placed orders — only users with matching orders appear:

SELECT orders.id AS order_id, users.name AS user_name, orders.quantity
FROM orders
INNER JOIN users ON orders.user_id = users.id;

Task 2: LEFT JOIN (All Users, Even Without Orders)

Every user appears. Users with no orders show NULL for order data:

SELECT users.name, orders.id AS order_id, orders.quantity
FROM users
LEFT JOIN orders ON users.id = orders.user_id;

Task 3: 3-Table JOIN (Detailed Orders)

Connect orders → users → products to get full details:

SELECT
  orders.id AS order_id,
  users.name AS customer,
  products.name AS product,
  orders.quantity,
  products.price,
  (orders.quantity * products.price) AS total
FROM orders
JOIN users ON orders.user_id = users.id
JOIN products ON orders.product_id = products.id;

Task 4: JOIN with Aggregation (Big Spenders)

Users who spent more than $100 total:

SELECT
  users.name,
  SUM(orders.quantity * products.price) AS total_spent
FROM users
JOIN orders ON users.id = orders.user_id
JOIN products ON orders.product_id = products.id
GROUP BY users.id
HAVING total_spent > 100;

Task 5: Table Aliases (Shorter Syntax)

SELECT o.id AS order_id, u.name AS customer, p.name AS product
FROM orders o
JOIN users u ON o.user_id = u.id
JOIN products p ON o.product_id = p.id;
