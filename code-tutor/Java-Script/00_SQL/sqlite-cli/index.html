Master the sqlite3 command-line tool — write SQL directly in the terminal, no JavaScript needed.

How to Use

  • 1 Open a terminal in this folder
  • 2 Type sqlite3 <db-file>.db
  • 3 Copy-paste the SQL from each exercise
  • 4 Type .quit to exit
