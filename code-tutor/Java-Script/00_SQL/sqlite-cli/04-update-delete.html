04 — UPDATE & DELETE

Modify and remove records. Always use WHERE or you'll affect every row.

Database file: store.db — use the same seed from Exercise 02, or re-run the seed SQL.
⚠️ CRITICAL: An UPDATE or DELETE without WHERE modifies every row. Always SELECT first to preview which rows will be affected, then run the UPDATE/DELETE with the same WHERE.

Step 0: Open store.db

sqlite3 store.db
.mode column
.headers on

If you haven't seeded this database yet, run the seed SQL from Exercise 02 first.

Task 1: UPDATE a Single Record

-- Preview: find Bob
SELECT * FROM users WHERE name = 'Bob';

-- Update Bob's email
UPDATE users SET email = 'bob.smith@example.com' WHERE name = 'Bob';

-- Verify
SELECT * FROM users WHERE name = 'Bob';

Task 2: UPDATE Multiple Records

-- Preview
SELECT name, price FROM products WHERE category = 'electronics';

-- Increase electronics prices by 10%
UPDATE products SET price = price * 1.1 WHERE category = 'electronics';

-- Verify
SELECT name, price FROM products WHERE category = 'electronics';

Task 3: UPDATE with Calculations

-- Restock Jeans: add 15 to current stock
UPDATE products SET stock = stock + 15 WHERE name = 'Jeans';
SELECT name, stock FROM products WHERE name = 'Jeans';

Task 4: DELETE Records

-- Preview: users under 25
SELECT * FROM users WHERE age < 25;

-- Delete them
DELETE FROM users WHERE age < 25;

-- Verify
SELECT * FROM users;

Task 5: DELETE Matching a Condition

-- Preview: out-of-stock products
SELECT * FROM products WHERE stock = 0;

-- Delete them
DELETE FROM products WHERE stock = 0;

-- Verify
SELECT * FROM products;

Task 6: Transactions (Undo Safety)

Wrap changes in a transaction so you can roll back if you make a mistake:

BEGIN TRANSACTION;
-- Try a dangerous operation
DELETE FROM products;
-- Oops! That deleted everything!
ROLLBACK;
-- All data restored
SELECT COUNT(*) FROM products;

Use COMMIT instead of ROLLBACK if you're happy with the changes.

Practice Tasks

  1. Update the category of 'Mouse' from 'electronics' to 'accessories'
  2. Delete all products in 'clothing' category
  3. Give all users a 1-year age increase: UPDATE users SET age = age + 1;
  4. Before doing #3, wrap it in a transaction and roll back if the result is wrong
