Exercise 04: ORDER BY, LIMIT, and Aggregates

Learn to sort datasets using ORDER BY, restrict rows returned with LIMIT, and query summary statistics using functions like SUM, AVG, COUNT, and GROUP BY.

Your Tasks

Task 1: Top 3 most expensive products

Retrieve the name and price of the top 3 most expensive products. Sort them descending.

Task 2: Total number of products and users

Get the total count of rows in the users table, and also the sum of all product stock in the products table. (Use COUNT(*) and SUM(stock)).

Task 3: Youngest user

Query the single user with the lowest age. (Hint: combine ORDER BY age ASC LIMIT 1 or use MIN(age)).

Task 4: Average price and count per category

Get the category, average price (as avg_price), and total product count (as total_items) for each category using GROUP BY category.

Task 5: Aggregate filter (HAVING)

Find the categories that have an average product price greater than $50. (Hint: Use GROUP BY category HAVING avg_price > 50).

💡 Key Hints
  • Use db.prepare(sql).get() when querying scalar values or a single row (like COUNT, MIN, or LIMIT 1).
  • Use db.prepare(sql).all() when grouping records (e.g. GROUP BY).
