## Multiple Databases in One File

You can create and use multiple database connections in the same script without issues. Each `new Database('filename.db')` opens a separate connection to its own file:

```js
const db1 = new Database('ex03.db');
const db2 = new Database('another.db');

db1.prepare("INSERT INTO users ...").run(...);
db2.prepare("CREATE TABLE ...").exec(...);
```

They operate independently — no conflict, no crash. Just remember to `.close()` each one at the end to free resources.

## Reference: `.run()` for UPDATE/DELETE

In better-sqlite3, `db.prepare(sql).run(...params)` is the method used for INSERT, UPDATE, and DELETE statements. Unlike `.all()` (which returns rows), `.run()` returns an object:

```js
{ changes: <number>, lastInsertRowid: <number> }
```

- `changes` — the number of rows affected by the statement
- `lastInsertRowid` — the row ID of the last inserted row (relevant for INSERT)

Example:

```js
const result = db.prepare("UPDATE users SET age = ? WHERE name = ?").run(31, 'Alice');
console.log(result.changes); // 1
```

You can also chain inline:

```js
const { changes } = db.prepare("DELETE FROM products WHERE stock = ?").run(0);
console.log(changes); // number of deleted rows
```
