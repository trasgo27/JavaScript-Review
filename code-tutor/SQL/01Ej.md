**Fix:** Changed to backtick template literal `` ` ``.

### 2. Invalid SQL: `AUTOCOMPLETE` (L26)
**Bug:** Used `AUTOCOMPLETE` instead of `AUTOINCREMENT`.
**Fix:** Replaced with `AUTOINCREMENT`.

### 3. SQL Malformed — `VALUES` clause in `CREATE TABLE` (L29-33)
**Bug:** A `VALUES (...)` clause was appended to the `CREATE TABLE` statement, which is invalid SQL. Also contained literal data ("salva") instead of being a pure DDL statement.
**Fix:** Removed the `VALUES` clause entirely.

### 4. Missing `NOT NULL` on `email` column (L27)
