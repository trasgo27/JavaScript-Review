Gemini ha dicho The reason both your "Initial" and "Ordered" arrays look the same in the console is because of how JavaScript handles Objects and Arrays. In your code, the line let vectorOrdenado = vectorNum; does not create a new array; it creates a reference (a shortcut) to the original one. Since the .sort() method is "destructive" (it modifies the original array in place), both variables end up pointing to the same sorted data.
